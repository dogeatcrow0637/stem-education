# 家长实现总纲（reBot-DevArm 开源六轴机械臂）

| 字段 | 值 |
|---|---|
| 项目编号 | 01 |
| 项目目录 | `projects/rebot-devarm` |
| 适用版本 | 硬件：B601-DM v1.1（DC 24V）／软件：官方 LeRobot 链路（版本号以官方 Wiki 当日文档为准，本项目未实测） |
| 最后更新 | 2026-10-20 |
| 前置条件 | 一张不小于 1.2 m 的空桌面、一台装了 Ubuntu 的**物理机**、一把可调扭力电批、24V 4.5A XT30 电源、USB-CAN 适配器 |

> 本手册面向**完全零基础的家长**，用于带一名小学生从零把本项目做出来并讲明白。工程细节以 `projects/rebot-devarm/docs/` 为准，本手册只讲"怎么带着孩子做"。

## 一句话目标

做完之后，孩子能独立完成的最小成果是：**在电脑上点一下，让机械臂的第 1 个关节转到一个指定角度，然后自己复位**；能看到的现象是：**电机"嗯"一声转过去、屏幕上的角度数字跟着变**。

> 这里刻意只要求"一个关节"。完整六轴装配是几十小时的工作量，先把一个关节跑通，孩子才有"我做到了"的感觉，后面再逐个加。这就是本手册的 **MVP（最小可跑闭环）**。

## 这套手册怎么用

1. **先读安全红线**（本文件最后一节），再读 `05-安全与工具采购清单.md`。
2. 按 `02-里程碑与任务卡.md` 从头做；**一张卡一次坐下做，做完打勾再进下一张**。
3. 每张卡按孩子的实际水平选一档执行（同一项目不同环节可选不同档）：

| 档 | 孩子做什么 | 家长做什么 | 什么时候升档 |
|---|---|---|---|
| L1 观察 | 递零件、对编号、按按钮、说出看到的现象 | 全部动手 + 讲解 + 防护 | 孩子能说清"这步在做什么、成功会看到什么" |
| L2 协作 | 拧螺丝、插线、插拔 USB、填验收表 | 把关紧固与极性、执行危险步骤 | 同类动作无提示也能做对 |
| L3 独立 | 看图纸独立做、改参数、记录数据、讲原理 | 只做安全监护，允许失败 | 能讲清"上次为什么失败、这次改了什么" |

4. 需要**外包**的环节（家长不必自学）：金属件 CNC/钣金加工、批量 3D 打印、线束压接（或直接买带端子成品线束）、可选的电机代烧参数与上位机环境代装。
5. 卡住了：先查 `04-验收与展示.md` 的失败排查表，再对照卡片里的"失败兜底"。

## 总路线图

```mermaid

  M0[M0 定稿与采购] --> M1[M1 底座装配与通电自检]
  M1 --> M2[M2 一个关节能动]
  M2 --> M3[M3 上位机完整链路]
  M3 --> M4[M4 自主创作]
```

| 里程碑 | 孩子的可见成果 | 家长工时估算 | 放弃/跳过条件 |
|---|---|---|---|
| M0 定稿与采购 | 采购清单 + 到货核对表 | 3–5 小时（选型比价、下单、收货核对） | 预算到上限时，只买 MVP 第一批，跳过全臂 |
| M1 底座装配与通电自检 | 底座立住不晃 + 电机指示灯亮的照片 | 4–6 小时 | 打印/加工件没到货时，可先用木板临时底座过渡 |
| M2 一个关节能动 | 关节按指令转过指定角度（≤10 秒视频） | 6–10 小时（含 CAN 环境与使能） | 环境装不上时，改用卖家/社区的桌面远程协助工具，或先只跑电机自带调试软件 |
| M3 完整链路 | 上位机界面显示关节角度并可一键复位（录屏） | 4–8 小时 | 若长期无法稳定通信，接受"只能单关节动作"，把 M3 目标降为"连续 2 次成功即通过" |
| M4 自主创作 | 改动前后对比记录（角度/速度/顺序） | 3–5 小时 | — |

> 工时是**家长实际坐在工作台前的时间**，不含采购等待与打印排期。全六轴装配另需 30 小时以上，不在本手册的 MVP 范围内。

## 场地、作息与收纳

- 工作台：≥1.2 m 长、能承重 10 kg；铺防火垫（电源与焊接用）、光线充足；**桌面必须能上 C 型夹**把底座夹死
- 单次时长：≤ 45 分钟（2 张卡），每 3 张卡安排一次"展示时刻"
- 收纳：螺丝按规格分格；每次结束拍照记录当前状态；**断电断料再离开**
- ⚠️ 机械臂**没有刹车**：收工时必须把臂体降到最低姿态或用支撑座托住，否则它会自己砸下来

## 安全红线（先读这一页）

1. 危险动作一律家长单独执行：焊接（本项目 MVP 不需要）、电源接线与上电、旋紧 C 型夹、任何需要把手臂抬高的操作；孩子在这些步骤里只做 L1（安全距离外观看 + 复述）。
2. 上电前必须做的三件事：① 万用表核对电源输出是 24V 直流且极性正确；② 底座 C 型夹已夹死、运动范围内**清空所有人和物**；③ 手离开臂体运动平面，臂下垫软垫。
3. 出现异常（异味 / 异响 / 冒烟 / 发烫 / 报错）→ **立即断电**，再排查
4. 详细清单见 `05-安全与工具采购清单.md`

## 假设与已知限制

- 本文假设：家长不会焊接 / 不写代码 / 有 Windows 或 Mac 电脑一台 + 一台可装 Ubuntu 的电脑（或双系统）；如不成立，可跳过对应外包项。
- 未验证项：官方套件实际到手件号与开源图纸的差异、DM4310 单价、24V 电源实测电流余量、本工位实测重复定位精度（均标 `待验证`，实测后更新）。
- 关键风险：① **官方开源文件 ≠ 官方出货散件**（金属镭雕、3D 打印件替换、线束定制都有改动），采购前必须逐项比对；② 电机规格相近，**扭力超 6 kgf·cm 会滑丝报废**；③ 无刹车，断电下落。
