# 里程碑与任务卡（reBot-DevArm 开源六轴机械臂）

| 字段 | 值 |
|---|---|
| 适用版本 | 硬件 B601-DM v1.1（DC 24V） |
| 最后更新 | 2026-10-20 |
| 前置条件 | 已读 `00-总纲与路线图.md`；材料已到货 |

> **MVP 边界（务必先看）**：本手册的 M0–M4 只做**底座 + 第 1 个关节**。不装六轴、不碰金属加工、不写代码、不焊接。跑通之后想继续，再回来看 `01-六维拆解总表.md` 的完整路径。

**卡片规则**：一张卡 = 一次坐下 = 一个动作单元（≤25 分钟）；做完必须能看见结果并打勾。打勾格式：`- [x] 卡 M1-1`。每张卡完成盖一枚章，每 3 张卡安排一次"展示时刻"（拍照/录 ≤10 秒视频），每完成一个里程碑发一个称号（材料员 → 接线员 → 调试员 → 工程师）。

## M0 定稿与采购

目标：型号定稿、MVP 物料到货、核对无缺件。

### 卡 M0-1：选版本与下单
- 目标（孩子视角）："我们决定买哪一套，把它请回家。"
- 物料：采购清单（见 `05-安全与工具采购清单.md`）
- 三档分工：L1 一起看图片/视频并说出选哪个｜L2 一起对照清单点数量｜L3 孩子做比较表（价格/难度）并给结论
- 步骤：
  1. 看官方演示视频 → 结果：孩子能说出"我们要做的是这个"（视频：`docs/99-参考资源.md` 里的 58 分钟组装实录）
  2. 对照版本对比表选型 → 结果：写下一行结论（版本 + 理由）。**给孩子一个真实的取舍**：B601-DM 用 24V 更安全、电源更好买；B601-RS 用 48V 和 2.5 kg 负载，但贵也更重
  3. 下单 → 结果：订单截图存档
- 验收判据：清单每一项都有"已下单/替代型号"状态
- 失败兜底：缺货 → 换替代型号或分两家买；预算超了 → 砍到只买 MVP 第一批（见 `05` 第 4 节）
- ⚠️ 安全：—

### 卡 M0-2：到货核对
- 目标："所有零件都到齐，一个都不少。"
- 物料：采购清单 + 分格收纳盒 + 标签贴
- 三档分工：L1 报出零件名｜L2 点数并分格收纳｜L3 记录缺件与错件
- 步骤：逐项核对 → 结果：清单全部打勾；分格收纳 → 结果：照片一张
- 验收判据：无未处理缺件（缺件已联系商家）
- 失败兜底：缺件先做不依赖它的里程碑；螺丝多买 10% 备损

## M1 底座装配与通电自检

目标：底座固定、电机上电看到指示灯，孩子看到"活的"第一眼反馈。

### 卡 M1-1：底座装配与固定
- 目标：把机器立起来、夹住，不会自己倒/掉。
- 物料：底座与第一关节的 3D 打印件（代打到货）、内六角螺丝（多规格，按规格分装）、热熔铜螺母、可调扭力电批、C 型夹、支撑软垫
- 三档分工：L1 递件对号｜L2 拧螺丝（家长把电批扭力锁在 3–6 kgf·cm）｜L3 独立照官方装配图装
- 步骤：
  1. 螺丝按规格分装并贴标签 → 结果：每格一个规格，孩子能报出"这个是 M3×8"
  2. 按官方装配图装底座与第一关节（**v1.1 第一关节用 DM4340P**）→ 结果：底座能立住不晃
  3. 用 C 型夹把底座夹死在桌沿 → 结果：用手推底座不动
  4. 固定线束走向 → 结果：极限姿态下不夹线
- 验收判据：螺丝紧固无漏装；手动缓推关节无卡滞、无异响；底座夹死后推不动
- 失败兜底：孔位偏紧 → 用热熔铜螺母重熔或轻攻丝，别硬拧；装不上 → 核对是不是拿了 v1.0 图纸（v1.1 第一关节改了型号）
- ⚠️ 安全：电批扭力**必须**先调到 3–6 kgf·cm 再用；热熔铜螺母属危险动作，家长单独执行，孩子 L1 旁观

### 卡 M1-2：首次上电（只上电，不装臂）
- 目标：电机指示灯亮，说明电走到了。
- 物料：24V 4.5A XT30 电源、电源线束、万用表、支撑软垫
- 三档分工：L1 在安全距离外看并说出看到什么｜L2 家长口令下按住电源开关｜L3 自己按顺序上电并口述检查项
- 步骤：
  1. **断电状态**用万用表核对电源输出是 24V 直流、极性正确 → 结果：读数写在验收表上
  2. 确认桌上没有金属碎屑、XT30 插头方向正确 → 结果：孩子复述"红对红、黑对黑"
  3. 上电 → 结果：电机指示灯亮 / 听到轻微"嘀"声
  4. 断电收工 → 结果：臂体已托稳
- 验收判据：出现预期指示灯反馈且无发烫、异味、异响
- 失败兜底：无反应 → 查电源开关 / 插头是否插到底 / 保险；发烫或异味 → 立即断电，重查极性
- ⚠️ 安全：上电前清空运动范围、机身已夹死、手离开运动区域；本项目**无刹车**，断电前先用支撑垫托住臂体

## M2 一个关节能动

目标：第 1 个关节受控转过指定角度，孩子第一次看到"我让它动它就动"。

### 卡 M2-1：给电机配 ID 与零点
- 目标：板子/电机装上"名字"和"零位"。（本项目没有自制主控板，这一步是**配置**不是烧录）
- 物料：USB-CAN 适配器、达妙官方调试软件、24V 电源、单颗 DM4310 电机
- 三档分工：L1 看着并复述"刚才给它起了什么名字"｜L2 在口令下插拔 USB-CAN｜L3 独立照文档改 ID 并读出结果
- 步骤：
  1. 装好 USB-CAN 的驱动与调试软件（装不上 → 找卖家远程协助/买已带软件的型号）→ 结果：软件里能扫到设备
  2. 只接一颗电机，设 ID = 1、波特率按官方值（常见 1 Mbps，**待确认**）→ 结果：重新扫描能扫到 ID 1
  3. 标零点并**保存**（不保存等于白标）→ 结果：断电重上电后零点还在
- 验收判据：软件里能稳定读到 ID 1 的角度，重复插拔不掉线
- 失败兜底：扫不到 → 换一根能传数据的 USB 线（很多线只供电）；扫描到多个 → ID 冲突，一颗一颗改；零点丢 → 检查是否点了保存
- ⚠️ 安全：配置时电机**空载、不装臂**、固定在桌上，防止参数错误时突然自转

### 卡 M2-2：让一个关节转起来
- 目标："我发命令，它转一下。"
- 物料：已配好的电机 + 底座第一关节 + 24V 电源 + USB-CAN + 上位机
- 三档分工：L1 按按钮并说出转了多少｜L2 按口令发指令并记录现象｜L3 自己改一个参数（角度/速度）看变化
- 步骤：
  1. 电机装到第一关节位，限位内留足转动空间 → 结果：手动能推到底，不撞桌
  2. 发一条"转到 30°"的指令 → 结果：关节转过去、软件角度读数跟着变（录 ≤10 秒视频）
  3. 发"回零" → 结果：回到起始位置
- 验收判据：动作方向、幅度与预期一致，角度读数与指令值差距在可用范围内（不做精度宣传，留足容差）
- 失败兜底：不动 → 查供电（24V 是否到位）→ 查使能状态 → 查 CAN 线序；抖动或异响 → 降速度、减幅度、查是否撞限位
- ⚠️ 安全：手不进入运动范围；异常立即断电；臂体下方垫软垫

## M3 上位机完整链路

目标：上位机 → CAN → 电机 的完整通路跑通，能做一次"一键演示"。

### 卡 M3-1：上位机连通
- 目标：电脑能识别并控制设备。
- 物料：装了 **Ubuntu 的物理机**（不能用虚拟机）、USB-CAN 适配器、官方 Python SDK、网线或稳定 Wi-Fi
- 三档分工：L1 看图说出"线和电脑接上了"｜L2 插拔 USB / 观察设备列表｜L3 自己跑启动命令并读日志
- 步骤：
  1. 按官方 Wiki 装依赖 → 结果：`python3 --version` 与官方要求一致
  2. 配 CAN 设备权限与 udev 规则（固定设备名，避免 `/dev/ttyACM*` 漂移）→ 结果：不用 `sudo` 也能连上
  3. 跑官方示例脚本读角度 → 结果：终端打印出关节角度
- 验收判据：设备列表出现目标设备且状态正常，连续读 10 次不掉线
- 失败兜底：权限/驱动问题 → 按 `04-验收与展示.md` 排查顺序逐条查；虚拟机问题 → 换物理机，不要在虚拟机上继续折腾
- ⚠️ 安全：—

### 卡 M3-2：一键演示
- 目标：全套动作一次跑通并录屏。
- 物料：上位机 + 已配好的机械臂 + 相机/手机（录屏）
- 三档分工：L1 当解说员｜L2 点击启动并观察｜L3 独立执行整个流程
- 步骤：按 `04-验收与展示.md` 第 3 节的演示脚本执行一遍 → 结果：录屏文件
- 验收判据：连续 2 次成功即可记通过（不追求 10 次 10 中）
- 失败兜底：偶发失败 → 记录现象、降低速度/幅度重试；连续失败 → 回查终端电阻与电源余量

## M4 自主创作

目标：孩子提出并实现一个小改动，形成"这是我改的"归属感。

### 卡 M4-1：改一个参数
- 目标：改动前后有可比较的差异。
- 物料：上位机 + 机械臂 + 记录表
- 三档分工：L1 选"改哪个、变大还是变小"｜L2 一起改并观察｜L3 独立改并解释原理
- 步骤：记录原始值（角度/速度）→ 改 → 对比 → 结果：对比记录（数字 + 照片/视频）
- 验收判据：孩子能说出"改了什么、为什么变了"
- 失败兜底：没变化 → 确认参数真的写进去了；变化太剧烈 → 改回一半再试

### 卡 M4-2：加一个功能 / 讲给别人听
- 目标：把作品讲清楚，成为"作者"。
- 建议选题（选一个，越具体越好）：让关节"走到 45° 停 2 秒再回来"／加一个"慢动作"模式／把两个动作连成一套小表演
- 三档分工：L1 说 3 句话介绍｜L2 演示 + 说 1 分钟｜L3 独立做 3 分钟讲解（按展示脚本）
- 验收判据：能回答"哪里最难、怎么解决的"
- 失败兜底：功能做不完 → 降级为"只把参数改得更夸张"，同样能展示
