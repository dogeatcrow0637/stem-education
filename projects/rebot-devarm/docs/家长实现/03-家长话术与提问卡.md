# 家长话术与提问卡（reBot-DevArm 开源六轴机械臂）

| 字段 | 值 |
|---|---|
| 适用版本 | 硬件 B601-DM v1.1（DC 24V） |
| 最后更新 | 2026-10-20 |
| 前置条件 | 与 `02-里程碑与任务卡.md` 配套使用 |

> 目标：家长不讲课，只提问。孩子说出来，才算学会。每张卡至少问一次"为什么"。

## 1. 各阶段引导提问（每个里程碑选 3 个问）

| 里程碑 | 提问 |
|---|---|
| M0 定稿与采购 | 1）"我们要做的这个东西，你见过真的吗？在哪见过？" 2）"你看这两套，哪个贵、差在哪？" 3）"第一批只买必须的，你猜哪些可以先不买？" |
| M1 底座装配与通电自检 | 1）"通电以后你看到了什么？" 2）"如果灯不亮，可能是哪三个原因？" 3）"为什么上电的时候要离远一点？" |
| M2 一个关节能动 | 1）"刚才是谁让这个关节动的？" 2）"改成 60° 会发生什么？先猜再试。" 3）"它动的时候有什么声音？说明什么？" |
| M3 上位机完整链路 | 1）"命令从哪出发、经过谁、最后到哪里？" 2）"如果电脑认识不到它，先查什么？" 3）"哪一步最容易出错？" |
| M4 自主创作 | 1）"你想让它多一个什么本事？" 2）"改哪里最小、最容易成功？" 3）"怎么证明你的改动有效？" |

## 2. 孩子常问的"为什么"与答法

| 孩子的问法 | 一句话答法 |
|---|---|
| 为什么不能直接用手掰？ | "掰它它不听指挥。它要自己知道'我转到几度了'，才叫会干活。" |
| 为什么插反了会坏？ | "电像水，倒着流会把里面的零件冲坏。所以插之前要看颜色对颜色。" |
| 为什么要先装这个再装那个？ | "后面装上去就挡住螺丝了，就像先穿袜子再穿鞋。" |
| 为什么它有时候抖？ | "它使劲太大了，像骑车把龙头抓太紧。" |
| 为什么非要对着电脑？ | "电脑是它的教练，教练喊口令它才做动作。" |
| 为什么它断电会掉下来？ | "因为它的关节里没有刹车。自行车没捏闸，坡上就会溜。" |
| 为什么螺丝要数着规格装？ | "它们长得太像了，装错了就像给小孩穿大人的鞋，会把鞋子撑坏。" |

## 3. 本项目术语生活类比表

（每个术语首现处必须能对上；详见 skill 的儿童适配参考）

| 术语 | 生活类比 | 一句话解释 |
|---|---|---|
| 电压 / 电流 | 水压 / 水流 | 电压是"推得多用力"，电流是"流过去多少" |
| 关节电机 | 人的关节 + 肌肉 | 每个关节里装一个电动的"肌肉"，它转多少度，手臂就摆多少度 |
| 自由度 | 能做几个动作 | 六轴就是"能弯六个地方"，第七个专门开合夹爪 |
| CAN 总线 | 一根对讲机总线 | 七颗电机共用两根信号线，靠不同"号码"互相不打架 |
| 终端电阻（120Ω） | 水管末端的堵头 | 总线两端各堵一个，信号才不会反弹回响 |
| 使能 | 让电机"上电待命" | 没使能时电机松着随便推；使能后它才肯用力 |
| 零点标定 | 校秤 | 先定好"这里是 0 度"，后面才知道转到哪儿 |
| 上位机 | 遥控器的大脑 | 电脑负责发指令、显示状态，机械臂只负责动 |
| USB-CAN 适配器 | 翻译机 | 把电脑的 USB 语言翻译成电机听得懂的 CAN 语言 |
| 抱闸 | 自行车刹车 | 本项目**没有**这个零件，所以断电就会掉下来 |
| 扭力（kgf·cm） | 拧瓶盖的力气 | 电批力气调小一点，螺丝才不会被拧坏 |
| 填充率 | 面包的夹心 | 3D 打印件里面填多少料，填得多就更结实 |
| 遥操作 | 我动它就跟着动 | 用 VR 手柄带着机械臂做动作，同时把它录下来学 |
| 数据集 / 微调 | 练习册 / 改作业 | 把几十次示范录成练习册，再让模型照着改 |

> 常用对照可直接取用：电压/电流 = 水压/水流；固件 = 小脑；上位机 = 遥控器的大脑；CAN = 对讲机频道；标定 = 校秤；PID = 骑车扶龙头；终端电阻 = 水管末端堵头；堵转 = 顶住电风扇；填充率 = 面包夹心；抱闸 = 自行车刹车。

## 4. 收尾 20 秒复盘（每张卡结束必做）

1. "今天成功的标志是什么？"
2. "哪里最麻烦？"
3. "下次想改哪里？"

## 5. 关键话术（直接抄）

- 交付动作："你负责拧这四颗螺丝，我负责把电批力气调到安全档。送电那一步我一个人做，你在旁边看。"
- 卡住时："先只找一件事：这一步和上一张卡比，哪里不一样？"
- 失败时："失败很正常，工程师每天在试。记下现象，下一张卡第一件事就查它。"
- 拒绝代劳："我可以说怎么做，但手是你的——所以你才是这台机器的作者。"
- 升档："这张卡我不动手，你来做，我叫你才帮。"
- 遇到"好难"时："难的是这台机器本身，不是你的问题。我们把它切成更小的一块。"
