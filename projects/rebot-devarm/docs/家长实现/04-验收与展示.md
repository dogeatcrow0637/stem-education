## 2. 失败排查表（按顺序查，不要跳）

| 现象 | 最可能原因（按概率排序） | 先查什么 |
|---|---|---|
| 上电无任何反应 | 未供电 / 保险 / 开关 / 极性反接 | 万用表量电源输出 → 量板端电压 |
| 灯亮但不通信 | 线序错 / 设备未使能 / 串口被占用 | 换线 → 查设备列表 → 关掉占用程序 |
| 电脑识别不到设备 | 驱动 / 权限 / 线材（很多线只供电不传数据） | 换一根确认能传数据的线 → 查权限与 udev |
| 电机不动 | 未使能 / CAN ID 冲突 / 供电不足 / 线序错 | 逐项查：使能状态 → 扫描到的 ID 列表 → 电源 24V 是否到位 → CAN-H/CAN-L 是否接反 |
| 电机抖动或异响 | 参数过大 / 机械干涉 / 撞限位 | 降速度幅度 → 断电手动缓推看是否卡 → 确认运动范围内无障碍 |
| 通信偶发失败 | 缺 120Ω 终端电阻 / 未共地 / 线太长 / 靠近大电流线 | 查总线**两端**终端电阻 → 缩短线 → 确认共地 → 远离电源线 |
| 断电后臂体突然下落 | 本项目关节**无刹车**（已知设计，不是故障） | 调试全程用支撑座托住；收工前先降到最低姿态再断电 |
| 打印件装不上 | 公差 / 支撑残留 / 方向装反 | 清支撑 → 攻丝或铜螺母 → 核对镜像件 |
| 跑一会就断 | 过热保护 / 电源余量不足 / 接触不良 | 断电摸温度 → 查电源额定 vs 峰值 |

## 3. 作品展示脚本（让孩子讲 3 分钟）

1. **它是什么**（30 秒）："这是我做的六轴机械臂的第一个关节，我叫它转 30 度，它就转 30 度。"
2. **怎么做的**（60 秒）：按"先…然后…最后…"说三个最关键的步骤（先装底座和关节 → 然后给电机起名字、定零位 → 最后接上电脑发指令）。
3. **最难的地方**（45 秒）："最难的是＿＿＿＿，我试了＿＿次，最后用＿＿＿＿解决。"（由孩子现场填写真实经历，家长只负责计时）
4. **我还想改**（45 秒）："下一步我想让它＿＿＿＿。"（推荐引导：转得更快 / 连着转两个角度 / 再加一个关节）

家长只做两件事：计时、听完后问一个问题（"如果再来一次，你会先做什么？"）。
