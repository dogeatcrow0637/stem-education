# 01 · 项目简介

> 适用版本：B601-DM / B601-RS　|　最后更新：2026-10-19　|　前置条件：无（阅读类文档）

## 一、这是什么

reBot-DevArm 是 Seeed Studio 推出的**开源六轴桌面机械臂**（6+1 自由度，第 7 个电机驱动夹爪）。它不是一段演示代码，而是**一套从结构图纸到算法生态的完整硬件主仓**：硬件蓝图、BOM 清单、结构源文件、算法栈全部公开。

一句话概括三个特点：

```
真·开源  →  hardware/ 约 275 个文件（93 STEP + 10 STP），BOM 细到螺丝规格与采购链接
生态成熟 →  原生接入 NVIDIA Isaac Teleop + GR00T N1.7 + Hugging Face LeRobot
文档闭环 →  官方 Wiki 中文教程覆盖组装、校准、LeRobot 集成、GR00T 微调与 Jetson 部署
```

## 二、能做什么

| 能力 | 说明 |
|---|---|
| 从零复刻 | 按官方 BOM + STEP 打印/加工结构件，自行采购电机与线束，装出一台完整机械臂 |
| 遥操作采数 | 用 Meta Quest 3 在 Isaac Lab 中遥操作，采集演示数据 |
| 模仿学习 | 数据打包成标准 LeRobot 数据集，微调 GR00T N1.7（30 亿参数 VLA 基础模型） |
| 真机部署 | 训练好的策略部署回真机；官方另有 Jetson Thor 部署教程 |
| 视觉抓取 | 基于 YOLO/OBB + RGB-D 相机做抓取 Demo |
| 算法教学 | ROS1/2（含 MoveIt）、Pinocchio、Isaac Sim、Python SDK 均有适配 |

社区已验证的完整循环（NVIDIA 开发者倡导者 Asier Arranz 实测记录）：

> Quest 3 遥操作 → 采集 **40 条**演示数据 → 打包为 LeRobot 数据集 → 微调 GR00T N1.7 → **第二天早上机械臂即可自主完成任务**，整个学习循环在仿真中完成。

## 三、关键参数

| 参数 | B601-DM | B601-RS |
|---|---|---|
| 自由度 | 6+1 | 6+1 |
| 最大臂展 | 767 mm | 754 mm |
| 推荐负载 | 1.5 kg | 2.5 kg |
| 重复定位精度 | < 0.2 mm | < 0.2 mm |
| 供电 | DC 24V | DC 48V |
| 自重 | 约 4.5 kg | 约 6.7 kg |
| 关节电机 | 4× DM4310(V4) + 3× DM4340P(V4) | 4× RobStride RS00 + 3× RS06 |

> ⚠️ **没有刹车**：断电后关节自由下落，不可用于搬运不能掉落的物品。
> 社区对 `< 0.2 mm` 的重复定位精度持保留态度，建议以实测为准。

## 四、教学价值与目标人群

**适合谁**

- 已经接触过宇树、天工等平台，想在自己桌面上跑通「采数 → 训练 → 部署」全链路的开发者
- 高校/职校具身智能、机器人学课程：需要**可完整复现、社区活跃**的真机平台
- 学生创新项目：视觉抓取、轨迹规划、模仿学习课题

**教学目标（建议）**

1. 理解六轴串联机械臂的构型、DH 参数与正逆运动学
2. 会用 URDF + MoveIt / Pinocchio 做运动规划与仿真
3. 掌握遥操作数据采集 → 数据集规范（LeRobot）→ 策略微调 → 真机部署的完整流程
4. 具备「硬件装配 + 标定 + 软件联调」的工程实践能力

**前置知识**：Linux 基本操作、Python、线性代数与坐标变换基础；ROS 非必需但有帮助。
