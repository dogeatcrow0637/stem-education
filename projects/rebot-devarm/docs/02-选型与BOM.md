# 02 · 选型对比与 BOM

> 适用版本：B601-DM v1.1 / B601-RS　|　最后更新：2026-10-19
> 用途：决定买哪个版本、整包买还是散件自采、需要额外准备什么。

## 一、两个版本怎么选

| 参数 | B601-DM（达妙电机） | B601-RS（RobStride 电机） |
|---|---|---|
| 自由度 | 6+1 | 6+1 |
| 最大臂展 | 767 mm | 754 mm |
| 推荐负载 | 1.5 kg | 2.5 kg |
| 重复定位精度 | < 0.2 mm | < 0.2 mm |
| 供电 | **DC 24V** | **DC 48V** |
| 自重 | 约 4.5 kg | 约 6.7 kg |
| 关节电机 | 4× DM4310(V4) + 3× DM4340P(V4) | 4× RobStride RS00 + 3× RS06 |
| 第七电机 | 驱动夹爪 | 驱动夹爪 |

**建议**

| 场景 | 推荐 | 理由 |
|---|---|---|
| 教学工位、预算敏感、实验室只有 24V 电源 | B601-DM | 24V 供电更安全、电源易得；自重轻，搬运与固定方便 |
| 需要更大负载 / 更接近工业级 | B601-RS | 负载 2.5 kg、48V 供电，电机能力更强 |
| 只做算法与 VLA 验证 | B601-DM | 官方 DM 版教程最全（LeRobot 中文教程、GR00T 微调教程均以 DM 版为例） |

> ⚠️ **两版都没有刹车**。断电即自由下落，装配和调试阶段务必先做机械支撑。

## 二、五种套件方案

Seeed 提供从“只有电机”到“装好的成品”的梯度方案，按需选择：

| 套件 | 包含 | 适合谁 |
|---|---|---|
| Arm Body Motor Kit | 仅电机 + 线束 | 已有结构件渠道、想自己加工的人 |
| Arm Body Structural Kit | 仅机械结构件 | 已有电机 |
| Gripper Complete Kit | 夹爪完整套件 | 给已有本体补齐夹爪 |
| Full Kit | 机械臂本体 + 夹爪完整套件 | **推荐起点**：一次配齐，少踩缺件坑 |
| Pre-assembled Robotic Arm | 完全组装好的成品 | 只想验证算法、不想动手装配 |

**套件不含**：电源适配器、C 型夹。Seeed 商店电源已下架，替代方案是搜索关键词 **`24V 4.5A XT30`**（DM 版）。

## 三、成本构成

| 类别 | 金额(CNY) | 说明 |
|---|---|---|
| 电机（7 颗） | 待填 | 见 `hardware/bom/` 明细 |
| 结构件 - 3D 打印 | ~350 | 官方文档参考均价，**仅为局部制造成本** |
| 结构件 - 金属加工 | ~1500 | 同上，金属件数量多（30+ 件） |
| 线束与接插件 | 待填 | 官方出货版对线束做了定制优化 |
| 电源与夹具 | 待填 | 套件不含，需另购 24V 4.5A XT30 |
| 工具 | 待填 | 电批（扭力可调）、内六角、卡尺、CAN 调试工具 |
| **合计（散件自采口径）** | **约 6000** | 社区口径 |
| **官方套件口径** | **$1499** | 早鸟价，Pre-assembled 更贵 |

> ⚠️ 官方公布的打印件/金属件均价只是**加工费**；电机、线束、电源、轴承和工时都要另计，做预算时不要漏项。

## 四、BOM 与采购

- 明细清单：[`../hardware/bom/`](../hardware/bom/)（`bom_b601-dm_v1.1-draft.csv` 为草稿，**须与官方 `readme_zh.md` 逐项核对后再下单**）
- 官方 BOM 位置（DM 版）：`hardware/reBot_B601_DM/readme_zh.md`
- 官方 BOM 位置（RS 版）：`hardware/reBot_B601_RS/README.md`
- 官方 BOM 可精细到**每一颗螺丝的规格和采购链接**，并列出打印件与金属件的参考均价。

**采购注意**

1. 官方明确声明：**公布的 BOM 并非出货最终版本**（金属镭雕、3D 打印件替换、线束定制均有优化）——下单前先确认你买的是「散件」还是「套件」，两者件号可能不同。
2. 缺货时优先找**同规格替代**，并在 BOM 的 `替代型号` 列登记，避免改结构。
3. 标准件（螺丝、铜螺母、轴承）按 **+10% 备损** 采购，滑丝/丢失在装配中很常见。

## 五、打印与加工前必读

打印参数、材料选择、装配顺序见 [`../enclosure/print-notes.md`](../enclosure/print-notes.md)。
金属件与打印件**分开走两条供应链**（CNC/钣金 vs 3D 打印），排期差异大，建议先下金属件。
