# 04 · 软件生态与 VLA 链路

> 适用版本：B601-DM（官方教程主要以此版本为例）　|　最后更新：2026-10-19
> 前置条件：Ubuntu 物理机（**不要用虚拟机**）

## 一、技术栈全景

```
┌───────────────────────────── 采数（真机） ─────────────────────────────┐
│  Meta Quest 3  ──Isaac Lab 遥操作──▶  reBot DevArm (7 自由度)          │
│                                        采集 40 条演示数据               │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌──────────────────── 数据（标准格式） ───────────────────────────────────┐
│  Hugging Face LeRobot 数据集                                            │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌──────────────────── 训练（仿真中完成） ─────────────────────────────────┐
│  NVIDIA GR00T N1.7（3B 参数，Apache 2.0 开源 VLA 基础模型）微调          │
└───────────────────────────────────┬────────────────────────────────────┘
                                    ▼
┌──────────────────── 部署（真机） ───────────────────────────────────────┐
│  真机自主执行  ／  进阶：NVIDIA Jetson Thor 平台部署                     │
└─────────────────────────────────────────────────────────────────────────┘
```

时间线：2026 年 7 月，NVIDIA 将 **Isaac Teleop**（遥操作数据采集工具）与 **GR00T N1.7** 原生集成进 Hugging Face **LeRobot**；reBot DevArm（7 自由度）适配了这套技术栈的每一层，成为新范式的**首批物理硬件平台之一**。

## 五、环境要求（先记住三条）

1. **Ubuntu 物理机**，官方明确不建议虚拟机。
2. 需要 USB-CAN 适配器与稳定的 24V（DM）/ 48V（RS）供电。
3. 采数阶段需要一个 Quest 3 头显（遥操作）。

> 具体版本号（Ubuntu 版本、LeRobot 版本、CUDA/驱动版本）以官方 Wiki 当日文档为准，落地后请在本文件补充**实测通过**的版本组合，避免后续同学踩版本坑。
