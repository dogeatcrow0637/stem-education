# 知识卡 · 3D 打印填充率（代号贴纸：K11-夹心）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
两个打印件外表一模一样，一个能捏得动，一个硬得像块石头。

```
┌──────────────────────────────────┐
│   画两个方块：里面一个空的、一个满的 ✏️│
└──────────────────────────────────┘
```

### ② 先猜
3D 打印的零件里面是实心的吗？

- A. 是实心的，全是塑料
- B. 里面是一格一格的"网"

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 拿两片面包（或两块饼干），一片只放一层夹心，一片夹得厚厚的
2. 两只手分别捏一下
3. 你看到：**夹心多的那片捏不动**——3D 打印件里的"夹心"就是它里面的网格

### ④ 它叫什么

- 外号：面包的夹心
- 正式名：**填充率（infill）**
- 一句话：里面填多少料，填得多就更结实

### ⑤ 还在哪见过

- 家里：羽绒服填充越多越保暖；沙发里塞的棉越多越硬
- 外面：桥梁用的是空心钢箱梁（像蜂窝）；飞机机身也是"外面结实、里面空心"

## 背面（给家长看）

| 项 | 内容 |
|---|---|
| 这张卡想让孩子明白 | 承力打印件要选对材料和填充率，不是"打出来就行" |
| ② 的引导 | 等 10 秒再给线索；答错就说"那我们掰开看看" |
| ③ 的预期结果 | 孩子应说出"夹心多的更硬"；看不出差别时先查：两片厚度是不是差太多 |
| 适合档位 | L1 捏面包 / L2 在切片软件里把填充率从 15% 改成 40% 再对比 / L3 解释为什么承力件用 PETG 而不是 PLA |
| 常见误解 | 孩子容易以为"打印件都是脆的"；实际承力件用 **PETG / 尼龙 + 填充 ≥40%** 会明显更耐用 |
