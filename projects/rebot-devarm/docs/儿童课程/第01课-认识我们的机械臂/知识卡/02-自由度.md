# 知识卡 · 自由度（代号贴纸：K02-自由度）

## 正面（给孩子看）

### ① 看到什么
机械臂能弯七个地方，但只有"七个"，不是想弯哪就弯哪。

```
┌──────────────────────────────────┐
│   数一数并用数字标出每个关节 ✏️    │
└──────────────────────────────────┘
```

### ② 先猜
人的手臂能弯几个地方？（肩、肘、腕、手指…）

- A. 比机械臂多得多
- B. 和机械臂一样多

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 伸出自己的一只手，从肩膀开始往下数：肩 1 个、肘 1 个、手腕 1 个
2. 再数手指：一根手指就有 3 个弯的地方
3. 你看到：一只手就超过 7 个——**所以人能做的事，机械臂要"慢慢学"**

### ④ 它叫什么

- 外号：能弯几个地方
- 正式名：**自由度**
- 一句话：一台机器能独立动的"弯"有几个，就叫几个自由度

### ⑤ 还在哪见过

- 家里：门的合页只有 1 个自由度；筷子夹菜要用到好几个
- 外面：挖掘机的大臂小臂铲斗；起重机也能数出好几段
