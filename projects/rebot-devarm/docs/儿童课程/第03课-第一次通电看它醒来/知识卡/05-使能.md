# 知识卡 · 使能（代号贴纸：K05-使能）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
同一颗电机，通上电它还是松的、能推动；只有"使能"以后它才突然变得很硬。

```
┌──────────────────────────────────┐
│   画两个小人：一个松、一个绷紧 ✏️  │
└──────────────────────────────────┘
```

### ② 先猜
通了电，它就会马上用力吗？

- A. 会，有电就有劲
- B. 不会，还要等一句"口令"

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 让孩子站直，全身放松，家长轻轻推他肩膀 → 他一推就晃
2. 让孩子用力"绷住"身体，家长再推同样一下 → 他站稳了
3. 你看到：**同一个身体，绷住之前和之后完全不一样**

### ④ 它叫什么

- 外号：醒来 / 站好
- 正式名：**使能**
- 一句话：给电只是"醒了"，还要喊一句"站好"它才肯使劲

### ⑤ 还在哪见过

- 家里：电视通电了但不按开机键就是黑的；玩具车装了电池还要拨开关
- 外面：保安站着但没"站岗"时很随意；足球守门员听到哨声才扑

| 项 | 内容 |
|---|---|
| 这张卡想让孩子明白 | "通电"和"使能"是两件事，电机不动常常是没使能而不是没电 |

| ③ 的预期结果 | 孩子应说出"绷紧之后站得稳"；不成功时先查：是不是推得太用力（要轻轻推同样的力） |
