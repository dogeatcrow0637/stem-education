# 知识卡 · 电压与电流（代号贴纸：K10-水压）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
这根电源线要接 24V——数字写错或者接反了，机器会坏。

```
┌──────────────────────────────────┐
│   画两个水龙头：一个细流一个喷 ✏️ │
└──────────────────────────────────┘
```

### ② 先猜
"24V"说的是"推得多用力"，还是"流过去多少"？

- A. 推得多用力
- B. 流过去多少

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 打开水龙头，只开一点点 → 水流很小（水压不变）
2. 再开大一点 → 水流变大
3. 你看到：**水压是"推的劲儿"，水流是"过去了多少"**——电压像水压，电流像水流

### ④ 它叫什么

- 外号：水压 / 水流
- 正式名：**电压 / 电流**
- 一句话：电压是推得多用力，电流是流过去多少

### ⑤ 还在哪见过

- 家里：水管爆了是因为水压太大；电闸跳了是因为电流太大
- 外面：消防水管又粗又猛；浇花的管子细细的
