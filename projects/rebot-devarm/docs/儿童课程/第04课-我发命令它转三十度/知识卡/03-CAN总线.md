# 知识卡 · CAN 总线（代号贴纸：K03-总线）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
七颗电机只用了两根细细的信号线，它们还能各自知道该听谁的话。

```
┌──────────────────────────────────┐
│   画一根线把 7 个电机连起来 ✏️     │
└──────────────────────────────────┘
```

### ② 先猜
如果七个人同时在一根电话线上说话，会乱吗？

- A. 会乱成一团
- B. 只要每个人有"编号"，就不乱

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 全家人站成一排，用一根绳子（或手拉手）串起来当"总线"
2. 每人先领一个号码，从 1 号排到 7 号
3. 你说"3 号转一下" → 只有 3 号动。你看到：**喊号码，就只有一个听**

### ④ 它叫什么

- 外号：一根对讲机总线
- 正式名：**CAN 总线**
- 一句话：大家共用两根线，靠"编号"决定谁回话

### ⑤ 还在哪见过

- 家里：电视遥控器按哪个键，只有电视听（不是所有电器一起动）
- 外面：教室里老师点名字回答问题；公交报站只叫一站
