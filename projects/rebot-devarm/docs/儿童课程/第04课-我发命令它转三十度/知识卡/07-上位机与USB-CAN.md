# 知识卡 · 上位机与 USB-CAN（代号贴纸：K07-翻译机）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
电脑的插口和机械臂的线，长得完全不一样，中间必须夹着一个小盒子。

```
┌──────────────────────────────────┐
│   画：电脑 → 小盒子 → 机械臂 ✏️    │
└──────────────────────────────────┘
```

### ② 先猜
为什么不能把线直接插进电脑？

- A. 它们说的"语言"不一样
- B. 因为线太短了

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 找出家里三个"要转换头"的东西：手机充电线、耳机转接头、HDMI 转接线
2. 让孩子说说：为什么不能直接插
3. 你看到：**插口形状不同 = 说的话不一样，需要"翻译"**

### ④ 它叫什么

- 外号：翻译机 / 大脑
- 正式名：**USB-CAN 适配器**（和它背后的"上位机"）
- 一句话：电脑说"电脑话"，电机听"总线话"，中间要有人翻译

### ⑤ 还在哪见过

- 家里：电视盒子把网络变成画面；充电头把 220V 变成手机要的电压
- 外面：机场的翻译柜台；对讲机和电话不能直接通话
