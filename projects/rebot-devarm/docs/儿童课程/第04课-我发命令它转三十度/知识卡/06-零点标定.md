## 正面（给孩子看）

### ① 看到什么
同样的角度数字，机器摆出来的姿势却每次不一样。

```
┌──────────────────────────────────┐
│   画一把尺子，并在 0 的位置画线 ✏️ │
└──────────────────────────────────┘
```

### ② 先猜
"转到 30 度"这句话，机器怎么知道 0 度在哪？

- A. 它天生就知道
- B. 要我们先告诉它"这里是 0 度"

### ③ 动手验证（家里就能做，5 分钟）

1. 用家里的体重秤（或厨房秤）：放一个空碗，看指针是不是 0
2. 如果指针不在 0，先按住"归零/去皮"按钮
3. 现在再放东西 → 数字才准。你看到：**先"归零"，后面的数才有意义**

### ④ 它叫什么

- 外号：校秤
- 正式名：**零点标定**
- 一句话：先告诉机器"这里是开始的地方"，它才数得对

### ⑤ 还在哪见过

- 家里：体重秤上秤前先归零；量身高时脚要顶住那条线
- 外面：跑步比赛都从同一条起跑线出发；地图上的"北"要先规定好
