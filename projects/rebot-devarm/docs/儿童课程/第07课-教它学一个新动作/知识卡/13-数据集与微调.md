## 正面（给孩子看）

### ① 看到什么
机器做了几十遍同一个动作，被"录"了下来；第二天早上，它自己就会做了。

```

│   画一叠练习册 + 一个打勾 ✏️      │

```

### ② 先猜
"看一遍"和"练几十遍"，哪个学得会？

- A. 看一遍就够
- B. 要练很多遍

### ③ 动手验证（家里就能做，5 分钟）

1. 让孩子连续 5 次把同一个小球投进纸篓，每次记下"进了还是没进"
2. 第 6 次之前，问他："前 5 次里，哪一次最好？为什么？"
3. 你看到：**记录下来的次数越多，越知道怎么才能进**——那一串记录就是"数据集"

### ④ 它叫什么

- 外号：练习册 / 改作业
- 正式名：**数据集 / 微调**
- 一句话：把几十次示范收成一叠练习册，再让模型照着改

- 家里：错题本；跳绳打卡记录本
- 外面：运动员看比赛录像复盘；AI 下棋也是靠几百万局棋谱练出来的

## 背面（给家长看）

| 项 | 内容 |
|---|---|
| 这张卡想让孩子明白 | "记录 → 整理成册 → 照着改进"是机器学习的三个动作 |
| ② 的引导 | 等 10 秒再给线索；答错就说"那我们数一数这 5 次" |
| ③ 的预期结果 | 孩子应说出"次数多才摸出门道"；不成功时先查：是不是只投了 1 次（要有多次对比） |
| 适合档位 | L1 记录次数 / L2 画出"哪次最好"的对比 / L3 解释"练习册质量差会怎样" |
| 常见误解 | 孩子容易以为"数据越多越好"；实际**示范做得乱的几十条，不如做得整齐的十几条** |
| 延伸追问 | 1）为什么示范要"做得一样"才好？ 2）这叠练习册能寄给别人的机器人用吗？ 3）如果环境变了，练好的本事还有用吗？ |
| 线索记录 | 日期＿＿＿ ／ 现象＿＿＿＿＿＿ ／ 结论＿＿＿＿＿＿（由孩子手写） |
