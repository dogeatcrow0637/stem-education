## 正面（给孩子看）

### ① 看到什么
大人戴上一个"眼镜"，手在空气里一抓，机械臂就跟着抓了一下。

```
┌──────────────────────────────────┐
│   画：人的手 → 虚线 → 机械爪 ✏️   │
└──────────────────────────────────┘
```

### ② 先猜
机械臂怎么会知道该怎么做这个动作？

- A. 有人带着它做了很多遍，它照着学
- B. 它自己想出来的

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 家长站在孩子身后，握住孩子的手，带着他写一个"8"字
2. 松开手，让孩子自己写一个
3. 你看到：**被带着做了几遍之后，自己就会了**——机器也是这么学的

### ④ 它叫什么

- 外号：我动它就跟着动
- 正式名：**遥操作**
- 一句话：人带着机器做动作，机器一边做一边把它记下来

### ⑤ 还在哪见过

- 家里：爸爸扶着自行车后座教骑车；写字帖上描红
- 外面：医生做手术时用机械手（医生动手，机械手跟着动）；深海机器人

## 背面（给家长看）

| 项 | 内容 |
|---|---|
| 这张卡想让孩子明白 | 机器的"技能"来自人类示范，不是凭空长出来的 |
| ② 的引导 | 等 10 秒再给线索；答错就说"那我们俩试试" |
| ③ 的预期结果 | 孩子应说出"被带着做几遍就会了"；不成功时先查：是不是握得太紧，孩子没有自己使劲 |
| 适合档位 | L1 被带着写 / L2 说出"这叫示教" / L3 解释为什么"只做一遍不够，要做几十遍" |
| 常见误解 | 孩子容易以为机器"看一眼就会"；官方社区实测是**采集约 40 条演示数据**才让模型学会一个任务 |
