# host · reBot-DevArm 上位机

> 状态：待开发。目标是把「连臂 → 看到状态 → 能动 → 能示教」做成一个教学友好的图形界面。

## 计划功能

| 模块 | 功能 | 优先级 |
|---|---|---|
| 连接管理 | 选择 CAN 适配器、扫描电机、显示在线状态与固件/版本 | P0 |
| 关节面板 | 7 个关节角度实时显示、单关节点动、限速/限幅 | P0 |
| 急停与安全 | 一键断使能/急停提示；⚠️ 无刹车，界面必须提示支撑 | P0 |
| 标定 | 零位标定向导、参数保存与回读 | P1 |
| 示教回放 | 记录轨迹、回放、导出数据集 | P1 |
| 夹爪控制 | 开合位置与力控制 | P1 |
| 视觉联动 | 相机预览 + 抓取点显示 | P2 |
