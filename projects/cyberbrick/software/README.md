## 技术栈基线

| 项 | 选择 | 备注 |
|---|---|---|
| 上位机（主线） | **CyberBrick App**（手机 / PC） | MVP 全程图形化，**不写代码** |
| 配置通道 | 蓝牙 | 短距离，用来配置与同步 |
| 遥控通道 | 2.4G 主从机 | 用来实际开车 |
| 编程（进阶） | MicroPython（ESP32-C3） | 官方推荐 Thonny（轻量）或 VS Code |
| 连接方式 | Type-C 数据线（**不是纯充电线**） | 进阶线才需要 |

## 开发顺序建议

1. **主线（MVP）**：装 App → 配对两块核心板 → 绑定 2.4G 主从 → 同步一个下载来的遥控工程 → 开车。
   说明见 [`../docs/04-软件环境.md`](../docs/04-软件环境.md)。
2. **进阶线**：装 Thonny → 连 Type-C → 进 REPL 打印一行字 → 改 `boot.py` 里一个数字 → 复位看变化。
3. 先能"看见设备"，再谈自定义程序。

> ⚠️ 关键概念：`boot.py` 是**上电跑一遍**就停，不是死循环。要让车持续响应，需在主循环或定时器里做。
