## 排错顺序（找不到串口时）

1. 换一根**确认能传数据**的 Type-C 数据线（很多线只供电不传数据）
2. 确认核心板已上电、Type-C 插到底
3. 装 CH34x / CP210x 驱动后重试
4. 换一个 USB 口（避开扩展坞）
