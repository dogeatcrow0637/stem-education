## 目标形态（草案）

```python
# boot.py —— 核心板上电后自动执行，执行完即停止（不是死循环）
import time
from machine import Pin

led = Pin(2, Pin.OUT)          # 引脚号以官方文档为准，待确认

for i in range(5):             # 闪 5 次，改这个数字就能改次数
    led.value(1)
    time.sleep(0.2)
    led.value(0)
    time.sleep(0.2)
```

## 设计原则

1. **不隐藏状态**：灯效、串口打印都要显式，教学场景需要"看得见发生了什么"。
2. **安全默认值**：默认低速度、默认限制运动范围；改参数先说清楚改了什么。
3. **兼容矩阵**：写清 `代码 ↔ 固件版本 ↔ 硬件版本` 的对应关系。
4. **单变量实验**：一次只改一个数字，方便对照前后差异。
