# host · 拓竹 CyberBrick 上位机（App）

> 状态：使用官方 **CyberBrick App**。本项目不自己开发上位机，只记录**操作路径与排错**。

## 这个 App 能做什么

| 模块 | 功能 | 优先级 |
|---|---|---|
| 设备管理 | 蓝牙搜索、连接两块核心板、显示灯语状态 | P0 |
| 遥控链路 | 把车与遥控器绑成 2.4G 主从 | P0 |
| 通道配置 | 摇杆/开关 → 电机/舵机的绑定、方向、行程 | P0 |
| 参数调整 | 限速、转向微调、混控、灯效 | P0 |
| 工程同步 | 下载模型页提供的遥控配置（JSON）并同步到板子 | P1 |
| 固件升级 | 蓝牙升级（白灯闪烁期间**不能断电**） | P1 |

## 获取方式

| 平台 | 入口 |
|---|---|
| 手机 | 应用商店搜 CyberBrick |
| 手机 / PC | 官方下载页 `https://bambulab.com/en/download/cyberbrick-apps`（访问 2026-10-20） |
