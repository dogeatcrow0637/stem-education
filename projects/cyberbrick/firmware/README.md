# firmware · 拓竹 CyberBrick

> 状态：资料整理。本项目的"固件"层与传统 MCU 项目不同——**核心板出厂已烧录可玩**，升级走 **App 内蓝牙**，家长**不需要**装工具链。

## 本项目的固件范围

| 子目录（规划） | 内容 | 状态 |
|---|---|---|
| `factory/` | 出厂固件的版本记录与来源（不存二进制，只登记版本） | 待补 |
| `boot-py/` | 自写 MicroPython 项目（`boot.py` 为入口） | 待补，先看 [`../software/`](../software/) |
| `tools/` | 升级说明与灯语对照 | 见 [`../docs/04-软件环境.md`](../docs/04-软件环境.md) |

## 需要搞清的三件事（推进时填写）

1. **出厂固件版本**：核心板到货版本号、是否有更新提示（官方 App 会提示）。
2. **升级方式**：**App 内蓝牙升级**；官方声明只支持官方工具，**第三方工具刷写可能不可逆损坏且不在保修内**。
3. **自定义程序**：`boot.py` 入口、源码总大小 ≤800 kB、上传 MakerWorld 后压缩体积 ≤250 kB。

## 灯语速查（升级相关，摘自官方 Wiki《模块列表》）

| 灯语 | 含义 | 该做什么 |
|---|---|---|
| 白灯常亮 | 等待升级 | 保持供电，开始升级 |
| 白灯快速闪烁 | **升级中** | **绝不能断电** |
| 红灯常亮 | 固件升级错误 | 用官方工具重做一次升级 |
| 绿灯 2Hz 闪烁 | 正在发送/更新配置 | 别断电，等它结束 |

## 约定

- **不提交厂商固件二进制与工具包**（体积大、含许可限制），只登记来源与版本。
- 自写的 MicroPython 改动放 `boot-py/`，改动记录写进 [`../CHANGELOG.md`](../CHANGELOG.md)。
- ⚠️ 任何刷写操作前先确认供电稳定；白灯闪烁期间断电有变砖风险。
