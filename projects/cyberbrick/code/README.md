# code · 拓竹 CyberBrick 算法与实验

> 本项目**没有传统意义的算法层**。它的"代码"分两层：App 图形化配置（主线）+ MicroPython（进阶）。本目录放的是**教学实验**，不是产品算法。

| 子目录（规划） | 主题 | 来源 | 状态 |
|---|---|---|---|
| `app-config/` | 从 MakerWorld 下载的遥控配置（JSON）留档与改动记录 | 模型页 | 待开始 |
| `boot-py/` | 自写 MicroPython 小项目（闪灯、读摇杆、简单逻辑） | 自研 | 待开始 |
| `notebooks/` | 数据记录与对比（速度档位对照表等） | 自研 | 可选 |

## 教学实验建议（可直接作为课后任务）

1. **单变量对照**：只改限速一个值，跑三次记录"跑完一圈用时"，看趋势。
2. **方向纠错**：故意把某个通道反向，让孩子找出"哪两根线/哪个设置"要改。
3. **灯效编程**（进阶）：在 `boot.py` 里改闪灯次数与间隔，做出自己的灯光节奏。
4. **换壳复用**：把同一套电子件换到另一个模型上，记录"哪些件要重新打印、哪些直接复用"。

## 约定

- 每个子目录一个 `README.md`：目的、输入、输出、运行方式、依赖。
- 配置 JSON 与代码要写清**对应哪个模型、哪个版本**。
- 实验必须留下结论（哪个参数有效、现象是什么），否则代码无法转化为教学素材。
- 引用官方代码注明来源与版本；厂商固件二进制不入库。
