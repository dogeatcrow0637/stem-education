# 拓竹 CyberBrick 模块化遥控套件

> 一句话定位：**免焊接、免写代码**就能让小学生做出会跑的遥控车——硬件是插的，外壳是 3D 打印的，编程从 App 里拖滑块开始，是"机械臂（01）之前的第二站"：比循迹小车（02）更好玩，门槛却一样低。

## 这是什么

拓竹（Bambu Lab / MakerWorld）推出的模块化智能玩具套件：一块 **ESP32-C3 核心板 XA003** + 两块功能底板（发射端 / 接收端）+ 一堆**免焊接模块**（摇杆、开关、按钮、舵机、直流电机、灯珠、轮胎、齿轮）。所有结构件都是 **3D 打印件**，模型从 MakerWorld 免费下载；官方宣称"开放设计规范 + 参考设计"，模型库里的遥控车、坦克、挖掘机、机械臂都能用同一套电子件来回换。

和循迹小车相比：不用焊接、不用买特殊工具，**但它需要一台 3D 打印机**（或找代打）。和机械臂相比：第一次"它动了"只要装车 + App 配对，不需要 CAN 总线、零点标定、上位机环境。

教学价值：它把"结构（打印件）+ 电子（插线）+ 软件（App 拖滑块 / MicroPython）"三段拆得非常干净，孩子每一段都有看得见的结果；换壳即可复用到下一个模型，边际成本只有耗材钱。

## 能力与参数

> 参数来源：Bambu Lab Wiki《CyberBrick 技术手册 / 模块列表》与官方商店产品页，**访问日期 2026-10-20**；未实测项标 `待验证`。

| 参数 | 值 |
|---|---|
| 核心板 | CyberBrick 核心板 **XA003**，ESP32-C3，MicroPython，带蓝牙 + WiFi |
| 板载接口 | Type-C（5V 输入 / 编程烧录）、邮票孔焊盘、复位键、用户可编程键、排针接底板 |
| 供电 | 核心板电池输入 3.7–12.6V；官方电池 **14500 7.4V 800mAh 锂电** 或 **3×AAA 电池盒**（均 XH2.54 接口） |
| 无线 | 蓝牙（App 配置）+ 2.4G 主从机（遥控链路）；官方商店规格写"遥控距离 up to 100 m"，而核心板规格页写"遥控距离 4 m" —— **两个来源冲突，待实测** |
| 控制模式 | 一对一 / 一对多 |
| 发射底板 XA005 | 6 路模拟量通道（L1–L3 / R1–R3，SH1.0 3P）+ 4 路数字量通道（K1–K4，SH1.0 2P）；输入 4.5–12.6V；工作电流 65mA |
| 接收底板 XA004 | 2 路有刷电机 M1/M2（SH1.0 2P，**正反转 + PWM 调速**）+ 2 路 LED 口 D1/D2（WS2812 协议）+ 4 路舵机 S1–S4（3-Pin：1 信号 / 2 5V / 3 GND） |
| 执行器 | 030 直流有刷马达、N20 直流减速电机、9g 180° 角度舵机、9g 360° 连续旋转舵机（均带离合保护）、电推杆 B-PG003 |
| 结构件 | Ø33.7×13.85mm 橡胶轮胎、塑料差速器齿轮包、1:48 单轴减速齿轮包、磁铁、压簧、尼龙绳、M2.5×6 BHCS 螺丝 |
| 编程 | **双层**：① App 图形化配置（多通道比例控制、通道绑定、混控、简单事件）；② MicroPython 自定义项目（入口 `boot.py`，源码 ≤800 kB） |
| 开发工具 | 官方推荐 Thonny（轻量）或 VS Code（功能全），任何支持 MicroPython + 串口的 IDE 均可（据官方商店 FAQ） |
| 结构件来源 | MakerWorld 模型库（免费下载 STL/3MF + 组装 PDF + 物料清单），模型页带 CyberBrick 徽章 |
| 安全等级 | 官方标注**面向 14 岁以上**；14 岁以下必须成人全程看护；含小零件，3 岁以下禁用 |

## 已知问题与踩坑

> 以下为**官方明确写出**与**社区反馈**两类，来源见 `docs/99-参考资源.md`；未见明确来源的一律不写。

| 现象 | 原因 | 规避方式 |
|---|---|---|
| 充电时发烫 / 损坏 | 用手机快充头（9V/12V）给 7.4V 锂电充电 | **只允许 5V 1–2A**（原装充电器或电脑 USB 口）；不要边充边玩，不要无人看管充电 |
| 活动件一掰就断 | 黑色活动件用了层间强度差的耗材 | 活动件用 **PLA Basic / PETG**，不用 PLA Lite；不要随意改官方推荐打印参数 |
| 打印件装不上 / 太松 | 缩放或公差不对 | 按模型页给出的配置打印，不要自行缩放；公差问题优先检查是否用了别人的参数配置 |
| 电机线接反 → 车不动/乱转 | M1/M2 极性 | 断电后对调同一电机的两根线 |
| 遥控没反应 | 主从机没绑上 | 看核心板**灯语**：黄色常亮才是 2.4G 主从已连（见 `docs/03-组装与调试.md` 灯语表） |
| 官方舵机不够用 / 螺丝不够长 | 社区常另购 MG90S 等第三方舵机，但套件螺丝长度不匹配 | 先用官方件把 MVP 跑通；要换第三方舵机时同时准备对应螺丝（社区经验，`待验证`） |
