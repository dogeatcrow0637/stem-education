## 计划归档的素材（推进时补）

- [ ] 到货开箱照片（套件全家福）

- [ ] 打印完成照片（去支撑前后对比）

## 命名与版本

- `wiring_<功能>_v<版本>.png`、`assembly_stepNN.png`、`app_<功能>.png`
- 素材文件名或随附说明中**标明对应的硬件版本与模型名**，改版后旧图容易误导。
- 课件配图随课分发在各课的 [`../docs/儿童课程/第NN课-课题/图/`](../docs/儿童课程/README.md)，实拍照片覆盖该课 `图/` 下的同名文件即可，不用改课件 md。
