## 1. 打印材料与参数

| 零件 | 材料 | 层高 | 壁厚(圈) | 填充 | 支撑 | 备注 |
|---|---|---|---|---|---|---|
| 车身 / 外壳 | PLA Basic | 按模型页推荐 | 按模型页推荐 | 按模型页推荐 | 按需 | 外观件，可换配色 |
| 活动件（关节/卡扣） | **PLA Basic 或 PETG** | 同上 | 同上 | 同上 | 按需 | **禁止 PLA Lite**（层间强度差，易断） |
| 齿轮/受力件 | PETG（可选） | 同上 | 同上 | 同上 | 按需 | 韧性更好 |

**通用建议**

- **不要自行缩放模型、不要自换参数**：模型页给的是经过验证的配置，改了容易装配不上。
- 活动件断裂几乎都是耗材问题：换成 PLA Basic / PETG 重打该件即可。
- 打印前确认耗材干燥；受潮会导致拉丝、强度下降。

## 4. 装配顺序（要点）

> 具体步骤以模型页的组装 PDF 为准；此处只记**顺序要点与卡点**。

1. 剪支撑、去毛刺，**先试插轴孔与齿轮**（能手动转再往下）
2. 装 030 电机 + 差速器齿轮包，涂薄薄一层润滑脂
3. **转向舵机先通电对中**，再装摇臂（顺序颠倒会把行程顶死）
4. 装接收底板 + 核心板（灰色双排槽，**插到底**）
5. 插 M1/M2、舵机 S1–S4、灯 D1/D2、电源开关、电池
6. **不接电池，先对端子表逐条核对**（返工率最高的一步）
7. 上电看灯语 → App 配对 → 首次行驶

**完成判断标准**：手推一侧车轮另一侧反向转且无卡涩；核心板插到底；所有插头听到"卡"声。

## 5. 易错点

| 现象 | 原因 | 规避 |
|---|---|---|
| 活动件一掰就断 | 用了 PLA Lite | 换 PLA Basic / PETG 重打该件 |
| 打印件装不上 / 太松 | 缩放或公差不对 | 按模型页推荐配置，不自行缩放 |
| 齿轮压太紧、转动发涩 | 装配用力过大 / 有毛刺 | 清毛刺；压到位即可，不要硬砸 |
| 舵机嗡嗡叫、发烫 | 先装摇臂后通电，行程顶死 | 先对中再装摇臂 |
| 车装好了跑不动 | 端子插错/插反 | 断电对端子表逐条核对，**以插口编号为准** |
