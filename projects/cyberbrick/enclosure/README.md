# enclosure · 拓竹 CyberBrick

> 状态：资料整理。本项目的结构件**全部是 3D 打印件**，模型来自 **MakerWorld**（免费下载 STL/3MF + 组装 PDF + BOM）。本仓库**不存放模型文件**，只登记来源与打印经验。

| 子目录 | 内容 | 当前状态 |
|---|---|---|
| `step/` | 官方 CAD / STEP（如需改件） | 待归档（官方 Solid Model zip 提供） |
| `stl/` | 可直接打印的网格文件 | 待归档（来自 MakerWorld 模型页） |
| [`print-notes.md`](print-notes.md) | 打印参数、选材、装配顺序与坑 | ✅ 已建 |

## 结构件构成

| 类别 | 说明 | 来源 |
|---|---|---|
| 车身 / 悬挂 / 传动外壳 | 打印件，按所选模型不同 | MakerWorld 对应模型页 |
| 车轮 | Ø33.7×13.85mm 橡胶轮胎（随套件） | 套件自带 |
| 齿轮 | 塑料差速器齿轮包 + 1:48 单轴减速齿轮包（随套件） | 套件自带 |
| 紧固 | M2.5×6 BHCS 螺丝 ×100 | 套件自带 |

## 打印规模参考（社区模型页公布值）

| 项 | 量级 |
|---|---|
| 盘数 | 2–4 盘 |
| 机器时间 | 约 **8–13 小时** |
| 耗材 | 1 kg PLA 足够一个车模 |

> ⚠️ 官方明确：套件**只含电子模块，不含 3D 打印件和工具**。

## 归档约定

- 不把 MakerWorld 的模型文件入库；只登记「模型页 URL + 作者 + 许可 + 打印配置来源」。
- 命名 `件名_版本_数量.stl`，左右对称件加 `_L` / `_R`。
- `.gcode` / `.3mf` 不入库，切片参数写进 [`print-notes.md`](print-notes.md) 以便复现。
- 大装配体走 LFS 或外链，见 [`../../../docs/大文件与Git-LFS.md`](../../../docs/大文件与Git-LFS.md)。
