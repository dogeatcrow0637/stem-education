## 电子件构成（MVP = 入门套件 ZK004）

| 类别 | 件 | 说明 |
|---|---|---|
| 主控 | **核心板 XA003 × 2** | ESP32-C3，MicroPython；一块装车、一块装遥控 |
| 底板 | 接收底板 **XA004** × 1 | 2× 有刷电机 + 4× 舵机 + 2× WS2812 灯口 |
| 底板 | 发射底板 **XA005** × 1 | 6× 模拟量（摇杆）+ 4× 数字量（开关/按钮） |
| 执行器 | 030 电机 × 2、9g 180° 舵机 × 1、9g 360° 舵机 × 1 | 均带离合保护 |
| 反馈 | WS2812 灯珠 × 4、LED 转接板 XA006 | 走 WS2812 协议 |
| 供电 | 14500 **7.4V 800mAh** 锂电 × 1 + XH2.54 充电器 × 1（另含 3×AAA 电池盒） | **只允许 5V 1–2A 充电** |
| 线材 | SH1.0 3P × 7、SH1.0 2P × 1、XH2.54 2P × 1 | 免焊插接 |

> 完整数量对比（ZK003/004/006/007）见 [`../docs/02-选型与BOM.md`](../docs/02-选型与BOM.md)。

## 关键电气参数

| 项 | 值 |
|---|---|
| 核心板电池输入 | 3.7–12.6V |
| 发射底板 XA005 输入 | 4.5–12.6V，工作电流 65mA |
| 舵机接口针序 | 3-Pin：**1 = PWM 信号，2 = 5V，3 = GND** |
| 电机接口 | M1/M2，SH1.0 2P，支持正反转 + PWM 调速 |
| 充电 | **只允许 5V 1–2A**，禁止 9V/12V 手机快充头 |
