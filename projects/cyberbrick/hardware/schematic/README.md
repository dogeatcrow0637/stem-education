## 端子表（已定稿，摘自工程文档）

### 接收端（装在车上）

| 位置 | 标识 | 接口 | 接什么 | 备注 |
|---|---|---|---|---|
| 电机 | M1 | SH1.0 2P | 030 有刷电机（左） | 正反转 + PWM 调速 |
| 电机 | M2 | SH1.0 2P | 030 有刷电机（右） | 转反了就对调这两根线 |
| 灯 | D1 / D2 | SH1.0 3P | WS2812 灯珠 | 不要插普通灯 |
| 舵机 | S1–S4 | 3-Pin | 转向舵机 / 机械爪等 | **1 信号 / 2 5V / 3 GND** |
| 核心板 | – | 灰色双排槽 | XA003 | 插到底 |
| 电源 | – | XH2.54 2P | 锂电或 AAA 电池盒 | 通电时接口旁白灯亮 |

### 发射端（遥控器里）

| 位置 | 标识 | 接口 | 接什么 | 备注 |
|---|---|---|---|---|
| 模拟量 | L1–L3 / R1–R3 | SH1.0 3P | 摇杆 / 船型开关 | 左右各 3 路 |
| 数字量 | K1–K4 | SH1.0 2P | 开关 / 瞬时按钮 | 下方 4 路 |
| 核心板 / 电源 | – | 槽位 / XH2.54 | XA003 / 电池 | 输入 4.5–12.6V |

> ⚠️ **线材颜色不固定**（官方按功能配线，不按颜色配），**以模型组装 PDF 的插口编号为准**，不要靠颜色猜。
> ⚠️ **插头方向**：断电状态核对；插反可能损坏模块。
