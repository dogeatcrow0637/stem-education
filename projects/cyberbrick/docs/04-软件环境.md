# 04 · 软件环境

> 适用版本：CyberBrick App（手机 / PC）+ 核心板出厂固件；MicroPython 进阶环境　|　最后更新：2026-10-20　|　前置条件：已装好车并能通电（见 `03-组装与调试.md`）

本项目有**两条完全不同的软件线**，先走第一条，第二条是加餐：

| 线 | 用来做什么 | 要不要写代码 | 难度 |
|---|---|---|---|
| **A. App 图形化配置**（主线，MVP） | 配对、绑定通道、调速度/转向/灯、下载别人的遥控工程 | 不要 | ★☆☆☆☆ |
| B. MicroPython 自定义项目（进阶） | 让核心板按自己的想法跑逻辑 | 要（Python 语法） | ★★★☆☆ |

## 一、线 A：CyberBrick App（MVP 只需要这条）

### 1. 安装

| 平台 | 获取方式 |
|---|---|
| 手机 | 应用商店搜索 CyberBrick，或官方下载页 `https://bambulab.com/en/download/cyberbrick-apps`（访问 2026-10-20） |
| PC | 同上页面（官方商店说明：配置方式支持 Mobile / PC） |

### 2. 配对（蓝牙）

1. 给车上电，看核心板灯语：**绿灯常亮** = 待连接。
2. 手机开蓝牙，打开 App，搜索设备并连接。
3. 连上后灯语变 **蓝灯常亮**；App 里会显示设备。
4. 同理配对遥控器里的核心板。

> 配不上时：① 先关掉另一台手机/平板的蓝牙连接（一块板同时只连一个蓝牙主机）；② 复位核心板（按复位键）再搜。

### 3. 建立遥控链路（2.4G 主从机）

车上的核心板设为主机（或从机，按模型页说明），遥控器上的设成另一端，App 里完成绑定。绑定成功后**两块板都是黄灯常亮**（若还连着蓝牙则是蓝黄交替）。

### 4. 下载现成的遥控工程

官方首批定位是"遥控模型"，所以**大部分模型页都提供现成的遥控配置（JSON / 工程文件）**，直接下载后用 App 同步到板子里即可，不需要自己配通道：

- MakerWorld 模型页 → 「CyberBrick 文件 / 配置 JSON」下载 → App 里同步。
- 官方标准遥控器模型页：MakerWorld 上搜 "CyberBrick Official Standard Remote"（`https://makerworld.com/en/models/1395991-cyberbrick-official-standard-remote`，访问 2026-10-20）。
- 同步时核心板**绿灯 2Hz 闪烁**，闪烁期间不要断电。

### 5. 能调什么（不用写代码）

| 能力 | 说明（官方 FAQ 口径） |
|---|---|
| 多通道比例控制 | 摇杆的中间量 → 电机/舵机的连续输出 |
| 通道绑定 | 把遥控器哪个摇杆绑到车上哪个动作 |
| 混控 | 一个摇杆同时影响两个输出（如履带车转向） |
| 简单事件控制 | 按键触发一个动作（如灯效切换） |

孩子能理解的"参数改写"就从这里开始：**限速、转向微调、灯色**——改完立刻能看见差别。

## 二、线 B：MicroPython 自定义项目（进阶）

### 1. 官方口径

- 核心板本质是 **ESP32-C3**，跑官方定制的 MicroPython 库，"ESPC32-C3 性能与接口能实现的功能，理论上都能实现"（官方商店 FAQ）。
- 开发工具：**任何支持 MicroPython + 串口的 IDE 都可以**；官方推荐 **Thonny**（轻量）或 **VS Code**（功能全）。
- 代码库与 API 文档：官方 GitHub 组织 `CyberBrick-Official`，核心仓库 `CyberBrick_Controller_Core`（社区论坛给出的路径；**本项目未直连 Github 验证，标 `待确认`**）。

### 2. 环境搭建（家长操作）

| 步 | 做什么 | 看得见的结果 |
|---|---|---|
| 1 | 装 Thonny（`https://thonny.org`） | 能打开 Thonny 界面 |
| 2 | 用 Type-C **数据线**（不是纯充电线）把核心板连电脑 | 系统出现一个串口设备 |
| 3 | Thonny → 右下角解释器 → 选 MicroPython (ESP32) / 对应串口 | Thonny 底部显示已连接，能进 REPL |
| 4 | 在 REPL 里敲一行 `print("hello")` 回车 | 立刻打印出 hello |

> 本机已验证：`待验证`（本项目尚未实物验证串口在 macOS/Windows 下的驱动情况；ESP32-C3 通常免驱，若 Thonny 找不到串口，装 CH34x/CP210x 驱动再试）。

### 3. 自定义项目的硬约束（官方 Wiki《高级编程与AI》）

| 约束 | 值 |
|---|---|
| 入口文件 | 项目根目录必须有 **`boot.py`**；核心板上电后自动执行 `boot.py`，**执行完程序停止**，直到再次复位 |
| 源码总大小 | 解压后 ≤ **800 kB** |
| 上传到 MakerWorld 后压缩体积 | ≤ **250 kB** |
| 可选文件 | `.ignore`（只支持精确路径匹配，不支持通配符）、`rc_config`、`log/` |

**这句话对教学很关键**：`boot.py` 不是"循环到底"，而是"开机跑一遍"。所以想让车持续响应，得在 `boot.py` 里起主循环或定时器（社区帖子提到官方默认 RC 工程用 `Timer` 做 50Hz 的软件 PWM 驱动有刷电机、舵机走 `machine.pwm`；`待确认`，需对照官方代码库）。

### 4. 孩子的第一个真实改动（建议）

1. 在 Thonny 里打开一个最简 `boot.py`（从官方代码库的示例出发）。
2. 改一个数：闪灯间隔、亮度、或循环次数。
3. 复位核心板 → 看灯的变化。
4. 把改动前后拍 10 秒视频存档。

## 三、固件升级

- 升级方式：**App 内蓝牙升级**（官方 Wiki：核心板带"可支持蓝牙升级的固件"）。
- 状态灯语：白灯常亮 = 等待升级；白灯快速闪烁 = 升级中（**此时断电会变砖风险**）；红灯常亮 = 升级错误。
- ⚠️ 官方声明：**只支持官方工具操作固件**，第三方工具刷写可能造成不可逆损坏且不在保修内。

## 四、环境验收判据（家长自查）

- [ ] App 能连上两块核心板（车上与遥控器上），灯语符合预期
- [ ] 能同步一个下载来的遥控工程，同步时看到绿灯 2Hz 闪烁
- [ ] 遥控链路建立后两块板黄灯常亮，车能按摇杆动
- [ ] （进阶）Thonny 能进 REPL 并打印一行文字
- [ ] （进阶）改过 `boot.py` 里的一个数字，复位后能看出差别
