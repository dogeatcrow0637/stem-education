# docs · 拓竹 CyberBrick

本目录放**给人看的文档**。

| 文件 | 用途 | 是否必需 |
|---|---|---|
| `01-项目简介.md` | 是什么、能做什么、教学价值、目标人群、前置知识 | ✅ |
| `02-选型与BOM.md` | 四档套件对比、MVP 采购清单、增购与替代 | ✅ |
| `03-组装与调试.md` | 装配顺序、接线核对、通电自检、灯语对照、故障排查 | ✅ |
| `04-软件环境.md` | App 配置链路、MicroPython 环境、固件升级 | ✅ |
| `05-教学与课程.md` | 课时安排、实验任务、考核点、教学材料索引 | ✅ |
| `99-参考资源.md` | 官方 Wiki、商店、MakerWorld、代码库（含访问日期） | ✅ |
| `家长实现/` | 面向家长的实现手册（六份） | ✅ |
| `儿童课程/` | 一课一个目录：`第NN课-课题/{课件.md,课件.html,图/,知识卡/,README.md}` | ✅ |

写作要求：

- 文档头写明 **适用版本 / 最后更新 / 前置条件**。
- 危险操作（锂电池充放电、通电、夹手风险）用 ⚠️ 单独标注，并写清防护与出错收场。
- 每一步都要能回答"做完这步我**看得见**什么"。
- 参数必须标来源；查不到的写 `待确认（来源：无）`，未实测的写 `待验证`。
