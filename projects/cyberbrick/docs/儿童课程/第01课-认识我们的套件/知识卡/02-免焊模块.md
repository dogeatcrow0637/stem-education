# 知识卡 · 免焊模块（代号贴纸：K02-免焊模块）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
所有零件都是小插头，一插就紧——**没有一根线是焊上去的**。

```
┌──────────────────────────────────┐
│   把一个插头画在这里 ✏️            │
│   （画它有几根"针"）               │
└──────────────────────────────────┘
```

### ② 先猜
不焊接、不用螺丝，插上去为什么就有电？

- A. 因为插头里藏着磁铁
- B. 因为插到底后，里面的金属片碰在一起，电就过去了

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 拿一根**充电线**和一个接口（给手机充电的）
2. 先把插头**插一半**，再**插到底**
3. 你看到：插一半可能充不上，插到底才稳——**金属碰金属，电才过得去**

### ④ 它叫什么

- 外号：乐高插头
- 正式名：**免焊模块 / 接插件**
- 一句话：插进去金属碰金属，电就通了。

### ⑤ 还在哪见过

- 家里：充电线、耳机插头、插线板
- 外面：USB 口、灯泡拧进灯座、充电桩
