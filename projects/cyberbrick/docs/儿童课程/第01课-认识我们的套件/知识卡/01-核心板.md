# 知识卡 · 核心板（代号贴纸：K01-核心板）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
插上电池，车上那块小板上的灯就亮了。

```
┌──────────────────────────────────┐
│   把这块小板画在这里 ✏️            │
│   （也可以贴一张手机拍的照片）      │
└──────────────────────────────────┘
```

### ② 先猜
为什么车和遥控器里，装的是**同样的**一块板？

- A. 因为它俩其实是同一台机器
- B. 因为它俩都靠这块板"动脑子"，只是下的命令不一样

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 找出家里的**电视遥控器**和**风扇遥控器**（或空调遥控器）
2. 各按一个键，看哪个电器响应
3. 你看到：长得差不多的两个"指挥器"，指挥的却是完全不同的东西——**外形不重要，里面的命令才重要**

### ④ 它叫什么

- 外号：大脑
- 正式名：**核心板**
- 一句话：车和遥控器的"指挥部"，插上就干活。

### ⑤ 还在哪见过

- 家里：遥控器、门铃、电动牙刷、会说话的玩具
- 外面：电梯按钮面板、自动门、取号机
