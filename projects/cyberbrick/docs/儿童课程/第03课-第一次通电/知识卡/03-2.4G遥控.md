# 知识卡 · 2.4G 遥控（代号贴纸：K03-2.4G）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
遥控器和车都开电，两块板变成**黄灯**；推摇杆，车就动——**中间没有一根线**。

```
┌──────────────────────────────────┐
│   把车和遥控器画在这里 ✏️           │
│   （中间画几条"看不见的线"）        │
└──────────────────────────────────┘
```

### ② 先猜
隔着一两米，命令是怎么"飞"过去的？

- A. 遥控器里有一根很细很细的线
- B. 它们用同一个"频道"互相喊话

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 拿**两个手电筒**（或手机闪光灯），隔开一段距离
2. 一个照向另一个，中间用手挡一下
3. 你看到：挡住就"收不到"了——**无线信号也怕被挡、也怕太远**

### ④ 它叫什么

- 外号：对讲机频道
- 正式名：**2.4G 无线遥控**
- 一句话：用同一个频道说悄悄话。

### ⑤ 还在哪见过

- 家里：无线鼠标、路由器、蓝牙音箱
- 外面：汽车遥控钥匙、无人机、无线门铃
