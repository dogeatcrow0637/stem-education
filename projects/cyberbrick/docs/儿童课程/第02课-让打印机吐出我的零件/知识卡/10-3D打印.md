# 知识卡 · 3D 打印（代号贴纸：K10-3D打印）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
打印机的喷嘴来回画，零件**一层一层长高**，几小时后变成一辆车的壳。

```
┌──────────────────────────────────┐
│   把打印机画在这里 ✏️              │
│   （画出"一层一层"的横线）          │
└──────────────────────────────────┘
```

### ② 先猜
它是像雕刻一样"削"出来的，还是一层层"堆"出来的？

- A. 削出来的
- B. **堆**出来的，像挤奶油做蛋糕

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 拿一叠**便利贴**（或者一块**橡皮泥**）
2. 一层一层往上叠，叠出一个小塔
3. 你看到：每一层都是平的，叠起来就变成立体的——**3D 打印就是这样长高的**

### ④ 它叫什么

- 外号：用奶油一层层挤蛋糕
- 正式名：**3D 打印（FDM）**
- 一句话：一层层堆出立体的零件。

### ⑤ 还在哪见过

- 家里：蛋糕、千层饼、便利贴
- 外面：玩具手办、鞋垫打样、牙套模型
