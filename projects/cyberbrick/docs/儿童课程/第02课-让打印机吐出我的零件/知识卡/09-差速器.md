# 知识卡 · 差速器（代号贴纸：K09-差速器）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
用手推**一边**车轮，**另一边会朝反方向转**。

```
┌──────────────────────────────────┐
│   把两个车轮画在这里 ✏️            │
│   （用箭头画出它们转向相反）        │
└──────────────────────────────────┘
```

### ② 先猜
转弯的时候，两边的轮子转得一样快吗？

- A. 一样快
- B. 不一样，**外侧快、内侧慢**

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 在空地上**走一个大圈**（转着弯走）
2. 低头看你两只脚踩出的脚印步数
3. 你看到：靠近圈里的那只脚迈得**少**，外面那只迈得**多**——**车转弯也是一样的道理**

### ④ 它叫什么

- 外号：转弯时两只脚迈不一样的步
- 正式名：**差速器**
- 一句话：让左右轮转得不一样快，车才好转弯。

### ⑤ 还在哪见过

- 家里：带齿轮的玩具车
- 外面：真汽车的后桥、遥控模型车、拖拉机
