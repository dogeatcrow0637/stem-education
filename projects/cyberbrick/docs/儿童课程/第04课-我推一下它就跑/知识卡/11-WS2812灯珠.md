# 知识卡 · WS2812 灯珠（代号贴纸：K11-WS2812）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
一颗小小的灯珠，能变红、变蓝、变黄、变绿；一串灯珠还能**一个接一个**亮过去。

```
┌──────────────────────────────────┐
│   把灯珠画在这里 ✏️                │
│   （涂上你看到的颜色）              │
└──────────────────────────────────┘
```

### ② 先猜
这么小的一颗灯，怎么装得下那么多颜色？

- A. 里面有一颗会变色的宝石
- B. 里面藏着**红、绿、蓝三盏小灯**，一起亮就能配出很多颜色

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 拿**红、绿、蓝三支彩笔**（或三张玻璃糖纸）
2. 把它们叠在一起，对着灯（或窗户）看
3. 你看到：颜色一叠就变出新颜色——**灯珠里就是红绿蓝三个小灯**

### ④ 它叫什么

- 外号：会变色的糖豆
- 正式名：**WS2812 灯珠**
- 一句话：一颗灯里装着红绿蓝三盏小灯。

### ⑤ 还在哪见过

- 家里：电视屏幕、电脑键盘灯、彩灯串
- 外面：电子广告牌、舞台灯带、树上的节日彩灯
