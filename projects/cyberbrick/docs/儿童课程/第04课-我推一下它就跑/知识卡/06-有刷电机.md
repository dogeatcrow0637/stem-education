# 知识卡 · 有刷电机（代号贴纸：K06-电机）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
通电后轮子转起来；用手轻轻捏住转轴，能感觉到它在**使劲**。

```
┌──────────────────────────────────┐
│   把电机画在这里 ✏️                │
│   （旁边写上"嗡嗡"）               │
└──────────────────────────────────┘
```

### ② 先猜
它为什么会自己转起来？

- A. 因为里面藏着一根橡皮筋
- B. 因为通电以后，里面的磁铁和线圈互相推来推去

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 找一个**带小马达的旧玩具**，或者一支**电动牙刷**
2. 打开开关，把耳朵凑近听
3. 你看到（听到）："嗡嗡"的声音——**那就是小电机在转**

### ④ 它叫什么

- 外号：会转的小马达
- 正式名：**有刷直流电机**
- 一句话：通电就转，但不会自己数转了几圈。

### ⑤ 还在哪见过

- 家里：电动玩具、电风扇、电动牙刷、剃须刀
- 外面：共享单车的助力、汽车雨刷、自动门

| ③ 的预期结果 | 孩子应指出"嗡嗡响的地方就是电机"；看不到时先查：玩具是否有电 |
