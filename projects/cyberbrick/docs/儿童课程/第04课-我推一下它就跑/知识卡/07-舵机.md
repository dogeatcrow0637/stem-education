# 知识卡 · 舵机（代号贴纸：K07-舵机）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
舵机通电后先"咔"一下停在**正中间**；让它转到某个角度，它转到那儿就**停住不动**。

```
┌──────────────────────────────────┐
│   把舵机画在这里 ✏️                │
│   （画出它的"小胳膊"停在哪）        │
└──────────────────────────────────┘
```

### ② 先猜
电机和舵机都会转，它们最大的不同是什么？

- A. 电机转得快，舵机转得慢
- B. 舵机能**停在指定的角度**，电机只会一直转

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 借一个**量角器**（或者用纸剪一个半圆、每 15° 画一条线）
2. 让家人喊"45 度"，你把手（手臂）摆到 45° 的位置上停住
3. 你看到：你能停在**指定的角度**上——**舵机就是"能停在指定角度"的电机**

### ④ 它叫什么

- 外号：会拐弯的小胳膊
- 正式名：**舵机**
- 一句话：能停在你说的那个角度上。

### ⑤ 还在哪见过

- 家里：会摆头的玩具、遥控车的转向
- 外面：无人机云台、机器人关节、自动门锁的小舌头
