# 知识卡 · PWM 调速（代号贴纸：K08-PWM）

> 打印建议：A5 横向 / 一页两卡对折；正面给孩子看（大字 + 图），背面给家长看（怎么问、线索记录）。

## 正面（给孩子看）

### ① 看到什么
在 App 里拖动"速度"滑块，车不是"一下快一下慢"，而是**稳稳地越跑越快**。

```
┌──────────────────────────────────┐
│   把滑块或按钮画在这里 ✏️          │
│   （画"快按开关"的动作）            │
└──────────────────────────────────┘
```

### ② 先猜
电只有"通"和"断"两种，为什么能调出**不同的速度**？

- A. 因为电机自己会算力度
- B. 因为电被**非常快地开了又关**，开得多就快、开得少就慢

<!-- 不写答案，留白。家长在背面第 ② 步准备接话。 -->

### ③ 动手验证（家里就能做，5 分钟）

1. 拿一个**手电筒**（或手机的闪光灯）
2. 用手**很快很快地**按开、关、开、关
3. 你看到：看起来像"半亮"——**开关得够快，就等于把劲儿调小了**

### ④ 它叫什么

- 外号：水龙头开大开小
- 正式名：**PWM 调速**
- 一句话：快速开关，假装成"半开"。

### ⑤ 还在哪见过

- 家里：调光灯、风扇调速、电饭锅保温
- 外面：电动车油门、舞台灯渐变、霓虹灯呼吸

## 背面（给家长看）

| 项 | 内容 |
|---|---|
| 这张卡想让孩子明白 | "调速"不是改变电压，而是快速开关的"占空比" |
| ② 的引导 | 等 10 秒再给线索；答错就说"那我们试试看" |
| ③ 的预期结果 | 孩子应说出"按得越快越亮/越慢越暗"；看不到时先查：按得够不够快 |
| 适合档位 | L1 说"车变快了" / L2 对比两档速度 / L3 用自己的话说出"快速开关" |
| 常见误解 | 孩子容易以为"调速=电压变小了"；实际是开关时间的比例在变 |
| 延伸追问 | 1）为什么开关太慢会变成"一闪一闪"？ 2）舵机也用它吗？ 3）灯能不能这样调亮度？ |
