# 03 · 组装与调试

> 适用版本：CyberBrick 入门套件 ZK004 + 任一官方/社区免费模型（以模型页的组装 PDF 为准）　|　最后更新：2026-10-20　|　前置条件：已打印好结构件（或收到代打件）、螺丝按规格分装

## 一、装配总顺序（先粗后细，一步一验）

```mermaid
graph LR
  A[1 清点模块] --> B[2 打印件去毛刺]
  B --> C[3 装电机与差速器]
  C --> D[4 装转向舵机]
  D --> E[5 装底板与核心板]
  E --> F[6 接线并核对方向]
  F --> G[7 装电池 不上电检查]
  G --> H[8 通电看灯语]
  H --> I[9 App 配对]
  I --> J[10 首次行驶]
```

**每一步都要有看得见的结果**，看不到就别往下走：

| 步 | 做什么 | 看得见的结果 | 常见卡点 |
|---|---|---|---|
| 1 | 按模型页 BOM 清点模块 | 所有模块都能点到，不缺件 | 缺件多半是模型页"另需"项没买 |
| 2 | 打印件剪支撑、去毛刺、试插 | 轴孔能手动转，齿轮不卡 | 活动件断裂 → 换 PLA Basic / PETG 重打 |
| 3 | 装 030 电机 + 差速器齿轮包，涂一点润滑脂 | 手推车轮，另一侧轮反向转（差速器在工作） | 齿轮压太紧 → 转动发涩 |
| 4 | 转向舵机居中后再装摇臂 | 通电时摇臂在正中，不是歪的 | 先装摇臂再通电 → 打舵会顶死 |
| 5 | 装接收底板 + 核心板（灰色双排槽） | 核心板**插到底**，不歪不翘 | 没插到底 → 灯不亮或接触不良 |
| 6 | 插 M1/M2、舵机 S1–S4、灯 D1/D2、电源开关、电池 | 每个插头都听到"卡"声 | **插反/插错口** → 见下方端子表 |
| 7 | 不接电池，先对着端子表逐条核对一遍 | 手指划过每条线都能说出"它去哪" | 跳过这步是返工率最高的原因 |
| 8 | 开电源，看核心板灯语 | 见下方灯语表 | 灯不亮 → 查电池电量与插头方向 |
| 9 | 装 App、蓝牙配对、下载对应遥控工程 | App 里能看到设备，遥控器灯变蓝 | 配不上 → 见 `04-软件环境.md` |
| 10 | 慢慢推摇杆 | 车动了，且**方向与摇杆一致** | 方向反了 → 断电对调该电机两根线 |

## 二、端子表（接线图和表同时给）

### 接收端（装在车上的 XA004 接收底板）

| 位置 | 标识 | 接口 | 接什么 | 备注 |
|---|---|---|---|---|
| 电机 | M1 | SH1.0 2P | 030 直流有刷电机（左） | 支持正反转 + PWM 调速 |
| 电机 | M2 | SH1.0 2P | 030 直流有刷电机（右） | 转反了就对调这两根线 |
| 灯 | D1 / D2 | SH1.0 3P | WS2812 灯珠 / 灯带 | 走 WS2812 协议，不要插普通灯 |
| 舵机 | S1 | 3-Pin 插针 | 转向舵机 | 针脚：**1 = PWM 信号，2 = 5V，3 = GND** |
| 舵机 | S2–S4 | 3-Pin 插针 | 机械爪 / 铲斗 / 转台（按模型 BOM） | 同一个 5V 母排，别堆太多大扭力舵机 |
| 核心板 | – | 灰色双排槽 | 核心板 XA003 | 插到底 |
| 电源 | – | XH2.54 2P | 锂电 或 AAA 电池盒 | 通电时接口旁**白灯亮起** |

### 发射端（遥控器里的 XA005 发射底板）

| 位置 | 标识 | 接口 | 接什么 | 备注 |
|---|---|---|---|---|
| 模拟量 | L1–L3 / R1–R3 | SH1.0 3P | 单/双通道摇杆、船型开关 | 左右各 3 路 |
| 数字量 | K1–K4 | SH1.0 2P | 开关模块、瞬时按钮 | 下方 4 路 |
| 核心板 | – | 灰色双排槽 | 核心板 XA003 | 插到底 |
| 电源 | – | XH2.54 2P | 锂电 或 AAA 电池盒 | 输入 4.5–12.6V，工作电流 65mA |

> 线材颜色对照不固定（官方线材按功能配，不按颜色配），**以模型组装 PDF 的插口编号为准**，不要靠颜色猜。

## 三、通电自检（每次上电都做）

⚠️ **上电前必做三件事**：① 确认电池极性/插头方向正确；② 确认所有插头插到底；③ 确认手和线不在车轮/齿轮运动范围里。

上电后按顺序看：

1. 电源接口旁**白灯亮**？→ 底板供电正常。
2. 核心板灯语是什么？→ 对照下表判断状态。
3. 摇杆回中，车轮**不该动**；动 = 摇杆没校准或通道绑错。
4. 轻推摇杆，车轮转向是否与摇杆一致。
5. 摸一下电机和底板温度，**明显发烫立即断电**。

### 核心板灯语对照表（来源：官方 Wiki《模块列表》）

| 灯语 | 含义 | 该做什么 |
|---|---|---|
| 绿灯常亮 | 开机但未连接 | 正常待机，去 App 配对 |
| 蓝灯常亮 | 蓝牙已连接 | App 配好了，可以下载/同步配置 |
| **黄灯常亮** | **2.4G 主从机已连接** | 遥控链路通了，可以开车 |
| 蓝黄交替闪烁 | 蓝牙与 2.4G 都已连接 | 最完整的状态（配置完 + 遥控中） |
| 绿灯 2Hz 闪烁 | 正在发送/更新配置 | 别断电，等它结束 |
| 绿灯 1Hz 闪 5 秒 | 识别灯效（找设备用） | 确认是哪一块板 |
| 红灯常亮 | 固件升级错误 | 用官方工具重做一次升级 |
| 白灯常亮 | 固件等待升级 | 保持供电，开始升级 |
| 白灯快速闪烁 | 固件升级中 | **绝不能断电** |

## 四、故障排查表

| 现象 | 先查什么 | 处理 |
|---|---|---|
| 上电没任何灯 | 电池电量 / 电源开关 / 插头方向 | 换满电电池；确认开关在 ON；重插 XH2.54 |
| 灯亮但 App 搜不到 | 手机蓝牙是否开；核心板是否已在别的设备上连着 | 关掉其他设备的连接；复位核心板再搜 |
| 配上了但车不动 | 核心板灯是否黄/蓝黄（2.4G 已连） | 没连上就重新绑定主从机 |
| 一个轮转、一个不转 | 该电机的 SH1.0 插头 / 电机线 | 断电重插；仍不动则用另一路 M 口测，判断是电机还是底板 |
| 前进变后退、左转变右转 | 电机极性 / 摇杆通道方向 | 断电对调该电机两根线；或在 App 里反向该通道 |
| 舵机嗡嗡叫、发烫 | 舵机被机械卡住（摇臂行程顶死） | 立即断电，重新对中装摇臂，或限制 App 里的行程范围 |
| 跑一会就停 | 锂电电量低；或电机堵转保护 | 充电；检查传动是否卡涩 |
| 活动件断裂 | 耗材层间强度不足 | 用 PLA Basic / PETG 重打该件，不要用 PLA Lite |
| 装满车装不回去 | 打印公差 / 用了别人的配置 | 按模型页推荐配置重打该件，不要自行缩放 |

## 五、安全红线（一票否决）

⚠️ 出现以下任一条，本节内容重做：

1. **用手机快充头（9V/12V）给 7.4V 锂电充电** —— 官方明确禁止，只允许 5V 1–2A。
2. **边充边玩 / 无人看管充电** —— 官方明确禁止，且不要盖住设备。
3. 手伸进运动范围（车轮、齿轮、舵机摇臂）时有人碰摇杆 —— 夹手风险，社区模型页反复提示。
4. 孩子单独操作锂电、充电器 —— 官方要求成人监督。
5. 用第三方工具刷固件 —— 官方声明不支持，可能不可逆损坏且不在保修内。

## 六、打印与代打

- 打印参数与选材：见 `enclosure/print-notes.md`。
- 无打印机：把模型页的 3MF/STL 打包发给 3D 打印代做（嘉立创 3D 打印 / 淘宝代打），按克计价；**先问单价与交期**，4 盘件一起发更划算。
- 收件验收：**先点件数，再量关键孔距**，缺件/变形当场拍图找代打。
