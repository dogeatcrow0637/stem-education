# 01 · 项目简介

> 适用版本：CyberBrick 硬件套件 ZK003 / ZK004 / ZK006 / ZK007（核心板 XA003，ESP32-C3）　|　最后更新：2026-10-20　|　前置条件：无（家长零基础可上手；需一台 3D 打印机或外协代打）

## 这是什么

拓竹（Bambu Lab）旗下 MakerWorld 团队推出的**模块化智能玩具生态**：一块通用核心板 + 两类功能底板 + 一批**免焊接模块**，配 3D 打印的结构件，组成遥控车 / 坦克 / 挖掘机 / 桌面机械臂等各种模型。

三段能力被拆得很干净，正好对应教学的三条线：

| 段 | 孩子看到的东西 | 家长要会的东西 |
|---|---|---|
| 结构 | 打印机吐出一堆零件，拼成车身 | 会用打印机（或把 STL 发给代打） |
| 电子 | 插上模块，车就有电、有灯、能动 | 会看接口方向，**不用焊接** |
| 软件 | App 里拖滑块 → 车真的动了；再写 MicroPython 改灯 | 会装 App；进阶会装 Thonny |

官方自我定位："介于专业 RC 模型与普通遥控玩具之间，优势不在性能与低价，而在**无限的多样性**"（官方商店 FAQ，访问 2026-10-20）。

## 能做什么

| 能力 | 说明 |
|---|---|
| 遥控行驶 | 双摇杆 → 2 路有刷电机正反转 + PWM 调速，可差速转向 |
| 机械动作 | 4 路舵机接口，可做机械爪、铲斗、转台等 |
| 灯光反馈 | WS2812 灯珠，颜色/闪烁可在 App 里配 |
| 换壳复用 | 同一套电子件换到另一个模型上，只需重新打印结构件 |
| 图形化编程 | App 内多通道比例控制、通道绑定、混控、简单事件，**零代码** |
| 代码编程 | MicroPython 自定义项目（`boot.py` 为入口），可读传感器、写自定义逻辑 |
| 一对多 | 一个遥控器可控制多台车（官方规格：一对一 / 一对多） |

## 教学价值与目标人群

**适合谁**

- 小学 3–6 年级（8–12 岁），**在家长全程看护下**使用（官方适龄 14+ 指的是可独立使用年龄）。
- 已经玩过积木/遥控玩具、想升级到"自己做一台"的孩子。
- 家里有 3D 打印机（或愿意用代打）的家庭；否则第一步就要解决打印问题。

**教学目标**

1. 说清一台遥控车的三段闭环：**结构承力 → 电驱动 → 信号指挥**，并能指着自己车上的零件对应。
2. 独立完成"打印件 → 装配 → 通电 → 配对 → 开动"全流程，中间至少排除一次故障。
3. 会改一个参数（速度上限 / 转向微调 / 灯色）并说出改动前后差别。
4. （进阶）在核心板上跑一段自己改的 MicroPython，让灯按自己的节奏闪。

**前置知识**：无。不需要焊接、不需要画电路板、不需要命令行。

**不适合谁**：想要"高精度运动控制 / 学算法 / 做科研级机械臂"的家庭——那是 01 号机械臂项目的范围。本项目是**结构 + 电子 + 入门编程**的综合体验。

## 投入与风险提示

| 项 | 量级 | 备注 |
|---|---|---|
| 硬件成本 | ￥199（入门套件页面价）～￥329（超级组合页面价） | 京东拓竹官方旗舰店原价口径，经比价页转述；以页面为准（2026-10-20） |
| 耗材成本 | 约 ￥70–100 / 1 kg PLA | 社区模型页显示 1 kg PLA Basic 起价约 $12.99 |
| 打印机 | 自备或代打 | **本项目最大的隐性门槛**：无打印机需走嘉立创/淘宝代打，按克计价 |
| 打印时间 | 单模型 2–4 盘，约 **8–13 小时**机器时间 | 家长工时很少，等待在机器上（社区模型页公布值） |
| 主要风险 | ①锂电池使用不当 ②活动件打印强度不足断裂 ③用错充电器 | 见 `03-组装与调试.md` 的安全一票否决项 |
| 能力边界 | 有刷电机 + 舵机，**不是**闭环伺服；没有编码器、没有力控 | 别拿它和 CAN 总线机械臂比精度 |
