# 里程碑与任务卡（拓竹 CyberBrick 模块化遥控套件）

| 字段 | 值 |
|---|---|
| 适用版本 | 硬件：入门套件 ZK004 + 一个 MakerWorld 免费车模　／　软件：CyberBrick App |
| 最后更新 | 2026-10-20 |
| 前置条件 | 已读 `00-总纲与路线图.md`；材料已到货 |

**卡片规则**：一张卡 = 一次坐下 = 一个动作单元（≤25 分钟）；做完必须能看见结果并打勾。打勾格式：`- [x] 卡 M1-1`。每张卡完成盖一枚章，每 3 张卡安排一次"展示时刻"（拍照/录 ≤10 秒视频），每完成一个里程碑发一个称号（材料员→装配员→接线员→驾驶员→工程师）。

---

## M0 定稿与采购

目标：套件型号定稿、MVP 物料到货、核对无缺件。

### 卡 M0-1：选套件与下单
- 目标（孩子视角）："我们决定买哪一套，把它请回家。"
- 物料：采购清单（见 `05-安全与工具采购清单.md`）+ 官方演示视频
- 三档分工：L1 一起看视频并说出选哪个｜L2 一起对照清单点数量｜L3 孩子做比较表（价格/含量）并给结论
- 步骤：
  1. 看官方/社区演示视频 → 结果：孩子能说出"我们要做的是这个"
  2. 对照档位表选定 → 结果：写下一行结论（**入门套件 ZK004**，1 车 1 遥控 + 理由）
  3. 加购耗材（PLA Basic 或 PETG 1 kg）→ 结果：订单截图存档
- 验收判据：清单每一项都有"已下单/替代型号"状态；确认买的是 ZK004 不是 ZK006（只有车没遥控）
- 失败兜底：缺货 → 换官方店另一渠道，或先买 ZK006 + ZK007 组合
- ⚠️ 安全：—

### 卡 M0-2：到货核对与分格收纳
- 目标："所有零件都到齐，一个都不少。"
- 物料：采购清单 + 分格收纳盒 + 标签贴
- 三档分工：L1 报出零件名｜L2 点数并分格收纳｜L3 记录缺件与错件
- 步骤：
  1. 对照 `docs/02-选型与BOM.md` 的 In The Box 表逐项点数 → 结果：清单全部打勾
  2. 螺丝、端子线、模块分格贴标签 → 结果：收纳照片一张
- 验收判据：无未处理缺件（缺件已联系商家）；**M2.5×6 螺丝单独一格**
- 失败兜底：缺件先做不依赖它的里程碑（如先打印结构件）
- ⚠️ 安全：小零件远离 3 岁以下幼儿

## M1 结构件就位

目标：打印件到手、去毛刺、能手动转动的传动部分装好。

### 卡 M1-1：挑模型、切片、开打印
- 目标："打印机开始吐我们的零件。"
- 物料：电脑/手机上的切片软件或官方切片配置 + 耗材
- 三档分工：L1 从模型库里挑一辆车并选颜色｜L2 一起看"要打印几盘、多久"｜L3 自己导入 3MF 并核对待打印盘数
- 步骤：
  1. 在 MakerWorld 搜带 CyberBrick 徽标的车模 → 结果：选定一个模型，记下 URL
  2. 下载官方打印配置（3MF/配置文件），**不改缩放** → 结果：切片预览无红色报错
  3. 开始打印 → 结果：打印机开始工作；记下预计总时长（通常 8–13 小时，机器时间，可过夜）
- 验收判据：切片预览各盘完整；耗材为 PLA Basic 或 PETG
- 失败兜底：切片报错 → 用模型页自带的官方配置；无打印机 → 把 STL 打包发代打
- ⚠️ 安全：打印机热端高温、运动件夹手，孩子只远观投料（L1）

### 卡 M1-2：去毛刺、装车轮与差速器
- 目标：车轮能手动转，左右轮反向转。
- 物料：打印件、M2.5×6 螺丝、迷你螺丝刀、润滑脂、030 电机、差速器齿轮包
- 三档分工：L1 递件对号、掰支撑｜L2 拧螺丝、涂一点润滑脂｜L3 独立照组装 PDF 装
- 步骤：
  1. 剪支撑、去毛刺、试插轴孔 → 结果：齿轮/轴孔能手动转动不卡
  2. 按组装 PDF 装 030 电机 + 差速器，涂薄薄一层润滑脂 → 结果：**手推一侧车轮，另一侧反向转**
- 验收判据：车轮能自由转、差速器工作（两侧反向）、无卡涩异响
- 失败兜底：齿轮太紧 → 清毛刺重装；活动件断裂 → 换 PLA Basic/PETG 重打该件
- ⚠️ 安全：剪支撑用剪钳时孩子不碰刃口；润滑脂别涂到电机轴外

## M2 通电配对

目标：供电正常、灯语正常、App 能连上并绑定遥控链路。

### 卡 M2-1：首次通电，读灯语
- 目标："通电以后灯会说话，我们看它在说什么。"
- 物料：装好的车/遥控器、满电电池
- 三档分工：L1 在安全距离外说"看到什么灯"｜L2 在家长口令下拨电源开关｜L3 自己按顺序上电并口述三检查项
- 步骤：
  1. 断电状态核对电池插头方向 → 结果：方向正确
  2. 清空运动范围、手上桌 → 结果：无人手在车轮/齿轮旁
  3. 开电源 → 结果：电源口旁**白灯亮**，核心板**绿灯常亮**（待连接）
- 验收判据：出现上述灯语且无发烫、异味、异响
- 失败兜底：无任何灯 → 查电池电量、开关、插头；发烫 → 立即断电
- ⚠️ 安全：上电前三检查（极性 / 清空范围 / 手离开）；首次上电家长执行

### 卡 M2-2：App 配对与绑定遥控
- 目标："手机认识它了，遥控器和车也牵上手了。"
- 物料：手机 + CyberBrick App
- 三档分工：L1 看灯语变化并描述｜L2 在 App 里点配对｜L3 独立完成两块板的配对与绑定
- 步骤：
  1. 手机开蓝牙、打开 App，连车上核心板 → 结果：灯语变**蓝灯常亮**，App 出现设备
  2. 同样配对遥控器核心板 → 结果：两块板都连上 App
  3. 在 App 里把两块板绑成 2.4G 主从 → 结果：两块板**黄灯常亮**
- 验收判据：灯语符合预期（蓝 / 黄 / 蓝黄交替）；App 里能看到两块设备
- 失败兜底：搜不到 → 先断开另一台手机上的 App（一块板只连一个蓝牙主机）；复位核心板再搜
- ⚠️ 安全：—

## M3 车跑起来

目标：接线核对无误，车能按摇杆动、方向正确、跑完一圈。

### 卡 M3-1：接线核对（对照端子表）
- 目标："每条线都能说出它去哪。"
- 物料：装好的车、`docs/03-组装与调试.md` 端子表
- 三档分工：L1 用手指点线并念出口位｜L2 逐条按表核对｜L3 独立发现并纠正插错的口
- 步骤：
  1. 对着端子表逐条核对 M1/M2、舵机 S1–S4、灯 D1/D2、电源 → 结果：每条线都对得上
  2. 确认所有插头插到底（听到"卡"声）→ 结果：无虚接
- 验收判据：端子表逐条打勾，无插反/插错
- 失败兜底：线色对不上 → **以组装 PDF 的插口编号为准**，不靠颜色猜
- ⚠️ 安全：核对时断电；确认无误再上电

### 卡 M3-2：首次行驶，跑一圈
- 目标："我推一下，它就跑，还能转弯。"
- 物料：充满电的车 + 遥控器 + 空场地
- 三档分工：L1 当解说员，喊"前进/左转"｜L2 轻推摇杆观察｜L3 独立驾驶并录视频
- 步骤：
  1. 原地小幅度推摇杆 → 结果：车动，方向与摇杆一致
  2. 清空 2 m 见方地面，跑一圈 → 结果：录 ≤10 秒视频存档
- 验收判据：车按摇杆前进/后退/转向，方向正确，能跑完一圈
- 失败兜底：方向反 → 断电对调该电机两根线；一个轮不转 → 查该 M 口插头与电机线
- ⚠️ 安全：手不进入车轮范围时再碰摇杆；失控立即松开摇杆或关电源

## M4 换壳改造

目标：孩子提出并实现一个小改动，形成"这是我改的"归属感。

### 卡 M4-1：改一个参数
- 目标：改动前后有可比较的差异。
- 物料：App + 车
- 三档分工：L1 选"改哪个、变大还是变小"｜L2 一起改并观察｜L3 独立改并解释原理
- 步骤：记下原值（限速/转向微调/灯色）→ 改 → 再跑一圈对比 → 结果：对比记录（数字 + 视频）
- 验收判据：孩子能说出"改了什么、为什么变了"
- 失败兜底：改坏了 → App 里改回原值，或重新同步一次默认配置
- ⚠️ 安全：改速度别一次调太大，先在空场地试

### 卡 M4-2：换壳或加一个功能，讲给别人听（Boss 关）
- 目标：把作品讲清楚，成为"作者"。
- 物料：新模型 STL（可选）+ 车
- 三档分工：L1 说 3 句话介绍｜L2 演示 + 说 1 分钟｜L3 独立做 3 分钟讲解（按 `04-验收与展示.md` 展示脚本）
- 步骤：
  1. 换一个模型壳（重新打印）**或**加一个动作（如舵机做个小爪子）→ 结果：新样子/新功能能跑
  2. 按展示脚本讲 3 分钟 → 结果：展示录像
- 验收判据：能回答"哪里最难、怎么解决的"
- 失败兜底：换壳太耗时 → 只换配色/贴纸也算；不设放弃条件
