# 家长实现总纲（拓竹 CyberBrick 模块化遥控套件）

| 字段 | 值 |
|---|---|
| 项目编号 | 03 |
| 项目目录 | `projects/cyberbrick` |
| 适用版本 | 硬件：CyberBrick 入门硬件套装 **ZK004** + 任一 MakerWorld 免费车模　／　软件：CyberBrick App（界面以手头版本为准） |
| 最后更新 | 2026-10-20 |
| 前置条件 | 一台 3D 打印机（或找代打）；一台手机（装 CyberBrick App）；十字螺丝刀（套件已赠） |

> 本手册面向**完全零基础的家长**，用于带一名小学生把一台遥控车做出来并讲明白。工程细节以 `projects/cyberbrick/docs/` 为准，本手册只讲"怎么带着孩子做"。

## 一句话目标

做完之后，孩子能独立完成的最小成果是：**装好一台带 3D 打印外壳的遥控车**；能看到的现象是：**推摇杆，车就按方向跑起来，灯还会亮**。

## 这套手册怎么用

1. **先读安全红线**（本文件最后一节），再读 `05-安全与工具采购清单.md`。
2. 按 `02-里程碑与任务卡.md` 从头做；**一张卡一次坐下做，做完打勾再进下一张**。
3. 每张卡按孩子的实际水平选一档执行（同一项目不同环节可选不同档）：

| 档 | 孩子做什么 | 家长做什么 | 什么时候升档 |
|---|---|---|---|
| L1 观察 | 递零件、对编号、按按钮、说出看到的现象 | 全部动手 + 讲解 + 防护 | 孩子能说清"这步在做什么、成功会看到什么" |
| L2 协作 | 拧螺丝、插线、插拔 USB、填验收表 | 把关紧固与极性、执行危险步骤 | 同类动作无提示也能做对 |
| L3 独立 | 看图纸独立做、改参数、记录数据、讲原理 | 只做安全监护，允许失败 | 能讲清"上次为什么失败、这次改了什么" |

4. 需要**外包**的环节（家长不必自学）：3D 打印（把 STL 发给代打，按克计价）。**本项目不需要焊接、不需要画板、不需要命令行**。
5. 卡住了：先查 `04-验收与展示.md` 的失败排查表，再对照卡片里的"失败兜底"。

| 里程碑 | 孩子的可见成果 | 家长工时估算 | 放弃/跳过条件 |
|---|---|---|---|
| M0 定稿与采购 | 采购清单 + 到货核对表 | 1–2 小时 | 打印机一直借不到 → 走代打（费用另计） |
| M1 结构件就位 | 一堆去完毛刺的打印件，手推车轮能转、左右反向 | 2–4 小时（另计打印机 8–13 小时机器时间） | 打印反复失败 → 先只打"车身 + 两个轮"最小件 |
| M2 通电配对 | 白灯亮、绿灯常亮、App 里看到设备 | 1–2 小时 | App 一直配不上 → 先只做灯效演示（降级但仍有成果） |
| M3 车跑起来 | 车按摇杆前进/转向，跑完一圈（≤10 秒视频） | 1–2 小时 | 转向总是不正 → 先只跑"直行 + 后退" |
| M4 换壳改造 | 换模型/换配色/改一个参数，前后对比 + 3 分钟讲解 | 2–3 小时 | 不设放弃条件，这是"还想继续"的关卡 |

## 时间与预算

| 项 | 估算 | 说明 |
|---|---|---|
| 家长工时合计 | 约 10–15 小时 | 不含采购等待与打印机的机器时间 |
| 日历周期 | 2–3 周 | 建议每周 2–3 次，每次 ≤45 分钟 |
| MVP 预算（能跑通最小闭环） | ￥300–360 | 入门套件 ￥199（页面价）+ 1 kg 耗材 ￥70–100 + 零碎 |
| 全量预算（含扩展） | ￥500+ | 换壳、加电池、加舵机等，按需 |
| 可能的外协费 | 按克计价，`待确认` | 无打印机时把 STL 发代打（嘉立创 3D 打印 / 淘宝代打） |

## 场地、作息与收纳

- 工作台：**平整桌面 + 充足光线**；玩车时**清空 2 m 见方的地面**（车轮会跑）。锂电充电时下面垫**防火/隔热垫**。
- 单次时长：≤ 45 分钟（2 张卡），每 3 张卡安排一次"展示时刻"。
- 收纳：**螺丝按规格分格**（M2.5×6 有 100 颗，混了很难找）；每次结束拍照记录当前状态；**断电再离开**。

## 安全红线（先读这一页）

1. 危险动作一律家长单独执行：**锂电池充电、首次上电、固件升级**。孩子只在安全距离外看。
2. 上电前必须做的三件事：**① 核对电池插头方向；② 清空车轮/齿轮运动范围；③ 手离开运动区域**。
3. 充电**只允许 5V 1–2A**（原装充电器或电脑 USB 口），**禁止手机快充头**；不边充边玩、不无人看管充电。
4. 出现异常（异味 / 异响 / 冒烟 / 发烫 / 报错）→ **立即断电**，再排查。
5. 详细清单见 `05-安全与工具采购清单.md`。

## 假设与已知限制

- 本文假设：家长不会焊接 / 不写代码 / **有一台 3D 打印机**；如没打印机，M1 改走代打，其余不变。
- 未验证项：遥控距离（官方两个来源冲突 100 m ↔ 4 m）、单次续航 → 标 `待验证`，实测后回填 `docs/01-项目简介.md`。
- 关键风险：① 用错充电器（官方明令禁止）；② 活动件用 PLA Lite 导致断裂；③ 玩车时手伸进车轮范围。
