## 2. 失败排查表（按顺序查，不要跳）

| 现象 | 最可能原因（按概率排序） | 先查什么 |
|---|---|---|
| 上电没任何灯 | 电池没电 / 开关没开 / 插头没插到底 | 换满电电池 → 确认开关 ON → 重插 XH2.54 |
| 灯亮但 App 搜不到 | 另一台设备占着蓝牙 / 核心板需复位 | 断开其他手机上的 App → 按复位键再搜 |
| 配上了但车不动 | 2.4G 主从没绑上 | 看灯语：**黄灯常亮**才是已连 |
| 一个轮转一个不转 | 该电机插头 / 电机线 | 断电重插；仍不动用另一路 M 口测，判断是电机还是底板 |
| 前进变后退、左变右 | 电机极性 / 通道方向 | 断电对调该电机两根线，或在 App 里反向该通道 |
| 舵机嗡嗡叫、发烫 | 摇臂行程顶死被卡住 | 立即断电，重新对中装摇臂或限制行程 |
| 跑一会就停 | 电池电量低 / 电机堵转保护 | 充电；检查传动是否卡涩 |
| 活动件断裂 | 耗材层间强度不足 | 用 PLA Basic / PETG 重打，别用 PLA Lite |
| 打印件装不上 / 太松 | 缩放或参数不对 | 按模型页推荐配置，不自行缩放 |
| 充电时发烫 | 用了手机快充头 | **只允许 5V 1–2A**，换官方充电器 |

## 3. 作品展示脚本（让孩子讲 3 分钟）

1. **它是什么**（30 秒）："这是我做的 ____，它能 ____。"
2. **怎么做的**（60 秒）：按"先…然后…最后…"说三个最关键的步骤（选车模 → 打印装配 → 配对跑起来）。
3. **最难的地方**（45 秒）："最难的是 ____，我试了 ____ 次，最后用 ____ 解决。"
4. **我还想改**（45 秒）："下一步我想让它 ____。"

家长只做两件事：计时、听完后问一个问题（"如果再来一次，你会先做什么？"）。
