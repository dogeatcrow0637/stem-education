# 家长话术与提问卡（拓竹 CyberBrick 模块化遥控套件）

| 字段 | 值 |
|---|---|
| 适用版本 | 硬件：入门套件 ZK004　／　软件：CyberBrick App |
| 最后更新 | 2026-10-20 |
| 前置条件 | 与 `02-里程碑与任务卡.md` 配套使用 |

> 目标：家长不讲课，只提问。孩子说出来，才算学会。每张卡至少问一次"为什么"。

## 1. 各阶段引导提问（每个里程碑选 3 个问）

| 里程碑 | 提问 |
|---|---|
| M0 采购 | 1）"我们要做的这个东西，你在哪见过真的？" 2）"这两套差在数量还是差在功能？" 3）"第一批只买必须的，你猜哪些可以先不买？" |
| M1 结构件 | 1）"这些零件是打印机一层一层堆出来的，你猜是怎么堆的？" 2）"手推一边轮子，另一边为什么反向转？" 3）"为什么活动的地方不能用最脆的那种料？" |
| M2 通电配对 | 1）"通电以后灯是什么颜色？它在说什么？" 2）"手机怎么'看见'车里这块板的？" 3）"黄灯亮说明什么连上了？" |
| M3 跑起来 | 1）"我推摇杆，命令从哪出发、经过谁、最后到哪？" 2）"如果车往后跑，是哪两根线的事？" 3）"一个轮转一个不转，先查什么？" |
| M4 改造 | 1）"你想让它多一个什么本事？" 2）"改哪个参数最容易看出差别？" 3）"怎么证明你的改动有效？" |

## 2. 孩子常问的"为什么"与答法

| 孩子的问法 | 一句话答法 |
|---|---|
| 为什么不能直接用手推着玩？ | "手推它不听你指挥；我们要让它自己会听摇杆的。"
| 为什么插反了会坏？ | "电和水一样，倒着流会把里面的零件冲坏。"
| 为什么打印要好几个小时？ | "打印机是用细细的塑料丝一层层画出来的，画得慢但很准。"
| 为什么要有电池不用插头？ | "因为它要在地上跑，拖着一根线就跑不开了。"
| 为什么遥控和车要先'牵手'？ | "它们要用同一个频道说悄悄话，没牵上手就互相听不见。"
| 为什么不能一步做完？ | "大楼也是一层一层盖的，我们先盖第一层。"

## 3. 本项目术语生活类比表

| 术语 | 生活类比 | 一句话解释 |
|---|---|---|
| 核心板 | 大脑 | 车和遥控器的"指挥部"。 |
| 免焊模块 | 乐高插头 | 插上就用，不用焊接。 |
| 电机 | 会转的小马达 | 通电就转，车靠它跑。 |
| 舵机 | 会拐弯的小胳膊 | 能停在你指定的角度。 |
| 电池 / 电压 | 水塔 / 水压 | 电的压力够，机器才转得动。 |
| 2.4G 遥控 | 对讲机频道 | 遥控器和车用同一个频道通信。 |
| 蓝牙 | 手机连耳机的线（没线的那种） | 用来配置，不是用来开车的。 |
| 差速器 | 转弯时两只脚迈不一样的步 | 让左右轮转速不同，车才好转弯。 |
| PWM 调速 | 水龙头开大开小 | 不是开关，而是调"多大劲"。 |
| WS2812 灯 | 会变色的糖豆 | 一颗就能变很多颜色。 |
| 3D 打印 | 用奶油一层层挤蛋糕 | 一层层堆出立体零件。 |
| MicroPython | 给大脑写的便条 | 用它给核心板下自定义指令。 |

## 4. 收尾 20 秒复盘（每张卡结束必做）

1. "今天成功的标志是什么？"
2. "哪里最麻烦？"
3. "下次想改哪里？"

## 5. 关键话术（直接抄）

- 交付动作："你负责拧螺丝和插线，我负责送电。危险的那步我一个人做，你在旁边看着。"
- 卡住时："先只找一件事：这一步和上一张卡比，哪里不一样？"
- 失败时："失败很正常，工程师每天在试。记下现象，下一张卡第一件事就查它。"
- 拒绝代劳："我可以说怎么做，但手是你的——所以你才是这台车的作者。"
- 升档："这张卡我不动手，你来做，我叫你才帮。"
