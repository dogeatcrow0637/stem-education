## 三、选型对比：CyberBrick 与同类方案

| 对比项 | **CyberBrick（本项目）** | 循迹小车（02） | reBot-DevArm 机械臂（01） |
|---|---|---|---|
| 主控 | ESP32-C3 + MicroPython | Arduino UNO R3（C++） | 上位机 Ubuntu + CAN 伺服 |
| 焊接 | **不需要** | 不需要 | 需要（线束/端子） |
| 3D 打印 | **必需**（全部结构件） | 可选（可跳过外壳） | 必需（打印件 + 金属件） |
| 第一次"它动了" | 装完车 + App 配对，1–2 天 | 半天 | 1–3 天 |
| 编程起点 | App 拖滑块（零代码） | 积木编程 / Arduino IDE | Python SDK / MoveIt |
| 成本量级 | ￥300–360 + 耗材 | ￥65–100 | 约 ￥6000 |
| 学到的核心概念 | 结构-电驱-信号三段闭环、PWM、差速、无线链路 | 传感器-判断-动作闭环 | 运动学、总线、伺服标定 |
| 最大门槛 | 有没有 3D 打印机 | 阈值标定 | 成本与装配量 |

结论：**想让小学生第一次就有"我造的玩具真的跑起来了"的成就感，CyberBrick 是三个项目里体验最好的一条**；它把"结构设计"这一维也交给孩子（选模型、选颜色、选耗材），这是小车上没有的。

## 四、下单检查表（照着勾）

- [ ] 确认套件编号是 **ZK004**（1 车 1 遥控），不是 ZK006（只有车、没遥控）
- [ ] 混色 / 型号一旦确认就固定，不要中途换档（会缺件）
- [ ] 耗材选 **PLA Basic 或 PETG**；活动件不要 PLA Lite
- [ ] 同时确认：**充电器是官方 7.4V XH2.54 款**，家里没有 5V 以上快充头插它
- [ ] 无打印机时，先问好代打的**单价与交期**，再把 4 盘件一起发过去
- [ ] 模型页面的 **BOM 里额外需要的件**（常出现"另需 1 微动开关 / 1 单通道摇杆 / 第三方舵机"）提前买齐，别等装到一半
