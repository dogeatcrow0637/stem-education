## 上课与构建

```bash
# 一次构建全部课时（--strict 有告警就报错，可当自检门禁）
python3 .trae/skills/stem-project-onboarding/scripts/build_slides.py projects/sesame-robot/docs/儿童课程/*/课件.md --strict
```

双击 `课件.html` → 浏览器按 `F` 全屏、`←→` 翻页、`N` 看讲者备注、`Ctrl+P` 导出 PDF 当讲义。

## 课程节奏（每课 45 分钟）

| 环节 | 时长 | 做什么 |
|---|---|---|
| 暖场 | 5 分钟 | 看 10 秒现象/视频，孩子说看到了什么 |
| 主体 | 30 分钟 | 一张任务卡：讲一步、做一步、验一步 |
| 收尾 | 10 分钟 | 3 个复盘问题 + 发知识卡 + 预告下一课 |

## 目录约定

- 一课一个目录，固定命名 `第NN课-课题`；
- 每课内固定件：`课件.md`（源）、`课件.html`（放映）、`图/`（配图）、`知识卡/`（本课发的卡）、`README.md`（课时卡）；
- 换成本工位实拍照片：覆盖本课 `图/` 下的同名文件即可，课件 md 不用改；
- 加一课：按现有结构新建 `第NN课-课题/`，再在 [`../05-教学与课程.md`](../05-教学与课程.md) 的课时表登记一行。
