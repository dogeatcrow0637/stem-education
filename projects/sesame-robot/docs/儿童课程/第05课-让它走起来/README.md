# 第05课-让它走起来

> 一课时 45 分钟（暖场 5 / 主体 30 / 收尾 10）　|　状态：课件已就绪
> 本目录 = 这一课的完整材料包：课件 + 配图 + 知识卡，拷走就能上课。

## 本课目标与可见成果

- **目标**：理解步态是 8 个舵机按顺序摆角，调一个参数观察变化。
- **可见成果**：连续走 10 秒不摔，能前进、转向、停止。
- **注意**：先站再走；一次只改一个参数。
