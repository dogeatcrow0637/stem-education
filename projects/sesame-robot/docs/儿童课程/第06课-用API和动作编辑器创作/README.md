# 第06课-用API和动作编辑器创作

> 一课时 45 分钟（暖场 5 / 主体 30 / 收尾 10）　|　状态：课件已就绪
> 本目录 = 这一课的完整材料包：课件 + 配图 + 知识卡，拷走就能上课。

## 本课目标与可见成果

- **目标**：用一条 HTTP 请求让机器人做动作，并说清请求→固件→舵机。
- **可见成果**：返回 status: ok，动作/表情正确；能讲 3 分钟作品展示。
- **注意**：固件无鉴权、无 HTTPS；只连可信局域网，不接公网。
