# 第01课-认识四足机器人

> 一课时 45 分钟（暖场 5 / 主体 30 / 收尾 10）　|　状态：课件已就绪
> 本目录 = 这一课的完整材料包：课件 + 配图 + 知识卡，拷走就能上课。

## 本课目标与可见成果

- **目标**：能指着机器人说出 4 条腿、8 个舵机、主控和屏幕的位置。
- **可见成果**：用仿真器演示站立/行走/挥手，孩子能指出哪条腿在动。
- **注意**：本课只用仿真 + 成品演示，不碰烙铁和锂电。
