## 本课目标与可见成果

- **目标**：看懂接线图和端子表，完成电源轨、8 路信号、OLED 与开关。
- **可见成果**：线束两端标好 S0–S7；万用表查 5V 轨对 GND 不短路。
- **注意**：⚠️ 焊接与首次送电由家长执行，孩子只做对号、记录、检查。
