# 01 · 项目简介

> 适用版本：上游 `main` @ `f328ed3`（2026-10-15），硬件方案 S2 Mini 手接线 / Distro V3.1　|　最后更新：2026-11-05　|　前置条件：无（但建议先完成循迹小车）

## 这是什么

Sesame Robot 是一台全开源的迷你四足机器人：ESP32 主控、8 个 MG90S 舵机（每条腿 2 个）、128×64 OLED 表情屏、WiFi 网页控制与 RESTful JSON API，外壳全部 3D 打印，上游采用 Apache-2.0 许可。

它解决的问题：把“多舵机协同 + 步态 + 电源管理 + 网络控制”这条足式机器人入门链路，压到 **￥400–700** 和 **2–4 个周末** 的量级。相比六轴机械臂，它没有昂贵的总线电机和复杂的标定工具；相比循迹小车，它多了 8 个关节的协同、重心转移和开环控制的不确定性，正好是“从会接线到会调系统”的台阶。

## 能做什么

| 能力 | 说明 |
|---|---|
| 四足行走 | 前进、后退、左转、右转、停止；步态由 8 个舵机角度序列配合完成 |
| 多种姿势 | `rest`、`stand`、`wave`、`dance`、`swim`、`point`、`pushup`、`bow`、`shrug` 等（见 `movement-sequences.h`） |
| 表情屏 | 0.96" OLED 显示像素表情，可随动作切换，支持自定义位图 |
| 网页遥控 | 手机/电脑连机器人热点，浏览器打开控制页即可操作 |
| JSON API | `GET /api/status`、`POST /api/command`，可用 Python / JavaScript / Home Assistant 调用 |
| 动作编排 | Sesame Studio 可视化摆姿势、串帧、生成 C++ 角度代码 |
| 浏览器仿真 | 无需实物即可调试步态与运动学参数（社区项目） |
| 二次开发 | 改表情、加动作、接传感器、做强化学习实验 |

## 关键参数

| 参数 | 值 |
|---|---|
| 主控 / 平台 | Lolin S2 Mini（ESP32-S2，DIY 推荐）或 Sesame Distro Board V3.1（ESP32-S3，SMD，预烧录套件） |
| 执行器 | 8× MG90S 金属齿 **180°** 舵机（髋 + 膝，每条腿 2 个） |
| 显示 | 0.96" SSD1306 I2C OLED，128×64 |
| 供电 | 5V/3A 以上；USB-C PD 或 2×14500 7.4V 锂电池 + 5V 降压 |
| 通信 | WiFi 2.4GHz；AP 模式 `Sesame-Controller-BETA` / `192.168.4.1`；STA 模式 `sesame-robot.local` |
| 结构 | 11 个 PLA 打印件（内部框架、上下盖、R1–R4/L1–L4 关节） |
| 舵机 PWM | 50Hz；0–180° 映射 732–2929μs；`motorCurrentDelay` 默认 20ms 错峰 |
| 整机尺寸 / 重量 | `待验证`（随打印材料、电池方案变化） |
| 续航 | `待验证`（与电池容量、步态、舵机质量强相关） |
| 控制方式 | 纯开环，无舵机位置/速度反馈；地面打滑或负载变化不能自动纠正 |

## 教学价值与目标人群

**适合谁**

- 10–14 岁、已经完成循迹小车或 CyberBrick 的孩子（L1 观察 / L2 协作 / L3 独立三档自适应）。
- 想从“单电机/单传感器”升级到“多关节协同”的家庭。
- 愿意花 2–4 个周末，且家里有一位能负责焊接、锂电和上电的成人。

**不适合谁**

- 第一次接触 STEM、还没有“传感器 → 主控 → 执行器”概念的孩子。
- 希望“一节课做完、当堂跑起来”的课堂——这个项目做不到。
- 不能接受 3D 打印公差、舵机一致性和反复校准的家庭。

**教学目标**

1. 能说出四足机器人的基本组成：主控、舵机、电源、结构、通信。
2. 能独立完成零件分类、腿部装配、舵机编号与线束整理。
3. 能在家长监护下完成通电、校准，让机器人稳定站起。
4. 能解释“步态是 8 个舵机按顺序摆角度”，并调一个参数观察变化。
5. 能用一条 HTTP 请求让机器人做动作，并说清“请求 → 固件 → 舵机”的链路。

**前置知识**：认识正负极、会拧 M2 螺丝、知道“程序控制电机”即可。焊接、锂电、烧录由家长完成或外包。

## 在课程体系里的位置

| 顺序 | 项目 | 关系 |
|---|---|---|
| 第 1 站 | `line-follower-car` | 感知 → 判断 → 动作，￥100，不焊接，最适合第一课 |
| 第 2 站 | `cyberbrick` | 无线遥控、结构搭建、3D 打印入门 |
| 第 3 站 | `sesame-robot` | 多舵机协同、步态、电源、API，进阶项目 |

> **本项目不作为整个 STEM 合集的第一课。** 第 1 课只做“仿真 + 成品演示”，不碰烙铁和锂电；完整装配拆到第 2–6 课。

## 投入与风险提示

| 项 | 量级 | 备注 |
|---|---|---|
| 硬件成本 | ￥400–700 | S2 Mini 手接线方案，不含电烙铁/万用表等工具；成品 V3.1 板更高 |
| 家长工时 | 约 12–20 小时 | 采购、打印、焊接、装配、校准、调步态；分 6 课时 |
| 日历周期 | 2–4 周 | 主要取决于打印和快递 |
| 主要风险 | 中 | 焊接烫伤、锂电充放电、8 舵机启动电流导致复位、打印公差、开环控制走不稳 |
| 可外包 | 高 | 3D 打印代做、PCB 贴片/手接线代焊、固件代烧；家长只做装配与陪玩 |
| 不确定项 | `待验证` | 国内到手价、整机重量、续航、不同批 MG90S 的一致性 |

## 验收标准（项目级）

- [ ] 11 个打印件齐全，关键孔位能装配，无严重翘边/层裂。
- [ ] 8 个舵机逐个测试，方向与编号正确，无堵转异响。
- [ ] 上电后 OLED 亮、WiFi 热点出现、网页控制页可打开。
- [ ] `REST` / `STAND` 校准后，四条腿呈镜像“X”形，能稳定站立。
- [ ] 能连续完成前进、后退、左转、右转、停止各 2 次。
- [ ] 能用 `curl` 或 Python 发送一条 `POST /api/command` 并看到动作。
- [ ] 孩子能用自己的话讲清“一条指令怎么变成 8 个舵机的动作”。
