## 2. 失败排查表（按顺序查，不要跳）

| 现象 | 最可能原因（按概率排序） | 先查什么 |
|---|---|---|
| 上电无任何反应 | USB 线只供电 / 板型选错 / 5V 短路 / 开关未开 | 换确认能传数据的线 → 核对 LOLIN S2 Mini → 万用表查 5V 轨对 GND |
| 灯亮但 OLED 不亮 | SDA/SCL 接反 / I2C 地址不对 / 供电不足 | 对照 GPIO33(SDA)、GPIO35(SCL) → 只接 OLED 上电 → 缩短线 |
| 串口看不到板 | 驱动缺失 / `USB CDC On Boot` 未开 / 线只供电 | 开了 CDC 再复位 → 装 CP210x/CH340 → 换线 |
| 上传成功但不断重启 | 5V 跌压 / 舵机堵转 / 库版本不对 | 断舵机再试 → 换 5V/3A → 确认 `ESP32Servo 3.0.9` |
| 插一个舵机就重启 | 电源峰值不够 / 舵机堵转 / `motorCurrentDelay` 太小 | 换 5V/3A → 空载测该舵机 → 把延迟调回 20–25ms |
| 动一个舵机带动好几个 | 升级了 `ESP32Servo` 高版本 / 引脚表选错 / 排针焊桥 | 卸载重装 3.0.9 → 确认只启用 S2 Mini 引脚表 → 查排针桥连 |
| 舵机抖动或嗡嗡响 | 机械干涉 / 角度超程 / 舵机质量差 | 断电手动盘腿 → 减小角度 → 换备件 |
| 走路原地打转 | 左右腿编号或镜像件装错 | 对照 `REST`/`STAND` 重装 → 查 S0–S7 |
| 走两步就趴下 | 重心偏 / 脚垫打滑 / 电池电压低 | 调站姿 → 加脚垫 → 换满电电池 |
| 网页打不开 | 手机走移动数据 / 没连热点 / AP 隔离 | 关移动数据 → 直接输 `192.168.4.1` → 关 AP 隔离 |
| 网页能开但按钮无反应 | 请求走蜂窝网络 / 页面缓存 / API 用 GET | 关移动数据 → 强制刷新 → 用 POST + JSON |
| 合盖后不开机 | 顶盖压到线或开关 | 断电开盖 → 查裸线与开关行程 |
| 打印件装不上 | 公差 / 支撑残留 / 镜像件装反 | 清支撑 → 轻回牙或铜螺母 → 核对镜像件 |

### 排查顺序（口诀）

**先电源 → 再接地 → 再编号 → 再固件 → 最后才怀疑代码。** 不要一上来重烧固件；90% 的"腿方向反"是插错编号。

## 3. 作品展示脚本（让孩子讲 3 分钟）

1. **它是什么**（30 秒）："这是我做的 Sesame 四足机器人，它有 8 个舵机、会走会挥手，还能显示表情。"
2. **怎么做的**（60 秒）：按"先…然后…最后…"说三个最关键的步骤（装腿 → 接线 → 校准站立）。
3. **最难的地方**（45 秒）："最难的是校准，我试了（孩子填：几次），最后用（REST/STAND 对齐）解决。"
4. **我还想改**（45 秒）："下一步我想让它（孩子填：走得更稳 / 加避障 / 做新表情）。"

家长只做两件事：计时、听完后问一个问题（"如果再来一次，你会先做什么？"）。
