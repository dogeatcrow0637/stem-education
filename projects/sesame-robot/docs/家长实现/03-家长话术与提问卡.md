# 家长话术与提问卡（Sesame Robot 迷你四足机器人）

| 字段 | 值 |
|---|---|
| 适用版本 | 上游 `main` @ `f328ed3`；硬件 S2 Mini 手接线（MVP） |
| 最后更新 | 2026-11-05 |
| 前置条件 | 与 `02-里程碑与任务卡.md` 配套使用 |

> 目标：家长不讲课，只提问。孩子说出来，才算学会。每张卡至少问一次"为什么"。

## 1. 各阶段引导提问（每个里程碑选 3 个问）

| 里程碑 | 提问 |
|---|---|
| M0 定稿与采购 | 1）"我们要做的这个东西，你见过真的吗？在哪见过？" 2）"手接线版和成品板，哪个贵、差在哪？" 3）"第一批只买必须的，你猜哪些可以先不买？" |
| M1 通电自检 | 1）"通电以后你看到了什么？" 2）"如果灯不亮，可能是哪三个原因？" 3）"为什么上电的时候手要离开腿？" |
| M2 单模块能动 | 1）"刚才是谁让这个舵机动的？命令从哪来？" 2）"让它从 90° 转到 180°，会发生什么？先猜再试。" 3）"它动的时候有嗡嗡声，说明什么？" |
| M3 完整链路 | 1）"你点一下网页按钮，命令经过谁才到腿上？" 2）"如果电脑认识不到它，先查什么？" 3）"为什么四个髋关节要摆成 X 形？" |
| M4 自主创作 | 1）"你想让它多一个什么本事？" 2）"改哪个参数最小、最容易成功？" 3）"怎么证明你的改动有效？" |

## 2. 孩子常问的"为什么"与答法

| 孩子的问法 | 一句话答法 |
|---|---|
| 为什么它有 8 个舵机，不是 4 个？ | "每条腿有髋和膝两个关节，4 条腿 ×2 = 8 个，关节越多动作越多。" |
| 为什么不能直接用手掰？ | "手掰会让里面的塑料/金属齿轮受力，容易扫齿；要让它自己走到角度。" |
| 为什么插一个舵机就重启？ | "8 个舵机一起启动像 8 个人同时抢水喝，电压一下被拉低，板子就重启了。" |
| 为什么走路会抖、会摔？ | "它是开环的，没有'感觉'自己腿在哪，只能按预设角度走，地面滑就会出错。" |
| 为什么要先校准再锁螺丝？ | "校准前齿轮可以自由对位，锁死了就再也对不齐了。" |
| 为什么手机连了热点还打不开网页？ | "手机可能还在用流量，先关掉移动数据，再输 192.168.4.1。" |
| 为什么仿真里能走、真机不行？ | "仿真没有地面摩擦、齿轮回差和电池跌压，真机要再调。" |
| 为什么不能一步到位？ | "8 个关节要排队配合，先让一个动，再让四个站，最后才走。" |

## 3. 本项目术语生活类比表

| 术语 | 生活类比 | 一句话解释 |
|---|---|---|
| 舵机 | 会数角度的胳膊 | 收到信号就转到指定角度并保持的小电机 |
| 髋关节 / 膝关节 | 肩膀 / 膝盖 | 每条腿两个关节：髋管前后摆，膝管抬落 |
| PWM | 敲桌子的节拍 | 用固定频率的脉冲宽度告诉舵机转到哪 |
| 中位（90°） | 立正站好 | 舵机行程正中间的位置，校准从这里开始 |
| 开环控制 | 闭着眼按菜谱做菜 | 只按预设角度走，不回头检查实际到没到 |
| 步态 | 走路的舞步顺序 | 8 个舵机按顺序摆角，让四条腿交替落地 |
| 校准 | 校秤 | 让舵机的"0°"和结构真正对正，再锁螺丝 |
| 堵转 | 顶住转动的电风扇 | 舵机被卡住还继续用力，电流大、会发烫 |
| 降压模块 | 水管减压阀 | 把电池 7.4V 降到舵机要的 5V |
| 固件 | 小脑 | 烧进主控、负责协调舵机和网络的程序 |
| AP 热点 | 机器人自己开的 wifi | 机器人发出 `Sesame-Controller-BETA`，手机连它 |
| API | 点外卖的订单格式 | 按固定格式发一条消息，机器人看懂就执行 |
| JSON | 带标签的便签 | `{"command":"wave"}` 这种"键: 值"的写法 |
| I2C | 两根线的对讲机 | OLED 用 SDA/SCL 两根线跟主控说话 |

> 以上术语都要在对应课时的知识卡里出现；家长只需用类比开场，定义让孩子在卡上自己读。

## 5. 关键话术（直接抄）

- 交付动作："你负责对编号、递零件、按按钮，我负责焊接和上电。危险的那步我一个人做，你在旁边看着。"
- 卡住时："先只找一件事：这一步和上一张卡比，哪里不一样？"
- 失败时："失败很正常，工程师每天在试。记下现象，下一张卡第一件事就查它。"
- 拒绝代劳："我可以说怎么做，但手是你的——所以你才是这台机器的作者。"
- 升档："这张卡我不动手，你来做，我叫你才帮。"
- 遇到舵机抖："先别改程序，先断电用手轻轻盘一下腿，看是不是卡住了。"
