# 家长实现总纲（Sesame Robot 迷你四足机器人）

| 字段 | 值 |
|---|---|
| 项目编号 | 05 |
| 项目目录 | `projects/sesame-robot` |
| 适用版本 | 硬件：S2 Mini 手接线方案（MVP）/ Distro V3.1；软件：上游 `main` @ `f328ed3` |
| 最后更新 | 2026-11-05 |
| 前置条件 | 孩子已完成循迹小车或 CyberBrick 一类的入门项目；家里有一位能负责焊接、锂电和首次上电的成人；已备好 3D 打印件或代打渠道 |

> 本手册面向**完全零基础的家长**，用于带一名小学生从零把本项目做出来并讲明白。工程细节以 `projects/sesame-robot/docs/` 为准，本手册只讲"怎么带着孩子做"。

## 一句话目标

做完之后，孩子能独立完成的最小成果是：**让机器人稳定站起、连续走 10 秒不摔，并用一条 HTTP 请求让它挥手换表情**；能看到的现象是：OLED 亮起表情、手机连上热点后网页按钮能遥控四条腿。

## 这套手册怎么用

1. **先读安全红线**（本文件最后一节），再读 `05-安全与工具采购清单.md`。
2. 按 `02-里程碑与任务卡.md` 从头做；**一张卡一次坐下做，做完打勾再进下一张**。
3. 每张卡按孩子的实际水平选一档执行（同一项目不同环节可选不同档）：

| 档 | 孩子做什么 | 家长做什么 | 什么时候升档 |
|---|---|---|---|
| L1 观察 | 递零件、对编号、按按钮、说出看到的现象 | 全部动手 + 讲解 + 防护 | 孩子能说清"这步在做什么、成功会看到什么" |
| L2 协作 | 拧螺丝、插线、插拔 USB、填验收表 | 把关紧固与极性、执行危险步骤 | 同类动作无提示也能做对 |
| L3 独立 | 看图纸独立做、改参数、记录数据、讲原理 | 只做安全监护，允许失败 | 能讲清"上次为什么失败、这次改了什么" |

4. 需要**外包**的环节（家长不必自学）：3D 打印代做（￥80–150）、洞洞板手接线代焊（￥100–250）、固件代烧（￥0–50）。三项全外包也能完成，见 `05-安全与工具采购清单.md` 第 6 节。
5. 卡住了：先查 `04-验收与展示.md` 的失败排查表，再对照卡片里的"失败兜底"。

## 时间与预算

| 项 | 估算 | 说明 |
|---|---|---|
| 家长工时合计 | 12–20 小时 | 不含采购等待；含焊接、装配、校准、调步态与陪课 |
| 日历周期 | 2–4 周 | 建议每周 2–3 次，每次 ≤45 分钟；打印与快递是主要等待项 |
| MVP 预算（能跑通最小闭环） | ￥350–600 | 明细见 `05-安全与工具采购清单.md`；不含工具 |
| 全量预算（含扩展） | ￥400–700 | 国内实际落地区间；含电池方案取上限 |
| 可能的外协费 | ￥80–400 | 打印代做 ￥80–150；手接线代焊 ￥100–250；固件代烧 ￥0–50 |

## 场地、作息与收纳

- 工作台：**硬质桌面 + 防火垫**，通风、光线充足；焊接与上电测试必须在成人一臂范围内。
- 单次时长：≤ 45 分钟（2 张卡），每 3 张卡安排一次"展示时刻"。
- 收纳：10 个舵机按 S0–S7 + 备用分格；M2 自攻螺丝与 M2.5 机械螺丝分开；每次结束拍照记录当前状态；**断电断料再离开**。
- 走线：8 根信号线两端都贴 S0–S7 标签，避免"装到最后不知道哪根是哪根"。

## 安全红线（先读这一页）

1. 危险动作一律家长单独执行：**电烙铁焊接、锂电池连接与充电、首次上电、降压模块调压**。孩子保持一臂距离，只做分类、编号、记录和观察。
2. 上电前必须做的三件事：**① 万用表确认 5V 轨对 GND 不短路；② 机身放稳、运动范围清空；③ 手离开四条腿**。
3. 出现异常（异味 / 异响 / 冒烟 / 发烫 / 报错 / 反复重启）→ **立即断电**，再排查；不要边跑边查。
4. 详细清单见 `05-安全与工具采购清单.md`。

## 假设与已知限制

- 本文假设：家长不会焊接、不写代码、有一台能装 Arduino IDE 的电脑和一个 2.4GHz WiFi 环境；如不成立，可跳过对应外包项。
- 未验证项：整机重量、续航、国内到手价、不同批次 MG90S 的一致性（标 `待验证`，实测后更新）。
- 关键风险：8 舵机同时启动导致 5V 跌压重启；舵机中位未校准导致走路"抽筋"；孤品 MG90S 批次差异大；开环控制在地毯等软地面走不稳。
- 本项目的定位是**进阶项目**，不是整个 STEM 合集的第一课。第 1 课只做仿真 + 成品演示，不碰烙铁和锂电。
