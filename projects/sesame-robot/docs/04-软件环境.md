# 04 · 软件环境

> 适用版本：上游 `main` @ `f328ed3`；Arduino IDE 2.x　|　最后更新：2026-11-05　|　已验证操作系统：macOS 26.x、Windows 10/11（待实测回填）、Linux（待实测回填）

> 本项目**不需要** ROS、不需要虚拟机；但烧录和串口调试必须能访问 USB 设备。虚拟机/容器可能看不到开发板，建议用物理机。

## 一、环境要求

| 项 | 版本 | 说明 |
|---|---|---|
| 操作系统 | macOS 12+ / Windows 10+ / Linux | 需要能安装 Arduino IDE 与 USB 驱动 |
| 开发工具 | Arduino IDE **2.0+** | 1.8.x 也能用，但 2.x 的板管理器与库管理器更顺 |
| 开发板支持 | **ESP32 by Espressif Systems ≥ 2.0.0** | 在 Arduino IDE 板管理器安装 |
| 库 | `ESP32Servo` **v3.0.9**（锁定） | 更高版本有 8 舵机 PWM 通道串扰问题 |
| 库 | `Adafruit SSD1306`、`Adafruit GFX Library` | OLED 驱动 |
| 硬件接口 | USB-C 数据线 | 必须能传数据；很多充电线只能供电 |
| 网络 | 2.4GHz WiFi | ESP32 不支持 5GHz |

> 为什么锁 `ESP32Servo v3.0.9`：上游记录了更高版本在 8 舵机场景下“写一个通道影响多个通道”的缺陷（[issue #103](https://github.com/madhephaestus/ESP32Servo/issues/103)）。不要随手升级。

## 二、安装

### 2.1 安装 ESP32 开发板支持

1. 打开 Arduino IDE → **File → Preferences**。
2. 在 **Additional Board Manager URLs** 填入：
   `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
3. **Tools → Board → Boards Manager**，搜索 `ESP32`，安装 **ESP32 by Espressif Systems**（≥ 2.0.0）。

### 2.2 安装库

**Tools → Manage Libraries**，逐个安装：

| 库 | 版本 | 搜索名 |
|---|---|---|
| ESP32Servo | **3.0.9** | `ESP32Servo` |
| Adafruit SSD1306 | 最新稳定版 | `Adafruit SSD1306` |
| Adafruit GFX Library | 最新稳定版 | `Adafruit GFX Library` |

### 2.3 获取固件

上游不采用子模块；本项目**不复制**上游源码，避免后续无法合并。按 commit 拉取：

```bash
mkdir -p ~/sesame && cd ~/sesame
git clone https://github.com/dorianborian/sesame-robot.git
cd sesame-robot
git checkout f328ed35f5cbcbdd44a5e16e3ec679d2caa00d92
```

固件关键文件：

| 文件 | 作用 |
|---|---|
| `firmware/sesame-firmware-main.ino` | 主程序：PWM、网络、API、姿态调度 |
| `firmware/face-bitmaps.h` | OLED 表情位图 |
| `firmware/movement-sequences.h` | 动作/姿态序列 |
| `firmware/captive-portal.h` | 网页控制页 HTML/CSS/JS |
| `firmware/debugging-firmware/sesame-motor-tester.ino` | 单舵机测试与校准 |

## 三、烧录（S2 Mini 手接线）

### 3.1 开发板设置

| 设置项 | 值 |
|---|---|
| Board | **LOLIN S2 Mini** |
| Upload Speed | 921600 |
| USB CDC On Boot | **Enabled** |
| Partition Scheme | Default 4MB with spiffs |
| Port | 对应的 `/dev/cu.usbmodem*`（macOS）或 COM 口（Windows） |

### 3.2 选择引脚配置

打开 `sesame-firmware-main.ino`，在文件前部的引脚配置区：

- 使用 **S2 Mini**：取消 S2 Mini 的 `servoPins` 与 `I2C_SDA`/`I2C_SCL` 注释，注释掉 V1/V2/V3。
- 使用 **V3.1 板**：取消 V3 配置注释，注释掉其他。
- 不要同时启用两组引脚表。

### 3.3 烧录步骤

1. USB-C 连接开发板。
2. 打开 `sesame-firmware-main.ino`（确保所在文件夹同名，且同目录有全部 `.h`）。
3. 选择板型、端口与上表参数。
4. 点击 **Upload**。
5. 打开串口监视器，波特率 **115200**；复位板子，应看到启动日志与网络信息。

> 上传失败时：按住 **BOOT** 再点 Upload；换一根确认能传数据的线；S3 板确认 `USB CDC On Boot` 已启用。

## 四、联网与控制页

### 4.1 默认 AP 模式（推荐第一课使用）

| 项 | 值 |
|---|---|
| SSID | `Sesame-Controller-BETA` |
| 密码 | `12345678` |
| 机器人 IP | `192.168.4.1` |

手机/电脑连上热点后，浏览器打开 `http://192.168.4.1/`；如果 captive portal 没弹出，直接输地址。**手机要关闭移动数据**，否则请求会走蜂窝网络。

### 4.2 接入家庭 WiFi（可选）

方式一：在网页 **Settings → WiFi / Network** 里扫描并连接 2.4GHz 网络（凭据不持久化，重启后回到 AP 模式）。
方式二：编译期写死：

```cpp
#define NETWORK_SSID "YourNetworkName"
#define NETWORK_PASS "YourPassword"
#define ENABLE_NETWORK_MODE true
```

连接成功后可用 `http://sesame-robot.local` 或串口打印的 IP 访问。

> ⚠️ 安全：固件默认**没有鉴权、没有 HTTPS**。只连可信局域网，不要把机器人暴露到公网；默认 AP 密码建议改掉。

## 五、API 速查

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/status` | 查询当前命令、表情、网络状态 |
| POST | `/api/command` | 下发动作/表情，JSON 请求体 |
| GET | `/cmd?go=forward` | 旧版移动接口（forward/backward/left/right/stop） |
| GET | `/cmd?pose=wave` | 旧版姿态接口 |
| GET | `/cmd?motor=1&value=90` | 单舵机测试（1–8） |
| GET | `/getSettings` | 读取参数 |
| GET | `/setSettings?frameDelay=120&walkCycles=15&motorCurrentDelay=25&faceFps=10` | 修改参数 |

### 5.1 示例

```bash
# 查询状态
curl http://192.168.4.1/api/status

# 挥手 + 开心表情
curl -X POST http://192.168.4.1/api/command \
  -H "Content-Type: application/json" \
  -d '{"command":"wave","face":"happy"}'

# 只换表情，不动
curl -X POST http://192.168.4.1/api/command \
  -H "Content-Type: application/json" \
  -d '{"face":"excited"}'

# 停止
curl -X POST http://192.168.4.1/api/command \
  -H "Content-Type: application/json" \
  -d '{"command":"stop"}'
```

```python
import requests

BASE = "http://192.168.4.1"  # 或 http://sesame-robot.local
print(requests.get(f"{BASE}/api/status", timeout=3).json())
requests.post(f"{BASE}/api/command", json={"command": "wave", "face": "happy"}, timeout=3)
```

可用动作：`forward`、`backward`、`left`、`right`、`stop`；姿态：`rest`、`stand`、`wave`、`dance`、`swim`、`point`、`pushup`、`bow`、`cute`、`freaky`、`worm`、`shake`、`shrug`、`dead`、`crab`。完整列表以 `movement-sequences.h` 为准。

## 九、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 串口看不到板 | 线只供电、驱动缺失、USB CDC 未开 | 换数据线；装 CP210x/CH340 驱动；开启 USB CDC On Boot |
| Linux 权限拒绝 | 用户不在 `dialout` 组 | `sudo usermod -a -G dialout $USER`，重新登录 |
| 上传成功但不断重启 | 供电不足、舵机堵转、V3 初版缺陷 | 断舵机再试；换 5V/3A；确认 V3.1 |
| 连不上 WiFi | 用了 5GHz、密码错、路由器隔离 | 换 2.4GHz；关 AP 隔离；看串口日志 |
| `sesame-robot.local` 不解析 | mDNS 被路由器屏蔽/系统无 Bonjour | 直接用串口打印的 IP |
| API 返回 404 | 用了 GET 调 `/api/command` | 必须 POST + `Content-Type: application/json` |
| 动作执行一半停 | 网络超时、舵机电流不足、`frameDelay` 太小 | 靠近 AP；加大 `motorCurrentDelay`；降低速度 |
| 网页按钮无反应 | 手机走移动数据、页面缓存 | 关移动数据；强制刷新；换浏览器 |
