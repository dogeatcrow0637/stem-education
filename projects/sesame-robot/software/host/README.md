# host · Web 控制页 / 上位机

Sesame 的“上位机”就是固件内置的网页控制页，不需要在电脑上安装软件。

## 连接

1. 机器人上电，等待 10–20 秒。
2. 手机/电脑连接 WiFi：`Sesame-Controller-BETA`，密码 `12345678`。
3. 浏览器打开 `http://192.168.4.1/`；若 captive portal 没弹出，直接输地址。
4. **关闭手机移动数据**，否则请求可能走蜂窝网络。

## 页面功能

| 区域 | 用途 |
|---|---|
| 方向按钮 | 前进/后退/左转/右转/停止 |
| 姿态按钮 | `rest`、`stand`、`wave`、`dance` 等 |
| 表情 | 切换 OLED 表情 |
| Settings | `frameDelay`、`walkCycles`、`motorCurrentDelay`、`faceFps` |
| WiFi / Network | 扫描并接入 2.4GHz 家庭网络（不持久化） |

## 验证

| 检查 | 通过标准 |
|---|---|
| 页面加载 | 出现控制按钮与设置区 |
| 姿态 | 点 `stand` 能站起，点 `rest` 能趴下 |
| 移动 | 点前进能走，点停止能立即停 |
| 设置 | 改 `motorCurrentDelay` 后保存，再读回一致 |
| 状态 | `/api/status` 返回当前命令与表情 |

## 常见问题

| 现象 | 处理 |
|---|---|
| 页面打不开 | 关移动数据；确认连的是机器人热点；换浏览器 |
| 按钮无反应 | 看串口日志；确认没在充电/重启循环 |
| 设置保存后丢失 | 编译期网络配置才持久化；网页 WiFi 凭据重启即失效 |
| 页面很卡 | 靠近机器人；减少同时连接的设备；2.4GHz 干扰 |
