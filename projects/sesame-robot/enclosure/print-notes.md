> 上游明确：PLA、8–10% 填充、2 圈壁厚；顶盖支撑是唯一必须手动处理的件。不要为了方便把填充拉到 30% 以上——会增加重量和舵机负担。

## 3. 顶盖支撑（唯一需要手动处理）

- 支撑类型：Normal / Manual。
- 只在悬空的面/槽位加支撑，不要全件包支撑。
- 加 brim（外圈）防翘边。
- 拆支撑后用尖嘴钳+美工刀清理，重点清理 OLED 槽、开关孔、磁吸帽位。

## 4. 后处理与装配顺序

1. 去支撑、修毛边；关键孔位用 M2 螺丝手拧试牙。
2. 关节按 R/L 分堆，左右镜像不要混。
3. 舵机装入腿壳（轴朝外、线从侧槽出）。
4. 髋关节盘先不锁，等 `REST`/`STAND` 校准后再锁。
5. OLED/开关装入顶盖；线束用扎带分组。
6. 框架装电池仓、侧舵机、主控/洞洞板；线走上侧。
7. 合顶盖/底盖，贴脚垫。

**完成判断标准**：手动转动关节无干涉；顶盖能自然扣合不夹线；螺丝无滑牙。

## 5. 易错点

| 现象 | 原因 | 规避 |
|---|---|---|
| 螺丝一拧就滑牙 | M2 自攻过拧 | 手拧到位即可；电动批调低扭矩 |
| 关节装反 | R/L 镜像混 | 按编号分堆；装前对图 |
| 顶盖扣不上 | 线束太厚/走线不对 | 线分左右两束，压进线槽 |
| OLED 装不进 | 支撑残留/尺寸公差 | 清槽；轻磨 0.1–0.2mm |
| 舵机装不进腿壳 | 打印收缩/毛边 | 清毛边；必要时轻磨；不要暴力敲 |
| 打印件开裂 | 层高/温度/填充不足 | 0.2mm、2 墙、8–10% 蜂窝；检查耗材受潮 |

后处理：去支撑、清孔；不要攻丝（M2 自攻）
