# software · 40cm 背滤海缸（小丑鱼练手版）

本项目**无程序化软件**：设备靠硬件插座自动控制，数据靠手填记录。

| 子目录 | 内容 |
|---|---|
| [`host/`](host/) | 水质记录表模板 + 可选智能插座 App 说明 |
| [`sdk/`](sdk/) | 不产出（无二次开发接口） |
| [`tools/`](tools/) | 不产出（无烧录/标定/仿真需求） |

## 约定

1. 记录模板保持"打印即用"，不要求家长装软件。
2. 不引入需要维护的代码；能把事情用插座和纸笔解决的，就不写程序。
3. 若以后 DIY 控制器，请新开项目，不要污染本项目结构。
