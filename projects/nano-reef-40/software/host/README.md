# host · 记录与（可选）设备控制

本项目**没有上位机程序**，`host/` 只放两样东西：给家长手填的记录模板，以及可选的智能插座 App 说明。

| 文件 | 说明 |
|---|---|
| [`水质记录表.md`](水质记录表.md) | 打印贴缸边，开缸期每 2 天一行、养水后每周一行 |
| [`water_log.csv`](water_log.csv) | 电子版，导入表格软件可画氨氮曲线 |

## 设备自动化不用写代码

灯与加热棒靠**硬件插座**控制（定时插座 / 温控插座），详见 [`../../docs/04-软件环境.md`](../../docs/04-软件环境.md)。

## 约定

- ⚠️ **不要**用智能插座控加热棒：断电是安全，误开是危险。加热棒只走独立温控插座。
- 记录**不许补编数字**；漏测写"缺"。
