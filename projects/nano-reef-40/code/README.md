# code · 本项目无算法代码

> 本项目不写算法。`code/` 只放**给孩子看的数据整理小工具**（可选）。

如果需要，可以放：

- 把 [`../software/host/water_log.csv`](../software/host/water_log.csv) 画成折线的 notebook（Python + pandas + matplotlib）
- 一个"盐度换算表"小脚本：输入读数与温度，输出 ppt 值

## 约定

1. 每个子目录一个 `README.md`：目的、输入、输出、运行命令、依赖。
2. 代码保持极简，能让孩子看懂每一行。
3. 不引入重依赖；能用表格软件做的，就不写代码。
