# enclosure · 40cm 背滤海缸（小丑鱼练手版）

本项目的结构件**几乎全部买成品**（缸、蛋分、泵都是市售件）。`enclosure/` 只放**可选 3D 打印件**，练习建模与打印用，不是开缸必需。

| 子目录 | 内容 | 格式 |
|---|---|---|
| `step/` | 可编辑源文件 | STEP、F3D、FreeCAD |
| `stl/` | 可直接切片打印 | STL、3MF |

命名规则：`件名_版本_数量.stl`（例：`防跳网框_v1.0_x1.stl`）。

- 打印参数与装配顺序统一写在 [`print-notes.md`](print-notes.md)。
- ⚠️ **不要打印任何泡在水里的承力件**（长期泡海水会析出、变脆、变形）。
- 代打渠道：嘉立创 3D 打印 / 淘宝代打，传 STL 按克计价（见 `docs/02-选型与BOM.md` 的实现路径）。
- 切片产物 `.gcode` 不入库（见仓库 `.gitignore`）。
