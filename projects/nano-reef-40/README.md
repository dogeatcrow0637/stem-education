# 40cm 背滤海缸（小丑鱼练手版）

> 一句话定位：在书房里，带小朋友从零开一口 **40cm 背滤小海缸**——只养 **1–2 条小丑鱼**，珊瑚只挑闪千手/纽扣/菇类这些"新手款"。**器材到手约 ￥741、首缸成型约 ￥866**，是千元级就能养起的下海入门方案。

## 为什么改小：一句话说清

大水体的好处是"容错高"，坏处是"样样都贵"。**40 方小缸把水体从 130–150L 降到 45–55L，器材、盐、水、电费同步降一半，代价是只能养 1–2 条小丑、水质波动更快、每周必须换水。**

> 生物目标是活的，不能讨价还价：40 方水体 45–55L，养 **1–2 条小丑鱼**是合理上限。硬放 4–5 条，鱼会打架、水质会崩。

### 三段式花钱节奏（避免一次性掏太多）

1. **今天下单 ￥849**：只买开缸必备，先把缸养上水。
2. **同批加 ￥55**：养水期测氨氮、亚硝酸盐，不能靠眼睛看。
3. **第 4–8 周再 ￥220**：水质合格才买鱼和珊瑚——**先清洁队，后下鱼，最后珊瑚**。

## 能力与参数

| 参数 | 值 |
|---|---|
| 缸体 | 40×40×40cm 超白玻璃**背滤**缸，背滤仓宽 10–12cm（3 格） |
| 系统水量 | 约 45–55L（含背滤仓、扣除造景石体积） |
| 目标水质 | 盐度 1.024–1.026（32–35 ppt）、25–26℃、KH 7–9、NO₃ < 10ppm、PO₄ < 0.1ppm |
| 循环与水流 | 回水泵 600–1200 L/h + 小型造浪 1 个（软珊瑚中等水流，8–15 倍/h） |
| 生物目标 | 小丑鱼 **1–2 条**；珊瑚：闪千手、纽扣、菇类 |
| 开缸周期 | 养水 4–8 周，之后每 2 周加一批生物 |
| 维护节奏 | 每日 3 分钟看护 · **每周换水 10%** · 每 2 周洗一次蛋分 |
| 家长工时 | 开缸首次 4–6 小时 + 每周 15 分钟 |

> ⚠️ **三条必须记住的现实提醒**
> 1. **小缸水质变化快**。水体小，一点脏东西浓度就上去了。每周 10% 换水是硬指标，不是可选项。
> 2. **两条小丑鱼要"体型差"**。挑一条明显大、一条明显小，同时入缸，才不容易打成生死仇。
> 3. **纽扣珊瑚有毒（palytoxin）**。必须戴手套、别碰眼睛、缸边常备肥皂水；有小孩的家庭把纽扣放在孩子够不到的位置，操作时家长单独做。

## 以后想换大缸（一句话）

**先按 40 方练手。** 养满一年、确认孩子真的喜欢，再考虑换大缸：水体越大容错越高（130–150L 能养 4–5 条小丑，出问题有时间救），但器材、盐、水、电费同步翻几倍（器材到手 ￥3,000+）；那时你已有全套经验，二手缸柜还能再省一笔。

## 已知问题与踩坑

| 现象 | 原因 | 规避方式 |
|---|---|---|
| 水面全是泡沫、水发白 | 新缸没养水就下生物 | 养水 4–8 周，测到 NH₃/NO₂ 归零再下 |
| 鱼一直在水面喘气 | 缺氧 / 氨中毒 | 立刻换水 30%，开造浪增氧，测氨氮 |
| 盐度一直涨 | 蒸发只丢水不丢盐，补水补成了盐水 | 补水**只加纯水**，不补盐水 |
| 蛋分打不出泡 | 水位不对 / 新缸太干净 | 调背滤水位，新缸没脏东西打不出来正常 |
