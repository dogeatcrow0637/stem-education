## 三、核心件选型说明（只讲"为什么这么选"）

| 件 | 选型 | 为什么 |
|---|---|---|
| 缸 | 40 方**背滤**裸缸，含 3 格背滤仓 | 背滤省掉外挂滤桶，书房更干净；裸缸不含泵，泵单独买型号更对 |
| 回水泵 | 600–1200 L/h 水陆两用 | 小缸够用；流量可调避免水流太猛吹跑鱼 |
| 蛋分 | 背滤内置式，匹配 50L | **海水缸的"心脏"**，把有机物打成泡沫带走；只降品牌、不降规格 |
| 造浪 | 小型可调 1500 L/h | 珊瑚要水流才开；小缸用一个小造浪即可 |
| 灯 | 18W 全光谱带定时 | 软珊瑚对光要求最低，￥25 的夹灯够用，不必买上百的 |
| 加热棒 | 100W 带独立温控 + **温控插座** | 双保险：棒子坏了插座还能断电，防止"煮鱼汤" |
| 盐 | 珊瑚盐 4kg（约配 120L） | 品质不省；4kg 小包先试配，避免囤大桶受潮 |
| 纯水 | 桶装纯净水（**不是矿泉水**） | 先不用买 RO 机；矿泉水含矿物质会让水质跑偏 |
| 盐度计 | 光学盐度计含校准液 | 别用浮子式当标准，读数差 0.002 就影响很大 |

**绝对不省的四件**：蛋分、漏电保护插头、橡胶手套、肥皂水。

**省钱只降品牌与时机，不降规格、不降安全。**

## 五、采购与验收

- 渠道：缸体/器材淘宝或拼多多；生物优先本地水族店（可现场看鱼状态），或鱼友转让
- 生物分批买：**清洁队 → 等 1 周 → 小丑鱼 1 条 → 等 1 周 → 第 2 条 → 等 2 周 → 珊瑚**
- 收货先验收：缸体量对角线与背滤仓宽度、灯通电试亮、蛋分通电试转、盐度计用校准液校一次

## 六、市售"海缸套装"怎么判断（以方小章 HB400 一类为例）

电商上常见的"背滤海水缸全套 / 珊瑚缸专业级 / 新手小丑鱼缸"，命名与本品类目一致（超白 + 背滤 + 海水通用 + 带挡板），**方向是对的**。判断只看三件事：

| 要确认的 | 合格线 | 不合格怎么办 |
|---|---|---|
| 尺寸 | 40×40×40cm 左右（HB400 系即 40 方），背滤仓宽 **≥10cm** | 仓太窄塞不下蛋分 → 别买 |
| 标配含什么 | 至少含**水泵 + 挡板**；**问客服：含不含蛋分** | 不含蛋分 → 按 ￥45–59 另买 |
| 价格 | **≤￥300 划算**；￥300–400 一般；**>￥400 不值**（灯/蛋分/加热棒仍要另买） | 超价就买裸缸 自己配 |

### 实测价（2026-10-20 查得，来源：什么值得买价格历史 + 京东/淘宝在售页）

以**方小章**（背滤海缸里销量最高的一家）为例，同一条链接里"裸缸 / 标配 / 标配+挡板"价差极大：

| SKU | 实测价 | 时间/渠道 |
|---|---|---|
| HB400-**标配+挡板** | **￥903.93**（页面价 ￥989–1039） | 2025-07 / 2024-11 京东官方旗舰店 |
| HB400-标配+挡板 | ￥929（券后） | 2024-07 京东官方旗舰店 |
| HB350-**裸缸** | ￥312.62 | 2024-05 京东 |
| BL400 2代-**裸缸** | ￥289 | 2024-08 京东 |
| HB600S-标配+挡板 | ￥1836 | 2024-12 京东 |
| 同标题（第三方店） | ￥239 / ￥269 "起" | 淘宝，多为最小号或裸缸 SKU |

**读法**：这家的规律是"裸缸 ￥280–320（40 方级），标配+挡板 ￥900–1000"，即**配件包溢价约 ￥600**。而按本项目 **推荐档全能配齐也才 ￥904**（含缸、泵、蛋分、灯、加热棒、两个插座、漏电保护、盐、纯水、盐度计、温度计、全套测试剂、安全件）。所以：

- ￥900 买"标配+挡板" → **不合算**，除非它已含蛋分+灯+加热棒且你不想比价
- 只看中这个缸 → **只买裸缸**；白牌 40 方背滤裸缸 ￥150–240，品牌贵 ￥60–130，换来做工与黑玻背滤板
- 本项目 BOM 里缸价 **￥189 = 白牌全新 / ￥120 = 二手**，是全市场下限价，品牌缸对不上这个数

**套装里的加分项**：挡板 = 防跳（小丑鱼会跳缸，必须有）。

**套装里的减分项**（不影响购买，但要心里有数）：

- 滤材（生化棉/陶瓷环）：淡水够用，海水里会积硝酸盐 → 背滤仓留一小格就够，别塞满
- 灯：多为淡水白光，喂小丑鱼和菇类/闪千手够用；想养纽扣要换 18W 全光谱夹灯（￥25）
- 蛋分：套装蛋分常是最低端款，装得进背滤格就行；打不出泡先调水位

**买完套装还要买什么**：缸垫、蛋分、灯、加热棒、定时+温控插座、漏电保护、盐、纯水、盐度计、温度计、缸刷、镊子、手套、肥皂水、造景石与胶、滤棉、水桶、防溅垫、硝化细菌（或借老棉）、养水期试剂（NH₃/NO₂ + NO₃）。按**省钱档**口径：

| 套装含泵 | 套装之外 | 例：套装 ￥199 | 例：套装 ￥299 |
|---|---|---|---|
| 是 | **￥467** | 器材到手 ￥666 / 首缸成型 ￥791 | 器材到手 ￥766 / 首缸成型 ￥891 |
| 否（需自购泵 ￥45） | **￥512** | 器材到手 ￥711 / 首缸成型 ￥836 | 器材到手 ￥811 / 首缸成型 ￥936 |

（首缸成型 = 器材到手 + 生物 ￥125）

## 七、新手结论：买"裸缸"，自己配器材（半自组）

三条路摆在面前，选中间那条：

| 路线 | 花多少 | 你会得到 | 新手风险 |
|---|---|---|---|
| ① 真·成品套缸（红海 Max Nano、蓝甸 EC/RF、Waterbox 等） | ￥1,500–3,000+ | 缸+柜+灯+蛋分+泵+电控，开箱即用 | 钱花最多；塞的是低端件，坏了不好换；柜子占地方 |
| ② 厂家"标配"套装（缸+泵+灯+滤材，如方小章 HB400-标配+挡板） | ￥900–1,000 | 缸+泵+灯+滤材+挡板 | **配件包溢价约 ￥600**；灯多是淡水白光；还缺加热棒/盐/盐度计/测试剂 |
| ③ **半自组：买裸缸（+挡板），器材照 BOM 自己买**（**推荐**） | **￥632（省钱档）～￥904（全新）** | 缸+泵+蛋分+灯+加热棒+插座+漏电保护+盐+水+盐度计+测试剂+安全件 | 要自己下 6–8 单；规格必须自己核对 |

**为什么推荐 ③**：

1. **缸体买成品**：背滤仓的宽度、格数、走水路径是玻璃切好的，新手自己做不出来，也让"蛋分能不能塞进去"这个问题由厂家替你解决。
2. **器材自己买**：蛋分、灯、加热棒这三个件直接决定能不能养，必须**规格对、型号可查、坏了能单换**。套装里这三件通常是最低端款。
3. **"自己组装"没有你想的难**：这个品类的组装 = 装滤材 + 插电 + 调水位 + 配盐水。**不用焊、不用接线、不用刷固件**。真正的门槛在后面的"养水 4–8 周"，那和买哪种缸无关。
4. **省钱**：③ 比 ② 便宜 ￥270–370，还能多拿到加热棒、盐、盐度计、温度计、全套测试剂和安全件。

**给新手的三个硬指标**（不满足就别买）：

| 指标 | 线 | 为什么 |
|---|---|---|
| 水体 | **≥40L**（40 方背滤 ≈ 45–55L） | 越小水质崩得越快，10–20L 的桌面缸不适合第一次下海 |
| 背滤仓宽 | **≥10cm** | 塞不进蛋分 = 白买 |
| 必须能说清型号的五件 | 缸、泵、蛋分、灯、加热棒 | 说不清 = 卖家在模糊配置，换一家 |

**一条偷懒但正确的规则**：只买"裸缸"或"裸缸+挡板"，**凡是名字里带"标配/全套/豪华"的都不要点**。

**挡板要不要加**：要。小丑鱼受惊会跳缸，￥30–50 的防跳挡板比捡鱼便宜。
