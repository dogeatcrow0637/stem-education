# 01 · 项目简介

> 适用版本：v1.0　|　最后更新：2026-10-20　|　前置条件：无（零基础家长可读）

## 这是什么

一口 **40×40×40cm 背滤海水小缸**，放在书房里，靠"背滤 + 蛋白质分离器 + 造浪 + 恒温"维持一个小生态，养 **1–2 条人工小丑鱼** 和 3 块新手珊瑚（闪千手 / 纽扣 / 菇类）。

## 能做什么

| 能力 | 说明 |
|---|---|
| 独立小生态 | 缸内能自己完成氮循环，不必每天换水（每周换 10%） |
| 养 1–2 条小丑鱼 | 人工繁殖个体，能适应人工海水，不依赖野生海葵 |
| 养 3 类新手珊瑚 | 闪千手、纽扣、菇类（软珊瑚，对灯光/水质要求最低） |
| 做长期观察记录 | 每天 3 分钟、每周 15 分钟，形成水质曲线 |

## 关键参数

| 参数 | 值 |
|---|---|
| 缸体 | 40×40×40cm 超白玻璃背滤缸，背滤仓宽 10–12cm（3 格） |
| 系统水量 | 约 45–55L（扣除造景石与背滤仓占用） |
| 目标水质 | 盐度 1.024–1.026（32–35 ppt）、25–26℃、KH 7–9、NO₃<10ppm、PO₄<0.1ppm |
| 循环与水流 | 回水泵 600–1200 L/h + 小型造浪 1 个（8–15 倍水体/h） |
| 生物 | 小丑鱼 1–2 条；珊瑚：闪千手 / 纽扣 / 菇类；清洁队（螺 + 寄居蟹） |
| 供电 | 220V 市电，全部设备经漏电保护插头；整缸常开功率约 30–60W |
| 开缸周期 | 装缸 1 天 + 养水 4–8 周（不可压缩）+ 分批加生物 4 周 |

## 教学价值与目标人群

**适合谁**：5 岁以上的孩子 + 零基础家长；家里有书房/客厅一角能放下一张 45cm 见方的桌面。

**教学目标**

1. 理解"看不见的细菌在净化水"——氮循环（氨 → 亚硝酸盐 → 硝酸盐）。
2. 学会用仪器说话：盐度计、温度计、测试剂的读数决定下一步做什么。
3. 体验**不可压缩的等待**：养水 4–8 周，急不得——这是本项目最想教的"耐心"。
4. 完成一份属于自己缸的水质记录与展示。

**前置知识**：无。会读数、会按按钮、能听指令即可（L1 档）。
