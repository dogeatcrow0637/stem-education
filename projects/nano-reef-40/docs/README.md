## 写作要求

- 文档头写 **适用版本 / 最后更新 / 前置条件**。
- 危险操作（220V 通电、海水、珊瑚毒素）用 ⚠️ 单独标注，并写清防护。
- 每大步给「完成的判断标准」；看不见结果的不算一步。
