# 04 · 软件环境

> 适用版本：v1.0　|　最后更新：2026-10-20　|　前置条件：无（本项目无固件、无上位机）

> 本项目是**活体生态缸**，没有单片机、没有需要编译的代码。本文件只讲两件事：**设备怎么被自动控制**，以及**数据怎么记录**。

## 一、环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | 无 | 不需要电脑参与运行 |
| 运行时 | 无 | 灯与加热棒靠**硬件插座**定时/控温 |
| 手机 App（可选） | 智能插座 App | 想远程看开关状态时才需要 |
| 记录工具 | 手机备忘录 / 打印的[水质记录表](../software/host/水质记录表.md) / 表格软件 | 每周记 1 行 |

## 二、设备的"自动化"怎么实现

不用写代码，用**两个插座件**代替程序逻辑：

| 设备 | 控制件 | 设定 | 相当于代码里的什么 |
|---|---|---|---|
| 珊瑚灯 | 定时插座 | 每天 09:00 开、17:00 关 | 一个定时任务 |
| 加热棒 | 温控插座（串在加热棒前） | 26℃ 启动、25℃ 停止 | 一个带滞环的恒温控制 |
| 泵 / 蛋分 / 造浪 | 直插常开 | 不断电 | 一直在跑的主循环 |

```text
# 等价伪代码（帮你理解，不需要真的写）
while True:
    if 时间 == "09:00": 灯.on()
    if 时间 == "17:00": 灯.off()
    if 水温 >= 26: 加热棒.off()   # 温控插座自动做
    if 水温 <= 25: 加热棒.on()
    泵.on(); 蛋分.on(); 造浪.on()  # 一直开
```

想升级成"手机能看"（可选，不在预算内）：把排插换成**智能排插**，用 App 看每个插位开了没、设定时。**不要**用智能插座去控加热棒——断电是安全，误开才危险，加热棒必须走**独立温控插座**。

## 三、运行与验证

| 步骤 | 操作 | 验证标准 |
|---|---|---|
| 1 | 装 App 或直接用插座件 | 到点灯自动亮/灭，连续 3 天不错 |
| 2 | 温控插座设定后放温度计对照 | 温度计读数稳定在 25–26℃ |
| 3 | 每天记录 | 记录表每天有 1 行：日期 / 温度 / 盐度 / 备注 |

**验证标准**：连续一周不用手动开关灯、不用手动开关加热棒，水温与灯时间都稳定。

## 四、数据记录

- 模板：[`software/host/水质记录表.md`](../software/host/水质记录表.md)
- 数据文件：[`software/host/water_log.csv`](../software/host/water_log.csv)
- 记录字段：日期、水温、盐度、NH₃、NO₂、NO₃、当天动作（换水/喂食/加生物）、备注
- 频率：**开缸期每 2 天**，养水结束后**每周 1 次**

## 五、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 灯到点不亮 | 定时插座档位拨错 / 没电 | 手动按下试灯，再查定时拨片 |
| 水温忽高忽低 | 温控插座启停温差设太小 | 改成 26 启 / 25 停（1℃ 滞环） |
| 记录表记了两周就断 | 没定固定时间 | 固定"每周日晚上换水时顺手记" |
| 手机 App 掉线 | 智能插座 WiFi 弱 | 本项目不强依赖 App，掉线不影响运行 |
