# 03 · 组装与调试

> 适用版本：v1.0　|　最后更新：2026-10-20　|　预计耗时：装缸 2–3 小时（分 2 次做）+ 配水养水 4–8 周
> ⚠️ 涉及 220V 通电、海水的步骤，孩子只能 L1 观察；插插座与下缸操作由家长执行。

## 一、前置准备

| 项 | 内容 |

| 需要先完成 | 收货验收：缸体量对角线与背滤仓宽度、灯试亮、蛋分试转、盐度计校准 |

## 二、设备位置与插位表（先规划再插电）

设备全部插在**一个排插**上，排插前面串 **1 个漏电保护插头**（另一只备用）。

| 插位 | 设备 | 功率 | 是否常开 | 备注 |
|---|---|---|---|---|
| ① | 回水泵 | 5–10W | 常开 | 停电也不能停 |
| ② | 蛋白质分离器 | 5–10W | 常开 | 与水泵同开 |
| ③ | 造浪泵 | 3–5W | 常开 | 可定时夜间降速 |
| ④ | 珊瑚夹灯（18W） | 18W | 定时 8h | 插**定时插座**，再插排插 |
| ⑤ | 加热棒（100W） | 100W（间歇） | 随温控 | 插**温控插座**（26℃ 启 / 25℃ 停），再插排插 |
| ⑥ | 备用 | — | — | 留给第二缸或临时设备 |

> 合计常开约 30W，冬季加热棒间歇工作，平均约 60W。

**接线顺序（严格按此顺序，避免带电插拔）**

```
墙上三孔插座（接地）
   └─ 漏电保护插头
        └─ 排插
             ├─ ① 回水泵  ② 蛋分  ③ 造浪
             ├─ 定时插座 ── ④ 灯
             └─ 温控插座 ── ⑤ 加热棒
```

## 三、装配步骤

### 步骤 1：摆缸与垫缸垫

- 装什么：把 EVA 缸垫（￥12）铺在桌面上，缸放上去，四角对准
- **完成判断标准**：缸放稳不晃，用手推四角不动；缸底与桌面之间无缝隙
- ⚠️ 缸装满水约 60kg，**必须在配水前摆好位置**，之后不要再搬

### 步骤 2：洗缸与洗造景石

- 装什么：用清水（自来水即可）冲洗缸内壁与人工造景石，倒掉脏水，**不要用洗洁精**
- **完成判断标准**：倒出的水不再发白、无沙粒

### 步骤 3：造景（做山洞）

- 装什么：人工造景石 2–3kg 摆成有洞穴/缝隙的形状，用珊瑚骨胶粘住不稳的石头
- **完成判断标准**：石头推一下不塌；至少留 2 个鱼能钻进去的洞
- 为什么：小丑鱼需要自己的"家"，有洞才不打仗

### 步骤 4：装背滤三格

- 装什么：按水流方向从上到下——
  1. **第一格（进水格）**：滤棉（￥10）→ 下面是生化球/陶瓷环（￥15）
  2. **第二格**：蛋白质分离器（￥59）
  3. **第三格（出水格）**：回水泵（￥45）
- **完成判断标准**：三格设备都卡稳、不上浮；背滤仓水位能淹没水泵进水口

### 步骤 5：配海水（第一次配水）

- 装什么：桶装纯净水（**不是矿泉水**）+ 珊瑚盐，按 **1kg 盐 : 30L 水** 比例
  1. 先在大桶里装满纯水，量好体积
  2. 分次加盐，每加一次搅拌到完全溶解再加下一次
  3. 用光学盐度计测，调到 **1.024–1.026**（约 32–35 ppt），不够再加盐
- **完成判断标准**：盐度计读 1.025 左右，桶里没有未溶解的盐粒，水清澈
- ⚠️ 加盐会放热/放气，**搅拌时别凑太近**；配好静置 30 分钟再倒进缸
- 孩子参与：L2 量水、按比例数盐勺；L3 自己读盐度计

### 步骤 6：倒水开泵（第一次通电）

- 装什么：把海水倒进缸与背滤仓 → 插漏电保护 → 逐个开泵
- **完成判断标准**：看得见水面从背滤第三格回流进主缸、有细小气泡；造浪让水面轻微晃动
- ⚠️ 插电前把手擦干；先按漏电保护插头的**试验键**确认能跳闸，再按复位

### 步骤 7：加硝化细菌，开始养水

- 装什么：按瓶身说明倒入成品硝化细菌（￥20）
- **完成判断标准**：缸里开始变浑浊（正常），灯按定时开 8 小时/天
- **从今天起进入 4–8 周养水期**，期间不放任何生物，每 2 天测一次 NH₃/NO₂

## 四、通电与自检

| 检查项 | 期望结果 | 异常处理 |
|---|---|---|
| 漏电保护试验键 | 按下即跳闸 | 不跳 = 换新的，绝不用 |
| 回水泵 | 有水流从背滤回流主缸 | 无水流：泵没入水/被滤棉堵住 |
| 蛋分 | 集污杯内水位在刻度内、有细泡 | 打不出泡：水位太低，调背滤水位 |
| 灯 | 定时到点自动亮 8 小时 | 不亮：换定时插座档位 |
| 加热棒 + 温控插座 | 水温稳定 25–26℃ | 温度乱跳：温控插座设 26 启 / 25 停 |
| 盐度 | 1.024–1.026 | 偏高加水，偏低加盐（只加纯水补水） |
| 蒸发补水 | 每天补 0.5–1L **纯水** | 千万别补盐水，否则越补越咸 |

## 五、常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 水发白、多泡沫 | 正常"新缸雾"；也可能是下生物太早 | 继续养水，测 NH₃/NO₂，未归零不下鱼 |
| 缸壁长绿藻 | 正常爆藻期 | 等养水结束，第一次放清洁队吃掉 |
| 鱼在水面喘气 | 缺氧或氨中毒 | 立刻换水 30%、开大造浪，测氨氮 |
| 盐度一直涨 | 补水时补了盐水 | 只补纯水；重新测盐度 |
| 蛋分一直溢出 | 水位太高 / 新缸太干净 | 调低背滤水位 |
| 珊瑚不开 | 水流不对 / 光照不足 / 水质未稳 | 先测 KH 与盐度，再调位置 |
| 白点病（鱼身上有白点） | 水温波动 / 新鱼带病 | 稳定水温；新鱼先隔离观察 1 周 |

## 六、校准

| 项目 | 方法 | 频率 |
|---|---|---|
| 光学盐度计 | 滴校准液到棱镜，调到 1.000 刻度线 | 每次测水质前 |
| 玻璃温度计 vs 加热棒显示 | 两者同时放缸里，差值 >1℃ 时以温度计为准 | 每月一次 |
| 换水量 | 系统水量 × 10% ≈ 5L，量杯量准 | 每周 |
