# 05 · 教学与课程

> 适用版本：v1.0　|　最后更新：2026-10-20　|　适用学段：小学低年级–高年级（分档）
> 课时安排：5 课时（每课 45 分钟）+ 养水期"观察打卡"（4–8 周，非课时）
> 配套产出：[`儿童课程/`](儿童课程/README.md)（一课一个目录：课件 + 配图 + 知识卡，md → 可放映 html）、[`家长实现/`](家长实现/)

## 一、课程目标

学完能：

1. 说出海水缸里"谁在干活"：泵、蛋分、造浪、灯、细菌，各管一件事。
2. 用盐度计与测试剂判断水质，并据此决定"能不能下鱼"。
3. 讲清氮循环三步：氨 → 亚硝酸盐 → 硝酸盐，理解"为什么要等 4–8 周"。
4. 独立完成每周体检（测盐度、量温度、换 5L 水、填记录表）。

## 三、实验任务

| # | 任务 | 难度 | 验收标准 |
|---|---|---|---|
| 1 | 配一桶 1.025 的海水 | 入门 | 盐度计读数落在 1.024–1.026 |
| 2 | 记录 14 天氨氮/亚硝酸盐曲线 | 入门 | 曲线出现"先高后归零"的形状 |
| 3 | 摆一个带洞的造景 | 入门 | 石头不塌，鱼能钻进去 |
| 4 | 独立完成一次每周体检 | 进阶 | 四步全做完，记录表填满 |
| 5 | 讲清"为什么不能立刻下鱼" | 进阶 | 能说出氨→亚硝酸盐→硝酸盐三步 |

## 四、考核点

| 维度 | 权重 | 说明 |
|---|---|---|
| 观察与记录 | 40% | 记录表连续、读数正确、能看曲线说结论 |
| 动手操作 | 30% | 配水、测盐度、换水、开关插座规范 |
| 原理表达 | 20% | 能用自己的话讲清氮循环与小丑鱼的家 |
| 安全规范 | 10% | 手湿不碰插座、碰珊瑚戴手套（一票否决） |

## 五、常见提问（FAQ）

| 学生问题 | 回答要点 |
|---|---|
| 为什么水要咸咸的？ | 因为小丑鱼老家在海里；盐度对不上，鱼会像人喝错水一样难受 |
| 为什么不能今天就放鱼？ | 缸里还没长出"吃脏东西的细菌"，鱼排的尿没人处理，会毒死自己 |
| 缸里那个打泡的是什么？ | 蛋分，像"海里的肺"，把脏东西变成泡沫捞走 |
| 为什么每周要换水？ | 硝酸盐会越积越多，换水等于"倒掉一部分脏水" |
| 珊瑚是石头吗？ | 不是，是动物，会张开小手抓东西吃 |
| 可以摸鱼吗？ | 不可以，手上有油和细菌，鱼会生病 |

## 六、安全须知（必讲）

1. ⚠️ **手湿不碰插座**；所有设备必须经漏电保护插头。
2. ⚠️ **碰纽扣珊瑚必须戴手套**，之后用肥皂水洗手；不要揉眼。
3. ⚠️ 家长负责插电、配盐、搬缸；孩子站在安全距离外做 L1 观察。
4. ⚠️ 尝任何水都不行——海缸水不是饮用水。
