# 家长话术与提问卡（40cm 背滤海缸（小丑鱼练手版））

| 字段 | 值 |
|---|---|
| 适用版本 | v1.0 |
| 最后更新 | 2026-10-20 |
| 前置条件 | 与 `02-里程碑与任务卡.md` 配套使用 |

> 目标：家长不讲课，只提问。孩子说出来，才算学会。每张卡至少问一次"为什么"。

## 1. 各阶段引导提问（每个里程碑选 3 个问）

| 里程碑 | 提问 |
|---|---|
| M0 采购 | 1）"我们要养的东西住在哪？" 2）"哪几样是必须的，哪几样可以以后再说？" 3）"为什么要买漏电保护插头？" |
| M1 装缸 | 1）"水从哪进、从哪出？" 2）"三个格子里谁在干活？" 3）"插电前我们做了什么保护？" |
| M2 养水 | 1）"为什么水一开始是浊的？" 2）"我们凭什么说现在还不能放鱼？" 3）"这两个星期缸里有变化吗？你怎么知道？" |
| M3 下生物 | 1）"为什么先放螺，再放鱼？" 2）"鱼为什么躲进洞里？" 3）"珊瑚是石头还是动物？" |
| M4 体检 | 1）"哪个数字变了？为什么？" 2）"水为什么会变少？变少的是水还是盐？" 3）"如果盐度太高，怎么办？" |

## 2. 孩子常问的"为什么"与答法

| 孩子的问法 | 一句话答法 |
|---|---|
| 为什么水要咸咸的？ | "小丑鱼老家在海里，水不咸它就像人喝错水一样难受。" |
| 为什么不能今天就放鱼？ | "缸里还没长出爱吃脏东西的细菌，鱼排的尿没人处理，会毒到自己。" |
| 缸里打泡的是什么？ | "像海里的肺，把脏东西变成泡沫捞走。" |
| 水少了为什么只加清水？ | "跑掉的只有水，盐还在缸里，不加盐才是对的。" |
| 为什么每周要换水？ | "脏东西会越积越多，换水就是倒掉一部分脏水。" |
| 珊瑚是石头吗？ | "不是，是动物，会张开小手抓东西吃。" |
| 螺在吃什么？ | "它在吃玻璃上的藻，是缸里的清洁工。" |
| 可以摸鱼吗？ | "不可以，手上有油和细菌，鱼会生病。" |
| 为什么等了这么久还没好？ | "细菌要慢慢长大，就像种花要等它发芽。" |

## 3. 本项目术语生活类比表

| 术语 | 生活类比 | 一句话解释 |
|---|---|---|
| 盐度 | 汤的咸淡 | 水里盐的多少，用 1.025 表示 |
| 背滤 | 房子的隔间 | 藏在缸背后的小房间，水在里面被清洗 |
| 蛋白质分离器（蛋分） | 海里的肺 | 打泡把脏东西带出去 |
| 造浪 | 电风扇 | 让水流动，珊瑚才开 |
| 氮循环 | 垃圾处理的流水线 | 氨→亚硝酸盐→硝酸盐，一步步变无毒 |
| 硝化细菌 | 看不见的清洁工 | 住在滤材上，吃掉有毒的氨 |
| 养水 | 腌菜发酵 | 等细菌长好，急不得 |
| 过水 | 慢慢适应新家 | 把鱼袋漂在缸里，让温度慢慢一样 |
| 补水 | 给汤加水不加盐 | 蒸发只跑水，补水只能补纯水 |
| 爆藻 | 长杂草 | 新缸必经的绿藻期，之后清洁队来吃 |

## 4. 收尾 20 秒复盘（每张卡结束必做）

1. "今天成功的标志是什么？"
2. "哪里最麻烦？"
3. "下次想改哪里？"

## 5. 关键话术（直接抄）

- 交付动作："你负责量水、按按钮、读数字，我负责倒盐和插电——危险的那步我一个人做。"
- 养水期安抚："缸里正在发生我们看不见的事。看不见，不等于没发生。"
- 卡住时："先只找一件事：这一步和上一张卡比，哪里不一样？"
- 失败时："死了一条鱼不是你的错，是水还没准备好。记下当时的水质数字，下次就懂了。"
- 拒绝代劳："我可以说怎么做，但手是你的——所以你才是这口缸的主人。"
- 升档："这张卡我不动手，你来做，我叫你才帮。"
