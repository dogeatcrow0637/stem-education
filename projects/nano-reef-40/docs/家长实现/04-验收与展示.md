## 2. 失败排查表（按顺序查，不要跳）

| 现象 | 最可能原因（按概率排序） | 先查什么 |
|---|---|---|
| 泵不转、水面不动 | 泵没入水 / 被滤棉堵 / 插座没开 | 看背滤水位是否淹过泵 → 清滤棉 → 换插位试 |
| 蛋分打不出泡 | 水位太低 / 新缸太干净 / 进气堵 | 调背滤水位 → 看进气口 → 新缸属正常 |
| 水发白、泡沫多 | 新缸雾 / 下生物太早 | 测 NH₃、NO₂；未归零就继续等 |
| 缸壁长绿藻 | 爆藻期（正常） | 等养水结束，放清洁队 |
| 鱼在水面喘气 | 缺氧 / 氨中毒 | 立刻换水 30%、开大造浪、测氨氮 |
| 鱼身上有白点 | 水温波动 / 新鱼带病 | 稳定水温；新鱼先隔离观察 1 周 |
| 珊瑚不开、变白 | 水流/光照不对 / 水质未稳 | 测盐度与温度 → 换位置 |
| 盐度一路涨 | 补水补成了盐水 | 只补纯水；分次加水稀释后重测 |
| 水温超过 28℃ | 加热棒失控 / 房间太热 | 拔加热棒，用水温计复核；夏季加风扇 |
| 珊瑚操作后手麻发痒 | 纽扣珊瑚毒素（palytoxin） | 立即用肥皂水彻底冲洗，不适就医 |

## 3. 作品展示脚本（让孩子讲 3 分钟）

1. **它是什么**（30 秒）："这是我开的一口海缸，里面住着 __ 条小丑鱼和 __ 块珊瑚。"
2. **怎么做的**（60 秒）：按"先…然后…最后…"说三个最关键步骤（配水 → 养水 → 分批下生物）。
3. **最难的地方**（45 秒）："最难的是等水变好，我等了 __ 周。怎么知道好了？测氨和亚硝酸盐都是 0。"
4. **我还想改**（45 秒）："下一步我想 __。"

家长只做两件事：计时、听完后问一个问题（"如果再来一次，你会先做什么？"）。
