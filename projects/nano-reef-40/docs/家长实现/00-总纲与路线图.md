# 家长实现总纲（40cm 背滤海缸（小丑鱼练手版））

| 字段 | 值 |
|---|---|
| 项目编号 | 05 |
| 项目目录 | `projects/nano-reef-40` |
| 适用版本 | 硬件：v1.0 器材清单 ／ 无软件 |
| 最后更新 | 2026-10-20 |
| 前置条件 | 一张能承重 60kg 的桌子、一个接地良好的三孔插座、能坚持 8 周不催 |

> 本手册面向**完全零基础的家长**，用于带一名小学生从零开一口海缸并讲明白。工程细节以 `docs/` 为准，本手册只讲"怎么带着孩子做"。

## 一句话目标

做完之后，孩子能**独立完成每周体检**（测盐度、量温度、换 5L 水、填记录表）；能看到的现象是：**水从背滤回流、蛋分冒泡、小丑鱼住在自己选的洞里**。

## 这套手册怎么用

1. **先读本文最后一节的安全红线**，再读 `05-安全与工具采购清单.md`。
2. 按 `02-里程碑与任务卡.md` 从头做；**一张卡一次坐下做完，打勾再进下一张**。
3. 每张卡按孩子水平选一档：

| 档 | 孩子做什么 | 家长做什么 | 什么时候升档 |
|---|---|---|---|
| L1 观察 | 递零件、对编号、按按钮、说出看到的现象 | 全部动手 + 讲解 + 防护 | 能说清"这步在做什么、成功会看到什么" |
| L2 协作 | 量水、加盐、插插座（家长在旁）、填记录表 | 把关比例与极性、执行危险步骤 | 同类动作无提示也能做对 |
| L3 独立 | 独立测盐度/氨氮、算换水量、讲氮循环 | 只做安全监护，允许失败 | 能讲清"上次为什么失败、这次改了什么" |

4. 需要**外包**的环节：本项目几乎没有。可选打印件（防跳网框、灯夹）走嘉立创 3D 打印/淘宝代打，￥5–30/件，3–7 天；**不打印也能开缸**。
5. 卡住了：先查 `04-验收与展示.md` 的失败排查表，再对照卡片里的"失败兜底"。

## 场地、作息与收纳

- 工作台：承重 ≥60kg，离墙 10cm 散热，旁边有接地三孔插座；**缸装满水约 60kg，配水前定好位置就别再搬**。
- 节奏：单次 ≤45 分钟；养水期每周 2 次"测一次 + 记一行"，其余时间不许打扰缸。
- 收纳：器材按"常开 / 定时 / 温控"三类分放；记录表固定贴缸边；**每次结束擦干手与台面**。

## 安全红线（先读这一页）

1. ⚠️ **手湿不碰插座**；所有设备必须经一个漏电保护插头，开工前先按"试验键"确认能跳闸。
2. ⚠️ **碰纽扣珊瑚必须戴手套**，操作后用肥皂水洗手，**不要揉眼**；缸边常备一瓶肥皂水。
3. ⚠️ 家长负责插电、配盐、搬缸；孩子站在安全距离外做 L1 观察。
4. ⚠️ 出现异味/异响/发烫/跳闸 → **先拔电，再排查**，不要边通边查。

## 假设与已知限制

- 本文假设：家长不焊接、不写代码、家里没有水族经验；全部器材可网购、即插即用。
- 水质达标时间因菌种与水温而异，`4–8 周` 是经验区间，**未实测**（自家缸数据请填进记录表）。
- 关键风险：**心急提前下鱼**（必死）、**蒸发后补了盐水**（盐度飙升）、**不戴手套碰纽扣珊瑚**。
