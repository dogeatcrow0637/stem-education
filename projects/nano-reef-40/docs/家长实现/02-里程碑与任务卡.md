# 里程碑与任务卡（40cm 背滤海缸（小丑鱼练手版））

| 字段 | 值 |
|---|---|
| 适用版本 | v1.0 |
| 最后更新 | 2026-10-20 |
| 前置条件 | 已读 `00-总纲与路线图.md`；材料已到货 |

**卡片规则**：一张卡 = 一次坐下 = 一个动作单元（≤25 分钟）；做完必须能看见结果并打勾。打勾格式：`- [x] 卡 M1-1`。每张卡完成盖一枚章，每 3 张卡安排一次"展示时刻"（拍照/录 ≤10 秒视频），每完成一个里程碑发一个称号（材料员→装配员→养水师→引鱼师→缸主）。

> 养水期（M2）卡片是"每隔 2 天做一次"的重复动作，不是连续课时；其间大段空闲正是教"耐心"的地方。

---

## M0 采购与到货

目标：型号定稿、物料到货、核对无缺件。

### 卡 M0-1：下单
- 目标（孩子视角）："我们决定买哪一套，把它请回家。"
- 物料：采购清单 `05-安全与工具采购清单.md`
- 三档分工：L1 一起看图片并说出喜欢哪个缸｜L2 一起对照清单点数量｜L3 自己做价格比较表并给结论
- 步骤：
  1. 打开 BOM 的"开缸必备"段 → 结果：孩子能说出"我们一共要买 26 样"
  2. 下单（可只下开缸必备 ￥849）→ 结果：订单截图存档
- 验收判据：清单每一项都有"已下单/替代型号"状态
- 失败兜底：缺货 → 换同规格别家，或分两家买
- ⚠️ 安全：—

### 卡 M0-2：到货核对
- 目标："所有东西都到齐，一个都不少。"
- 物料：BOM + 分格收纳盒
- 三档分工：L1 报出物品名｜L2 点数并分格收纳｜L3 记录缺件错件
- 步骤：逐项核对 → 结果：清单全部打勾；分格收纳 → 结果：照片一张
- 验收判据：缸体量对角线与背滤仓宽度、灯试亮、蛋分试转、盐度计用校准液校准
- 失败兜底：缺件先做不依赖它的部分（如洗石头）

---

## M1 装缸与通电

目标：缸立起来、水能循环、孩子看到"活的"第一眼。

### 卡 M1-1：摆缸与铺垫
- 目标："缸放稳了，推也推不动。"
- 物料：EVA 缸垫 ￥12、缸、毛巾
- 三档分工：L1 递垫子｜L2 一起抬缸对位（家长主抬）｜L3 用水平尺看是否平整
- 步骤：
  1. 铺垫 → 结果：垫子平整无褶皱
  2. 抬缸上垫 → 结果：四角对准
- 验收判据：手推四角不晃、缸底与桌面无缝隙
- 失败兜底：桌面不平 → 加垫片找平
- ⚠️ 安全：**配水前必须摆好，装水后约 60kg 不要搬**

### 卡 M1-2：洗缸与造景
- 目标："给鱼造一个有洞的家。"
- 物料：人工造景石 2–3kg、珊瑚骨胶、清水
- 三档分工：L1 递石头说"放这里"｜L2 摆石头并涂胶｜L3 独立设计造景
- 步骤：
  1. 清水冲洗缸与石头（**不用洗洁精**）→ 结果：倒出的水不发白
  2. 摆石头留 2 个洞 → 结果：推不塌、有洞
- 验收判据：石头稳、有 ≥2 个鱼能钻的洞
- 失败兜底：不稳 → 用胶粘；洞太小 → 重摆
- ⚠️ 安全：—

### 卡 M1-3：装背滤三格
- 目标："水要走的三个房间都准备好了。"
- 物料：滤棉、生化球、蛋分、回水泵
- 三档分工：L1 对号放件｜L2 卡稳设备｜L3 按水流方向独立装
- 步骤：① 格放滤棉 + 生化球 → ② 格放蛋分 → ③ 格放泵 → 结果：三格都卡稳不上浮
- 验收判据：背滤水位能淹没泵进水口
- 失败兜底：设备上浮 → 用吸盘或支架固定
- ⚠️ 安全：—

### 卡 M1-4：首次通电
- 目标："看见水自己转一圈。"
- 物料：漏电保护插头、排插、手已擦干
- 三档分工：L1 在安全距离外看并说出看到什么｜L2 家长口令下按住排插开关｜L3 按插位表独立上电并复述检查项
- 步骤：
  1. 先按漏电保护**试验键** → 结果：跳闸（跳不了就换一个）
  2. 复位，逐个开泵 → 结果：水面从背滤回流 + 造浪让水面轻晃
- 验收判据：有水流、有气泡，无发烫异味
- 失败兜底：没水流 → 泵没入水/被滤棉堵；蛋分不打泡 → 调背滤水位
- ⚠️ 安全：手湿不碰插座；插电前先按试验键

## M2 配水与养水（4–8 周，本项目的"耐心关"）

目标：把水变成海水，然后**什么都不做地等**，直到氨与亚硝酸盐归零。

### 卡 M2-1：配第一桶海水
- 目标："把淡水变成海水。"
- 物料：桶装纯净水 4 桶、珊瑚盐、量杯、盐度计
- 三档分工：L1 数桶数、看盐度计刻度｜L2 量水加盐搅拌｜L3 自己算比例并校盐度
- 步骤：
  1. 大桶装满纯水，量出体积 → 结果：知道这桶有多少升
  2. 按 **1kg 盐 : 30L 水** 分次加盐，搅到全溶 → 结果：无盐粒、水清
  3. 盐度计测到 **1.024–1.026** → 结果：读数落区间
- 验收判据：盐度计读 1.025 左右
- 失败兜底：偏低 → 加盐；偏高 → 加纯水
- ⚠️ 安全：加盐有放热放气，别凑近闻；尝水绝对不行

### 卡 M2-2：注水开泵，加入硝化细菌
- 目标："细菌宝宝搬家进来了。"
- 物料：配好的海水、硝化细菌
- 三档分工：L1 看水变浑｜L2 一起倒水（家长提桶）｜L3 按说明加菌
- 步骤：倒水进缸与背滤 → 开泵 → 加硝化细菌 → 结果：水开始微浑（正常）
- 验收判据：泵在转、灯按定时开 8 小时
- 失败兜底：水太浑 → 正常，等几天会清
- ⚠️ 安全：提水别闪腰；地面铺防溅垫

### 卡 M2-3：每 2 天测一次（重复卡）
- 目标："用数字决定能不能放鱼。"
- 物料：NH₃/NO₂ 测试剂、记录表
- 三档分工：L1 读出颜色对应的数字｜L2 按说明书滴试剂比色｜L3 独立测并画曲线
- 步骤：测 → 记一行 → 结果：记录表连续有数
- 验收判据：**氨 = 0 且亚硝酸盐 = 0**，连续两次 → 才能进 M3
- 失败兜底：数字很高 → 正常，继续等；一周无变化 → 检查水温是否 >=24℃
- ⚠️ 安全：试剂别入口；用完洗手
- **放弃/跳过条件**：不可跳过。等 8 周仍不归零 → 检查菌种是否过期、水温是否太低

## M3 分批下生物

目标：按"清洁队 → 鱼 → 珊瑚"的顺序，每步间隔观察。

### 卡 M3-1：放清洁队
- 目标："先请两个小工人来打扫。"
- 物料：食藻螺 ×3、寄居蟹 ×1
- 三档分工：L1 看螺在爬｜L2 一起过水（把袋子漂在缸里 15 分钟）｜L3 独立过水并记录
- 步骤：袋子漂 15 分钟 → 放出 → 结果：螺开始啃藻
- 验收判据：24 小时后生物活着、在动
- 失败兜底：不动 → 查盐度与温度是否在区间
- ⚠️ 安全：—

### 卡 M3-2：下第一条小丑鱼
- 目标："1 号鱼入住。"
- 物料：人工繁殖公子小丑 1 条
- 三档分工：L1 给鱼起名字｜L2 一起过水｜L3 独立过水 + 记录
- 步骤：过水 20 分钟 → 放鱼 → 结果：鱼找到自己的角落
- 验收判据：一周内正常游动、吃食
- 失败兜底：躲着不出来 → 正常，减少打扰；水面喘气 → 立即换水 30%
- ⚠️ 安全：手别伸进缸乱抓

### 卡 M3-3：下第二条小丑鱼（间隔 ≥1 周）
- 目标："2 号鱼入住，它们做邻居。"
- 物料：另 1 条小丑，**体型与第 1 条明显不同**
- 三档分工：同上
- 步骤：过水 → 放出 → 结果：两条各占一角，不追咬
- 验收判据：3 天内无明显追咬、鳍完整
- 失败兜底：打得太凶 → 临时用隔离盒分开；加更多躲避
- ⚠️ 安全：—

### 卡 M3-4：下珊瑚（间隔 ≥2 周）
- 目标："给缸里加会动的小花。"
- 物料：闪千手 / 纽扣 / 菇类断枝各 1
- 三档分工：L1 说喜欢哪个｜L2 一起粘/放珊瑚｜L3 独立摆放并记录位置
- 步骤：先测盐度与温度 → 摆放 → 结果：珊瑚张开
- 验收判据：一周内珊瑚开、不变白
- 失败兜底：不开 → 换位置（水流/光照不同）
- ⚠️ 安全：**碰纽扣珊瑚必须戴手套**，之后肥皂水洗手，别揉眼

## M4 每周体检与创作

目标：孩子独立完成维护，并做一次属于自己的改动。

### 卡 M4-1：第一次独立体检
- 目标："我来当缸的医生。"
- 物料：盐度计、温度计、新配海水 5L、记录表
- 三档分工：L1 说四个步骤的名字｜L2 做其中两步｜L3 独立做完四步并填表
- 步骤：① 测盐度 ② 量温度 ③ 换水 5L ④ 填表 → 结果：记录表连成线
- 验收判据：四步全做完，数字落在目标区间
- 失败兜底：读数记不住 → 就写在纸上再抄进表
- ⚠️ 安全：换水时别把电线碰水

### 卡 M4-2：改一件事（自主创作）
- 目标："我改了，效果不一样。"
- 三档分工：L1 选"改哪个"｜L2 一起改并观察｜L3 独立改并解释
- 可选改动：灯照时长 8h→7h；造浪强度调小；给鱼加一个新躲避；换水从 5L 改 6L
- 步骤：记录原始值 → 改 → 观察 3 天 → 结果：对比记录
- 验收判据：孩子能说出"改了什么、为什么变了"
- ⚠️ 安全：加热棒与水温相关的改动必须家长确认

### 卡 M4-3：讲给别人听
- 目标：成为"缸主"，把它讲清楚。
- 三档分工：L1 说 3 句话｜L2 演示 + 说 1 分钟｜L3 按展示脚本讲 3 分钟
- 验收判据：能回答"最难的是什么、怎么解决的"（答案通常是"等 6 周"）
