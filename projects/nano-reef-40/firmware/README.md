# firmware · 本项目无固件

> 40cm 背滤海缸是**活体生态缸**，不含单片机、不含需要编译烧录的代码，因此本目录不产出固件。

## 那"自动控制"靠什么？

| 设备 | 控制件 | 设定 |
|---|---|---|
| 珊瑚灯 | 定时插座 | 每天 09:00 开 / 17:00 关 |
| 加热棒 | 温控插座（串在加热棒前） | 26℃ 启 / 25℃ 停 |
| 泵 / 蛋分 / 造浪 | 直插常开 | 一直运行 |

伪代码级解释见 [`../docs/04-软件环境.md`](../docs/04-软件环境.md)。

## 什么时候才需要固件

如果以后想加"手机看温度、自动补水、水温超限报警"，那才需要 DIY 控制器，建议**单独开一个新项目**（ESP32 + 温度传感器 + 继电器 + MQTT），不要在本项目里堆。
