# 循迹小车

> 一句话定位：￥100 以内、不用焊接的入门练手项目——让一辆两轮小车自己沿着黑线跑，是机械臂（01）之前的低门槛第一站。

## 这是什么

一辆用两个减速电机驱动、靠一对红外传感器"看"地上黑线、自己拐弯跟着跑的小车。全部用成品模块插线组装，**不需要焊接、不需要 3D 打印、不需要买特殊工具**。它把"传感器 → 主控 → 电机"这条最小闭环讲得干干净净，是理解机器人"感知—判断—动作"的最佳起点。

教学价值：孩子能亲手完成"接线—烧程序—调参数"三件事，看到自己写的逻辑真的让轮子转起来；成本低、失败可承受、当堂就能看到结果。

## 能力与参数

| 参数 | 值 |
|---|---|
| 主控 / 平台 | Arduino UNO R3 兼容板（ATmega328P，CH340 USB） |
| 编程方式 | mBlock / Mixly 积木编程，或 Arduino IDE（C 语言） |
| 驱动 | L298N 双 H 桥模块，PWM 调速 |
| 感知 | 2 路红外反射式循迹模块（TCRT5000），可升级 5 路 |
| 供电 | 4×AA 干电池（约 6V）供电机；USB 供主控（可选单电源） |
| 尺寸 / 重量 | 约 200×140×70mm / 约 250g（整机，实测为准） |
| 关键指标 | 黑线宽 15–20mm；调速约 40%–100% PWM；连续跑 ≥30 分钟（新电池） |

## 已知问题与踩坑

| 现象 | 原因 | 规避方式 |
|---|---|---|
| 上电后主控重启、行为乱 | 电机启动瞬间拉低电压（同一电源供电） | 电机与主控分开供电；或电池盒并联 470–1000μF 电容 |
| 传感器对着黑线也输出"白" | 探头离地太高（>15mm）或环境光太亮 | 降到离地 8–12mm，避开阳光直射，用可调电位器重新标定 |
| 小车原地打转不前进 | 左右电机线接反 | 对调同一电机两根线（OUT1/OUT2 或 OUT3/OUT4） |
| 电池很快耗尽 | 干电池内阻大，带载压降大 | 换新碱性电池；长期用改 2×18650（见扩展） |
