# tools · 开发机工具（预留）

本项目**不需要脚本工具**：烧录就是在 Arduino IDE 里点「上传」，标定就是"读两个数字、取中间值填进程序"。

若后续做批量或自动化，可在此放：

| 脚本 | 作用 |
|---|---|
| `check-env.sh` | 检查是否装了 CH340 驱动、串口是否可见 |
| `build-and-upload.sh` | 命令行编译并上传（用 arduino-cli） |
| `serial-log.py` | 把串口数据存成 CSV，便于对比调参 |

约定：每个脚本顶部写「用途 / 用法 / 依赖 / 影响范围」，且要能重复执行不出错。
