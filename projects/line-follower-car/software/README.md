# software · 循迹小车

本项目的"软件"只有两样，**都不需要自己开发**：

| 用途 | 用什么 | 在哪 |
|---|---|---|
| 写/上传程序 | Arduino IDE 2.x（或 mBlock 5 / Mixly 积木） | 见 `../docs/04-软件环境.md` |
| 看传感器数值 | Arduino IDE 自带「串口监视器」（波特率 9600） | 同上 |

下面三个子目录为**预留**，本项目当前用不到：

| 子目录 | 内容 | 本项目是否需要 |
|---|---|---|
| [`host/`](host/) | 图形化上位机 | 不需要（串口监视器足够） |
| [`sdk/`](sdk/) | 二次开发接口 | 不需要 |
| [`tools/`](tools/) | 烧录/标定脚本 | 不需要（IDE 点"上传"即可） |

> 若后续加蓝牙遥控，可在 `host/` 放一个手机端 App 说明或微信小程序方案。
