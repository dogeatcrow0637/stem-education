# 01 · 项目简介

> 适用版本：硬件 v1.0（Arduino UNO R3 兼容板 + L298N + 2 路红外循迹）　|　最后更新：2026-10-20　|　前置条件：无

## 这是什么

一辆两轮驱动的循迹小车：车头下方两个红外探头不断"看"地面，看到黑线就报告，主控按规则让左右两个轮子快一点或慢一点，小车就会自己沿着黑线跑。全部用成品模块**插线**组装，不用焊接、不用 3D 打印。

它解决的问题：给第一次接触机器人的孩子一个**当天就能看到结果**的项目。相比动辄几千元的机械臂，"感知 → 判断 → 动作"这条核心闭环，用 ￥100 就能跑通，失败成本极低。

## 能做什么

| 能力 | 说明 |
|---|---|
| 自动循迹 | 沿 15–20mm 黑线行驶，直角弯/缓弯不掉线（缓弯更稳） |
| 调速 | PWM 调左右轮速度，可做"快车/慢车"版本对比实验 |
| 阈值可调 | 用螺丝刀拧传感器上的电位器，或程序里改阈值（L3 关卡） |
| 串口观察 | 电脑上看到两个探头的实时读数，把"传感器在想什么"变成数字 |
| 可扩展 | 加 5 路循迹更稳、加蓝牙变遥控、加蜂鸣器做"到站提示" |

## 关键参数

| 参数 | 值 |
|---|---|
| 主控 / 平台 | Arduino UNO R3 兼容板，ATmega328P，CH340 串口芯片 |
| 供电 | 电机 4×AA（约 6V）／主控 5V（USB 或 L298N 板载 5V 输出） |
| 尺寸 / 重量 | 约 200×140×70mm / 约 250g（以实物为准） |
| 关键指标 | 线宽 15–20mm；PWM 有效区间约 40%–100%；续航 ≥30 分钟（新碱性电池，实测为准） |
| 传感器 | 2 路 TCRT5000 红外反射模块，检测距离 3–15mm（建议 8–12mm） |

## 教学价值与目标人群

**适合谁**

- 8–12 岁小学生（L1 观察 / L2 协作 / L3 独立三档自适应）
- 完全零基础、不会焊接也不会写代码的家长
- 想先"小成本试水"，再决定要不要上机械臂的家庭

**教学目标**

1. 能说出机器人做事的三个环节：**传感器看 → 主控想 → 电机动**。
2. 能独立完成接线、烧录、跑通循迹，并解释"为什么它拐弯"。
3. 能改一个参数（速度/阈值）并说出改前改后的差别。

**前置知识**：无。会数数、能拧螺丝、认得红黑颜色即可。

| 项 | 量级 | 备注 |
