# docs · 循迹小车

本目录放**给人看的文档**。推荐编号与用途：

| 文件 | 用途 | 是否必需 |
|---|---|---|
| `01-项目简介.md` | 是什么、能做什么、教学价值、目标人群、前置知识 | ✅ |
| `02-选型与BOM.md` | 版本/型号差异、选型对比、采购渠道、参考价、替代方案 | ✅ |
| `03-组装与调试.md` | 分步骤装配、接线核对、通电自检、标定 | ✅ |
| `04-软件环境.md` | 操作系统版本、依赖、安装命令、一键脚本入口 | ✅ |
| `05-教学与课程.md` | 课时安排、实验任务、考核点、常见提问 | 按需 |
| `99-参考资源.md` | 官方仓库、Wiki、视频、社区帖（含链接与访问日期） | ✅ |

## 教学材料（两份，各有分工）

| 目录 | 是什么 | 怎么用 |
|---|---|---|
| [`家长实现/`](家长实现/00-总纲与路线图.md) | 家长实现手册（6 份） | 照着做就能出结果；**只写怎么做，不讲原理** |
| [`儿童课程/`](儿童课程/README.md) | 一课一个目录（课件 + 配图 + 知识卡） | 打开某课的 `课件.html` 全屏放映；知识卡讲完原理当场发 |

写作要求：

- 文档头写明 **适用版本 / 最后更新 / 前置条件**。
- 危险操作（通电、抱闸、高压、激光、加热、旋转部件）用 ⚠️ 单独标注，并写清防护措施。
- 步骤要能**照着做**：每一大步给出「完成的判断标准」。
