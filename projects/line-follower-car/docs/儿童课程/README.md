## 上课与构建

```bash
# 一次构建全部课时（--strict 有告警就报错，可当自检门禁）
python3 .trae/skills/stem-project-onboarding/scripts/build_slides.py projects/line-follower-car/docs/儿童课程/*/课件.md --strict
```

双击 `课件.html` → 浏览器按 `F` 全屏、`←→` 翻页、`N` 看讲者备注、`Ctrl+P` 导出 PDF 当讲义。

## 目录约定

- 一课一个目录，固定命名 `第NN课-课题`；
- 每课内固定件：`课件.md`（源）、`课件.html`（放映）、`图/`（配图）、`知识卡/`（本课发的卡）、`README.md`（课时卡）；
- 换成本工位实拍照片：覆盖本课 `图/` 下的同名文件即可，课件 md 不用改；
- 加一课：按第 1 课的结构新建 `第NN课-课题/`，再在 [`../05-教学与课程.md`](../05-教学与课程.md) 的课时表登记一行。
