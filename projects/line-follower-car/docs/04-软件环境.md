# 04 · 软件环境

> 最后更新：2026-10-20　|　已验证操作系统：macOS 14+ / Windows 10+ / Ubuntu 22.04（均可，仅串口驱动不同）

> 说明：本项目**不需要**虚拟机、容器或 Linux。Arduino IDE 与 mBlock 均为图形化安装，家用电脑直接可跑。

## 一、环境要求

| 项 | 版本 | 说明 |
|---|---|---|
| 操作系统 | Windows 10+ / macOS 12+ / Ubuntu 20.04+ | 任意一款都行 |
| 开发工具（二选一） | Arduino IDE 2.x ／ mBlock 5 ／ Mixly 2.0 | 小学生先用积木（mBlock/Mixly），进阶用 Arduino IDE |
| 串口驱动 | CH340/CH341 驱动 | UNO 兼容板多为此芯片；Win 需装驱动，macOS 12+ 免驱 |
| 依赖库 | 无第三方库 | 示例代码只用 Arduino 自带函数 |
| 硬件接口 | USB-A/USB-C（视板而定）+ 串口 | 波特率 9600 |

## 二、安装

```bash
# 方案一：Arduino IDE（进阶，写 C 代码）
#   1) 官网下载：https://www.arduino.cc/en/software
#   2) 安装后打开 → 工具 → 开发板选 "Arduino Uno" → 端口选出现的 USB 口
#   3) CH340 驱动：Windows 从卖家提供的链接或 wch.cn 下载安装

# 方案二：mBlock / Mixly（推荐小学生，积木拖拽）
#   mBlock 5：https://www.mblock.cc/   安装后选 "Arduino Uno"
#   Mixly 2.0：http://mixly.org/       安装后选 "Arduino Uno"

# 本项目仓库内不需要安装任何脚本；示例程序直接在 IDE 里打开：
#   firmware/line_follower/line_follower.ino
```

## 三、运行与验证

```bash
# 1) 用 USB 线连电脑与 UNO，IDE 里选对"端口"
# 2) 打开 firmware/line_follower/line_follower.ino → 点"上传"
# 3) 上传成功后：打开"串口监视器"，波特率设 9600
```

**验证标准**：串口监视器里每 200ms 打印一行类似
`L=980 R=120 | 状态: 直行`——说明程序在跑、传感器在读数。把探头分别对着黑线与白底，数值应明显变化。

## 五、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 上传报 "avrdude: stk500_recv()" | 端口选错 / 板型选错 | 重选端口与"Arduino Uno" |
| 找不到端口 | CH340 驱动未装 / 线只供电 | 装 CH340 驱动；换数据线 |
| 串口全是乱码 | 波特率不是 9600 | 串口监视器右下角改成 9600 |
| 端口被占用 | mBlock 与 Arduino IDE 同时开着 | 关掉其中一个再上传 |
| 上传后无反应 | 没点"上传"只点了"验证" | 点向右箭头"上传" |
| macOS 提示"无法打开" | 未签名拦截 | 系统设置 → 隐私与安全性 → 仍要打开 |
