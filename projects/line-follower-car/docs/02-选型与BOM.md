# 02 · 选型与 BOM

> 适用版本：v1.0　|　最后更新：2026-10-20　|　用途：决定买整包套件还是散件自采、还要额外准备什么。

## 一、两条采购路线

| 参数 | 方案 A：整包套件 | 方案 B：散件自采 |
|---|---|---|
| 内容 | 商家把 UNO + L298N + 底盘 + 循迹模块 + 线材打包 | 逐件买（可选更高质量件） |
| 主控 | Arduino UNO R3 兼容板（CH340） | 同上，或升级 ESP32（可蓝牙） |
| 循迹 | 常见配 2 路或 5 路 | 自选 2 路（简单）或 5 路（更稳） |
| 供电 | 底盘套件一般带 4×AA 电池盒 | 自配 4×AA 电池盒带开关 |
| 价格 | ￥55–75（量级） | ￥70–95（量级） |
| 优点 | 一次到货、线材配套、最省心 | 件可选好、便于后续复用与升级 |
| 缺点 | 个别件质量一般 | 要自己核型号、可能要分 2–3 家买 |

**选型建议**

| 场景 | 推荐 | 理由 |
|---|---|---|
| 第一次做、想最快跑通 | 方案 A 整包套件 | 少踩"型号不匹配/少线材"的坑 |
| 已有 Arduino、想省钱 | 方案 B 只补底盘+驱动+循迹 | 复用家里主控，成本可压到 ￥50 内 |
| 想顺便教编程升级 | 方案 B 选 ESP32 版 | 后续可加蓝牙遥控、WiFi 上位机 |

## 二、模块型号说明（散件自采要点）

| 模块 | 推荐型号 | 要点 |
|---|---|---|
| 主控 | Arduino UNO R3 兼容板（CH340 串口） | 认"R3"端子排布；CH340 驱动好装，别买无标杂板 |
| 驱动 | L298N 双 H 桥模块 | 板上 5V 使能跳帽可给 UNO 供电；注意散热片方向 |
| 底盘 | 2WD 亚克力/铝合金底盘套件 | 看是否含"2 个 TT 减速电机 + 2 轮 + 万向轮 + 电池盒 + 螺丝" |
| 循迹 | 2 路 TCRT5000 或 5 路一体模块 | 2 路最易理解；5 路更稳但要学"权重"概念 |
| 电池 | 4×AA 碱性（家里常有） | 别用旧电池；长期玩建议 2×18650 + 充电器 |
| 线材 | 公母杜邦线 20cm（约 20 根） | 多买几根备用，杜邦线是易损件 |

**不含项（容易漏买）**：黑胶带/黑色电工胶带（做赛道，家里常有）、扎带、双面胶/热熔胶棒（固定传感器）、小十字螺丝刀（家里可能有）、4 节 5 号电池。

## 三、成本构成（MVP，方案 A 口径）

| 类别 | 金额(CNY) | 说明 |
|---|---|---|
| 主控与电子（UNO+L298N+循迹+线材） | ￥40–50 | 整包套件通常已含 |
| 结构件（底盘套件） | ￥15–25 | 含电机、轮、万向轮、电池盒、螺丝 |
| 标准件与耗材（电池、胶带、扎带） | ￥5–15 | 电池若家里已有可记 ￥0 |
| 工具 | ￥0–15 | 只需要小十字螺丝刀，多数家庭已有 |
| **合计（MVP）** | **￥65–100** | 不含已有电池与胶带 |

**外协费**：本项目**不需要**焊接/打印/加工；若想让小车更漂亮，可选嘉立创 3D 打印外壳（￥10–30，见 `../enclosure/print-notes.md`）。

## 四、BOM 与采购

- 明细：[`../hardware/bom/bom_lfc_v1.0.csv`](../hardware/bom/bom_lfc_v1.0.csv)（可直接按"是否 MVP"列筛选下单）
- 采购注意：
  1. **先问卖家"是否含电池盒和杜邦线"**，避免重复买或漏买。
  2. 缺货替代：UNO 可用"Arduino UNO R3 改进版/CH340 版"；2 路循迹缺货可用 5 路。
  3. 备损：杜邦线、扎带按 1.5 倍买；TT 电机是唯一易损件，可多备 1 个（￥5）。
  4. 价格随时间波动，**下单前以页面为准**（本表访问日期 2026-10-20）。
