# 家长实现总纲（循迹小车）

| 字段 | 值 |
|---|---|
| 项目编号 | 02 |
| 项目目录 | `projects/line-follower-car` |
| 适用版本 | 硬件 UNO R3 v1.0 ／ 固件 line_follower v1.0 |
| 最后更新 | 2026-10-20 |
| 前置条件 | 会拧螺丝、认得红黑颜色即可；不需要焊接/编程/3D打印 |

> 本手册面向**完全零基础的家长**，用于带一名小学生从零把小车做出来并讲明白。工程细节以 `projects/line-follower-car/docs/` 为准，本手册只讲"怎么带着孩子做"。

## 一句话目标

做完之后，孩子能独立完成的最小成果是：**接线 → 烧录 → 让小车沿黑线自己跑完 1.5 米**；能看到的现象是：**车头两个小灯在黑白之间一亮一灭，小车自己拐弯跟着黑线走**。

## 这套手册怎么用

1. **先读安全红线**（本文件最后一节），再读 `05-安全与工具采购清单.md`。
2. 按 `02-里程碑与任务卡.md` 从头做；**一张卡一次坐下做，做完打勾再进下一张**。
3. 每张卡按孩子水平选一档（同一项目不同环节可选不同档）：

| 档 | 孩子做什么 | 家长做什么 | 什么时候升档 |
|---|---|---|---|
| L1 观察 | 递零件、对编号、按开关、说出现象 | 全部动手 + 讲解 + 防护 | 能说清"这步在做什么、成功会看到什么" |
| L2 协作 | 拧螺丝、插杜邦线（断电）、插拔 USB、填验收表 | 把关极性与紧固、执行送电 | 同类动作无提示也能做对 |
| L3 独立 | 看接线表独立插线、改参数、记数据、讲原理 | 只做安全监护，允许失败 | 能讲清"上次为什么失败、这次改了什么" |

4. 需要**外包**的环节：本项目**没有**。全流程可在家完成，不需要焊接、打印、报班。
5. 卡住了：先查 `04-验收与展示.md` 的失败排查表，再对照卡片里的"失败兜底"。

## 总路线图

```mermaid
graph LR
  M0[M0 定稿与采购] --> M1[M1 通电自检]
  M1 --> M2[M2 轮子能转]
  M2 --> M3[M3 看见黑线]
  M3 --> M4[M4 跑通赛道]
```

| 里程碑 | 孩子的可见成果 | 家长工时估算 | 放弃/跳过条件 |
|---|---|---|---|
| M0 定稿与采购 | 采购清单打勾 + 到货核对表 | 1 小时 | 缺货→换替代型号继续 |
| M1 通电自检 | UNO 上电亮灯 + 串口出字（照片） | 0.5 小时 | 灯不亮先查电源与极性 |
| M2 轮子能转 | 左轮/右轮各按指令转 2 秒（≤10 秒视频） | 1–1.5 小时 | 单轮不转先查该轮使能脚 |
| M3 看见黑线 | 串口显示黑/白两组明显不同的数 | 1 小时 | 数值不变→调电位器/降高度 |
| M4 跑通赛道 | 连续 2 次跑完 1.5m 跑道（录屏） | 1.5–2 小时 | 掉线就降速、慢一点再试 |

## 时间与预算

| 项 | 估算 | 说明 |
|---|---|---|
| 家长工时合计 | 约 6–8 小时 | 不含采购等待；分 4 次，每次 ≤45 分钟 |
| 日历周期 | 1–2 周 | 建议每周 2–3 次 |
| MVP 预算（能跑通最小闭环） | ￥65–100 | 明细见 `05-安全与工具采购清单.md` |
| 全量预算（含 5 路循迹/蓝牙/打印外壳） | ￥110–180 | 跑通 M4 后再考虑 |
| 可能的外协费 | ￥0 | 本项目无外包环节；想要好看外壳才需嘉立创打印 ￥10–30 |

## 场地、作息与收纳

- 工作台：平整桌面 + 桌面铺一块垫子；地上贴一条 ≥1.5m 黑线当跑道（客厅地板即可）。
- 单次时长：≤ 45 分钟（2 张卡），每 3 张卡安排一次"展示时刻"（拍 ≤10 秒视频）。
- 收纳：螺丝、杜邦线分格放；**每次结束拔电池、拔 USB 再离开**。
- 跑道贴好后先留 1 米直道，最后再加弯道，别一上来就上 S 弯。

## 安全红线（先读这一页）

1. 危险动作一律家长单独执行：**接电源正负极、上电池、第一次送电、用热熔胶**。
2. 上电前必须做三件事：**① 极性核对 ② 小车放桌面、轮子悬空 ③ 手离开轮子**。
3. 出现异常（异味 / 发烫 / 冒烟 / 轮子卡住嗡嗡响）→ **立即拔电池**，再排查，别边跑边查。
4. 详细清单见 `05-安全与工具采购清单.md`。

## 假设与已知限制

- 本文假设：家长不会焊接、不写代码，家里有一台能装软件（USB 口）的电脑。
- 未验证项：循迹阈值、续航时间、最高稳定速度——需实物实测后回填（`待验证`）。
- 关键风险：**电源正负极接反会烧模块**，按 `../03-组装与调试.md` 的接线表逐条核对即可避免。
