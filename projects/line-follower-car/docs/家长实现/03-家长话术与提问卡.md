# 家长话术与提问卡（循迹小车）

| 字段 | 值 |
|---|---|
| 适用版本 | v1.0 |
| 最后更新 | 2026-10-20 |
| 前置条件 | 与 `02-里程碑与任务卡.md` 配套使用 |

> 目标：家长不讲课，只提问。孩子说出来，才算学会。每张卡至少问一次"为什么"。

## 1. 各阶段引导提问（每个里程碑选 3 个问）

| 里程碑 | 提问 |
|---|---|
| M0 定稿与采购 | 1）"你见过会自己拐弯的车吗？在哪见过？" 2）"整包和散件，哪个省事、哪个省钱？" 3）"第一批只买必须的，你猜哪些可以以后再加？" |
| M1 通电自检 | 1）"通电以后你看到什么亮了？" 2）"如果灯不亮，可能是哪三个原因？" 3）"为什么现在只插 USB、不装电池？" |
| M2 轮子能转 | 1）"刚才是谁让轮子转起来的？" 2）"把速度数字改大，你猜会怎样？先猜再试。" 3）"轮子转的时候有声音吗？说明什么？" |
| M3 看见黑线 | 1）"黑线上读出来的数和白纸上比，哪个大？" 2）"为什么探头要离地那么矮？" 3）"如果两个探头读数一样，它会往哪走？" |
| M4 跑通赛道 | 1）"它拐弯之前，是先看到了什么？" 2）"为什么跑快了容易掉线？" 3）"哪一步最容易出错，你怎么发现的？" |

## 2. 孩子常问的"为什么"与答法

| 孩子的问法 | 一句话答法 |
|---|---|
| 为什么它认识黑线？ | "黑颜色把光吃掉了，白颜色把光弹回来，探头一数弹回来的光就知道下面是什么颜色。" |
| 为什么要两个探头？ | "一个只知道在不在线上，两个才知道自己是偏左还是偏右，才能拐回中间。" |
| 为什么灯灭了是黑线？ | "黑线把光吸走了，探头收不到光就灭了——这是我们和它约好的暗号。" |
| 为什么跑快会掉线？ | "看到线到拐弯的时间变短了，像骑车冲太快来不及拐弯。" |
| 为什么要先接黑线再接红线？ | "先接负的、最后接正的，就像先关水龙头再开水——不容易出危险。" |
| 为什么两根线不能接反？ | "电像水，倒着流会把里面的零件冲坏。" |
| 为什么电池没电它就不听话？ | "电不够，电机没劲、大脑还可能重启，就像没吃饭没力气。" |
| 为什么红线黑线要分开？ | "红线是'正'、黑线是'负'，像电池的两头，接对了才通。" |

## 3. 本项目术语生活类比表

| 术语 | 生活类比 | 一句话解释 |
|---|---|---|
| 电池 / 电源 | 小水库 | 提供"水压"让电流动起来 |
| 电压 | 水压 | 推电往前走的"劲" |
| 电流 | 水流 | 每秒流过多少电 |
| 主控 / 单片机 | 小脑袋 | 接收信息、做决定 |
| 固件 / 程序 | 小脑袋里的想法 | 装在主控里的一套命令 |
| 电机 | 小马达 | 通电就转，把电变成动作 |
| 减速电机 | 会省劲的马达 | 转得慢但力气大，像自行车低速挡 |
| 驱动板 L298N | 电机的"大力士翻译" | 小信号指挥大电流去带动电机 |
| 循迹探头 | 会数光的眼睛 | 用反射光的多少分辨黑与白 |
| 阈值 | 及格线 | 数超过它就判"黑"，不超过就判"白" |
| PWM 调速 | 快速开关水龙头 | 手一开一关得越快，水越大 |
| 共地 | 说同一种语言 | 两块板子的"负"要连在一起，信号才听得懂 |
| 串口 | 对讲机 | 电脑和主控互相说数字的通道 |

## 4. 收尾 20 秒复盘（每张卡结束必做）

1. "今天成功的标志是什么？"
2. "哪里最麻烦？"
3. "下次想改哪里？"

## 5. 关键话术（直接抄）

- 交付动作："你负责插线和对号，我负责最后送电。危险的那一步我一个人做，你在旁边看着。"
- 卡住时："先只找一件事：这一步和上一张卡比，哪里不一样？"
- 失败时："失败很正常，工程师每天在试。我们把它记成一条线索，下一张卡第一件事就查它。"
- 拒绝代劳："我可以说怎么做，但手是你的——所以这辆小车是你做的。"
- 升档："这张卡我不动手，你来接线，接完我检查。" 
- 红线提醒（每次上电前）："上电三件事是什么？你说一遍：极性对不对？轮子悬空没有？手离轮子远不远？"
