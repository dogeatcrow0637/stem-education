# 里程碑与任务卡（循迹小车）

| 字段 | 值 |
|---|---|
| 适用版本 | v1.0 |
| 最后更新 | 2026-10-20 |
| 前置条件 | 已读 `00-总纲与路线图.md`；材料已到货 |

**卡片规则**：一张卡 = 一次坐下 = 一个动作单元（≤25 分钟）；做完必须能看见结果并打勾。打勾格式：`- [x] 卡 M1-1`。每张卡完成盖一枚章，每 3 张卡安排一次"展示时刻"（拍照/录 ≤10 秒视频），每完成一个里程碑发一个称号（**材料员 → 接线员 → 观察员 → 调试员 → 小工程师**）。

## M0 定稿与采购

目标：型号定稿、MVP 物料到货、核对无缺件。

### 卡 M0-1：选版本与下单
- 目标（孩子视角）："我们决定买哪一套，把它请回家。"
- 物料：`05-安全与工具采购清单.md` 的 MVP 清单
- 三档分工：L1 一起看图片/视频并说出选哪套｜L2 一起对照清单点数量｜L3 做比较表（整包 vs 散件、价格/难度）并给结论
- 步骤：
  1. 看 2 分钟循迹小车演示视频 → 结果：孩子能说出"我们要做的就是它"
  2. 对照两种方案选一种 → 结果：写下一行结论（方案 + 理由）
  3. 下单 → 结果：订单截图存档
- 验收判据：清单每项都有"已下单/替代型号"状态
- 失败兜底：缺货 → 换替代型号或分两家买
- ⚠️ 安全：—

### 卡 M0-2：到货核对
- 目标："所有零件都到齐，一个都不少。"
- 物料：采购清单 + 分格收纳盒
- 三档分工：L1 报出零件名｜L2 点数并分格收纳｜L3 记录缺件与错件
- 步骤：逐项核对 → 结果：清单全部打勾；分格收纳 → 结果：照片一张
- 验收判据：无未处理缺件（缺件已联系商家）
- 失败兜底：缺件先做不依赖它的里程碑（如先装底盘）
- ⚠️ 安全：—

**发称号：材料员**

## M1 通电自检

目标：主控通电、串口有输出，孩子看到"活的"第一眼反馈。

### 卡 M1-1：装底盘与轮子
- 目标："让它先站起来，能推着走。"
- 物料：2WD 底盘套件（2 电机 + 2 轮 + 万向轮 + 螺丝）
- 三档分工：L1 递件对号｜L2 拧螺丝（家长把关拧紧）｜L3 独立照图装
- 步骤：
  1. 电机卡进底盘两侧（都在内侧）→ 结果：电机不晃
  2. 装两个轮子 → 结果：手转不刮底盘
  3. 装底部万向轮 → 结果：放手能立住
- 验收判据：车放在桌上能立住，用手推能滑行不卡
- 失败兜底：轮子刮底盘 → 加垫片把电机垫出 1–2mm
- ⚠️ 安全：—

### 卡 M1-2：首次通电（家长执行送电）⚠️
- 目标："让它亮起来，证明电走到了。"
- 物料：UNO、USB 线、电脑
- 三档分工：L1 在安全距离外看并说出看到什么｜L2 家长口令下插 USB｜L3 自己插 USB 并口述检查项
- 步骤：
  1. USB 连 UNO 与电脑 → 结果：UNO 上 PWR 灯亮
  2. 打开 Arduino IDE 串口监视器（9600）→ 结果：看到程序打印的字
- 验收判据：PWR 灯常亮且串口有输出，无发烫
- 失败兜底：不亮 → 换 USB 口/换线；串口乱码 → 波特率改 9600
- ⚠️ 安全：此时**不接电池、不接电机**，只用 USB 供主控

**发称号：接线员**

## M2 轮子能转

目标：一个电机受控动作，孩子第一次看到"我让它转它就转"。

### 卡 M2-1：接线（家长执行，孩子看表核对）⚠️
- 目标："把线都接对，电才能听话。"
- 物料：L298N、杜邦线、电池盒
- 三档分工：L1 报线色/端子号｜L2 按接线表插杜邦线（**断电状态**）｜L3 独立照接线表接线并逐条复述
- 步骤：照 `../03-组装与调试.md` 的接线表 1–15 条接完 → 结果：每条都能对号
- 验收判据：**红线对 12V、黑线对 GND；UNO GND 与 L298N GND 相连**
- 失败兜底：拿不准就先只接"共地 + 电源"，别的先空着
- ⚠️ 安全：**只接线、不上电**；接完由家长复述一遍极性再送电

### 卡 M2-2：烧录并让左右轮转
- 目标："我发命令，它动一下。"
- 物料：`firmware/line_follower/line_follower.ino`
- 三档分工：L1 按按钮/看轮子｜L2 点"上传"并观察｜L3 自己改 `SPEED_NORMAL` 看快慢变化
- 步骤：
  1. IDE 打开示例 → 点"上传" → 结果：提示"上传成功"
  2. 上电池、轮子悬空 → 结果：左轮转、右轮转（可临时把程序改成只跑一遍）
  3. 观察转向 → 结果：前进时两轮都往前转
- 验收判据：左右轮都能转，方向正确、无卡顿（录 ≤10 秒视频）
- 失败兜底：不转 → 查该轮 ENA/IN 脚、共地；反转 → 对调该电机两根线
- ⚠️ 安全：轮子悬空再上电；手别碰轮子

**发称号：观察员**（第一次展示时刻：拍一段"轮子听我的话"）

## M3 看见黑线

目标：孩子亲眼看到"传感器在想什么"变成数字。

### 卡 M3-1：装探头并读数值
- 目标："让小车学会看黑线。"
- 物料：2 路循迹模块、双面胶/扎带
- 三档分工：L1 把纸片放黑线/白底上｜L2 固定探头到离地 8–12mm｜L3 自己读串口数值并记录
- 步骤：
  1. 探头装到车头，离地 8–12mm、两个同高 → 结果：小车放地上探头不蹭地
  2. 打开串口监视器（9600）→ 结果：看到 `L=xxx R=xxx`
  3. 分别对黑线和白底各读一次 → 结果：两组数字明显不同，记在纸上
- 验收判据：黑线读数与白底读数差距 ≥200（越大越好）
- 失败兜底：数值几乎不变 → 降高度、调电位器、避开强光
- ⚠️ 安全：—

### 卡 M3-2：把阈值填进程序
- 目标："告诉小车，多少算黑、多少算白。"
- 三档分工：L1 说"哪种颜色数大"｜L2 改 `THRESHOLD` 并重新上传｜L3 解释 `BLACK_IS_LOW` 为什么可能要改
- 步骤：取黑白读数的中间值填进 `THRESHOLD` → 上传 → 结果：探头对着黑线时串口状态变成"左拐/右拐"
- 验收判据：手动把左边对黑线，串口显示"左拐"；右边对黑线显示"右拐"
- 失败兜底：黑白反了 → 把 `BLACK_IS_LOW` 改 true/false 再上传
- ⚠️ 安全：—

**发称号：调试员**

## M4 跑通赛道

目标：完整闭环，做一次"一键演示"。

### 卡 M4-1：直线 → 加一个弯
- 目标："它自己能跟着线跑了！"
- 物料：黑胶带跑道（先 1 米直道，再贴一个缓弯）
- 三档分工：L1 当解说员："它现在在直行/在拐弯"｜L2 放车、捡车｜L3 调 `SPEED_NORMAL` 找不掉线的速度
- 步骤：
  1. 只跑直道 → 结果：能直着走完
  2. 加一个缓弯 → 结果：能自己拐过去
- 验收判据：连续 2 次通过直道+1 个弯
- 失败兜底：弯道掉线 → 降速（`SPEED_NORMAL` 调到 120）、探头前移 5–10mm
- ⚠️ 安全：小车别对着桌边冲，跑道离桌沿 ≥30cm 或放地上

### 卡 M4-2：Boss 关——给家人演示
- 目标："我做的小车，我来讲给你听。"
- 三档分工：L1 说 3 句话介绍｜L2 演示 + 说 1 分钟｜L3 独立做 3 分钟讲解（按 `04-验收与展示.md` 的展示脚本）
- 步骤：按展示脚本演一遍并录像 → 结果：录屏 + 3 分钟讲解
- 验收判据：能回答"哪里最难、怎么解决的"
- 失败兜底：紧张忘词 → 家长按展示脚本 4 个问题一个个问
- ⚠️ 安全：—

**发称号：小工程师**（最终展示时刻：录一段完整循迹 + 讲解）
