## 2. 失败排查表（按顺序查，不要跳）

| 现象 | 最可能原因（按概率排序） | 先查什么 |
|---|---|---|
| 上电后完全没反应 | USB 没插好 / 电池没电 / 开关没开 / 极性反接 | 换 USB 口 → 换新电池 → 核对极性 |
| UNO 灯闪或反复重启 | 电机启动拉低电压 / 电池电量不足 | 电机与主控分开供电；量电池电压（4×AA 应 ≥5V） |
| 主控认不到（无端口） | CH340 驱动未装 / 线只供电不传数据 | 装 CH340 驱动 → 换一根数据线 |
| 串口全是乱码 | 波特率不是 9600 | 串口监视器右下角改 9600 |
| 上传报错 stk500 | 端口/板型选错 / 端口被占用 | 重选端口与"Arduino Uno" → 关掉 mBlock |
| 轮子完全不转 | ENA/ENB 未接 / 未共地 / 电机线松 | 查该轮使能脚 → 查 GND 相连 → 重插电机线 |
| 小车原地打转 | 左右电机线接反 | 对调同一电机两根线（OUT1/OUT2 或 OUT3/OUT4） |
| 只走直线不拐弯 | 探头没接好 / 阈值错 / 探头太高 | 看串口数值有无变化 → 重新定阈值 → 降到 8–12mm |
| 循迹总掉线 | 速度太快 / 探头太靠后 / 环境光太强 | 降 `SPEED_NORMAL` → 探头前移 5–10mm → 避开强光 |
| 黑线白线分不清 | 探头太高 / 阈值不对 / 阳光直射 | 降高度、调电位器、换到室内柔和光下重标 |
| 跑几秒就停/乱走 | 电池快没电 / 接线松动 | 换电池 → 逐个按一按插头 |

## 3. 作品展示脚本（让孩子讲 3 分钟）

1. **它是什么**（30 秒）："这是我做的循迹小车，它能自己跟着黑线跑。"
2. **怎么做的**（60 秒）：按"先…然后…最后…"说三个最关键的步骤（接线 → 烧程序 → 调阈值）。
3. **最难的地方**（45 秒）："最难的是 __（如：它总掉线），我试了 __ 次，最后用 __（如：把速度调慢）解决。"
4. **我还想改**（45 秒）："下一步我想让它 __（如：加蜂鸣器，到终点会响）。"

家长只做两件事：计时、听完后问一个问题（"如果再来一次，你会先做什么？"）。
