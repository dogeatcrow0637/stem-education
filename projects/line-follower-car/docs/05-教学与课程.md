# 05 · 教学与课程

> 最后更新：2026-10-20　|　适用学段：小学 3–6 年级（8–12 岁）　|　课时安排：4 课时（每课时 45 分钟）
> 配套产出：`docs/儿童课程/`（一课一个目录：课件 + 配图 + 知识卡，md → 可放映 html）、`docs/家长实现/`

## 一、课程目标

学完能：

1. 说出机器人做事的闭环：**传感器看 → 主控想 → 电机动**，并能指着自己车上的部件对应。
2. 独立（或在提示下）完成接线、烧录、跑通循迹，并解释"为什么它看到黑线就拐弯"。
3. 改一个参数（速度或阈值）并说出改动前后的差别，形成"我能改机器"的自信。

## 三、实验任务

| # | 任务 | 难度 | 验收标准 |
|---|---|---|---|
| 1 | 通电点亮主控 | 入门 | UNO PWR 灯亮、串口有输出 |
| 2 | 左右轮分别转动 | 入门 | 左轮/右轮各按指令转 2 秒 |
| 3 | 读出黑/白数值 | 进阶 | 串口显示黑线与白底两组明显不同的数 |
| 4 | 单探头循迹（只用一个探头拐弯） | 进阶 | 小车能沿直线+一个弯跑过去 |
| 5 | 双探头完整循迹 | 挑战 | 连续 2 次跑完 ≥1.5m 赛道不掉线 |
| 6 | 自主改动（改速度/阈值/加蜂鸣器） | 挑战 | 有改动前后对比记录，能说清原理 |

## 五、常见提问（FAQ）

| 学生问题 | 回答要点 |
|---|---|
| 为什么它认识黑线？ | 红外光照到**黑色被吸收、白色被反射**，探头收到的反射光不一样，就"知道"下面是黑还是白。 |
| 为什么要两个探头？ | 一个探头只知道"我在不在线上"，两个才能知道"我偏左了还是偏右了"，才能拐回中间。 |
| 为什么灯灭了就是黑线？ | 黑线把光吸走了，回来的光少，探头的灯就灭（或读数变小）——这只是一个约定，程序里要对得上。 |
| 为什么它跑太快会掉线？ | 跑得快，看到线到做出反应的时间变短，容易冲过头。就像跑步急转弯要减速。 |
| 为什么电池没电它就不听话？ | 电不够，电机转得慢、主控还可能重启，像人没吃饭没力气。 |
| 为什么不能直接用 220V？ | 电压太高会电人、烧坏零件；我们只用几节干电池的小电。 |

## 六、安全须知（必讲）

1. ⚠️ **接线和送电由家长做**；孩子只做插杜邦线（断电状态）、拧螺丝、看现象。
2. ⚠️ 上电前：轮子悬空、小车放桌面、手离开轮子；**别让小车自己冲下桌子**。
3. ⚠️ 出现异味、发烫、冒烟 → **立即拔电**，不边跑边查。
4. ⚠️ 电池别用破损/鼓包的；不要拆电池、不要给一次性干电池充电。
5. ⚠️ 不要用金属物在通电时戳电路板，避免短路。
