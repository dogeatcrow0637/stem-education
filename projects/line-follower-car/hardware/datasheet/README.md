# datasheet · 手册与关键参数

放模块手册与**实际用到的关键参数摘录**，避免每次翻 PDF。

## 本项目涉及的模块

| 模块 | 型号 | 关键参数 | 手册 |
|---|---|---|---|
| 主控 | Arduino UNO R3（ATmega328P） | 5V 逻辑、16MHz、14 路数字 IO、6 路模拟输入、每路 IO ≤40mA | arduino.cc 官方文档 |
| 驱动 | L298N 双 H 桥 | 电机电压 5–35V、每路持续 2A（峰值 3A）、PWM ≤20kHz | 卖家页 / ST 数据手册 |
| 循迹 | TCRT5000 红外反射 | 检测距离 3–15mm（建议 8–12mm）、模拟/数字双输出 | 卖家页 / Vishay 数据手册 |
| 电机 | TT 减速电机（130 型） | 3–6V、约 1:48 减速比、空载约 200mA | 卖家页 |

- 命名：`<型号>_datasheet.pdf`，例：`L298N_datasheet.pdf`
- 手册体积大时只留外链，登记到 `../../docs/99-参考资源.md`
- 建议另建 `key-params.md`，把上面这张表抄成完整版（含供电范围、峰值电流）
