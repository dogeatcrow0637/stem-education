# hardware · 循迹小车

| 子目录 | 放什么 | 本项目的文件 |
|---|---|---|
| `bom/` | 采购清单 | [`bom_lfc_v1.0.csv`](bom/bom_lfc_v1.0.csv)（MVP ￥65–100） |
| `schematic/` | 接线图与端子表 | 接线表在 `../docs/03-组装与调试.md`；示意图见 `../docs/儿童课程/第02课-让轮子转起来/图/图-接线.svg` |
| `datasheet/` | 芯片/模块手册与关键参数 | 见 `datasheet/README.md` |

约定：

1. 接线资料**图 + 表**成对提供；表里写清端子号、信号名、线色、对端、备注。
2. BOM 字段固定（见 `bom/README.md`），价格注明**采集日期与币种**。
3. 本项目**不需要焊接**，全部杜邦线插接，因此没有 PCB 工程文件；想要一体化板见 `../docs/99-参考资源.md` 的"进阶"。
