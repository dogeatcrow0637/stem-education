# enclosure · 循迹小车

外壳、支架、转接件等**结构件**资料。

> **本项目可以不打印任何东西**：MVP 用市售亚克力底盘套件开箱即装；探头用扎带/双面胶固定即可。打印只是"更好看、更稳"的可选项，见 [`print-notes.md`](print-notes.md)。

| 子目录 | 内容 | 格式 |
|---|---|---|
| `step/` | 可编辑源文件（可选） | STEP、F3D、FreeCAD |
| `stl/` | 可直接切片打印（可选） | STL、3MF |

命名规则：`件名_版本_数量.stl`（例：`sensor_bracket_v1.0_x1.stl`）。

- 打印参数、下单渠道（嘉立创 3D 打印）与装配顺序统一写在 [`print-notes.md`](print-notes.md)。
- 本项目**无金属加工件**。
- 切片产物 `.gcode` 不入库（见仓库 `.gitignore`），参数记录在文档里即可复现。
