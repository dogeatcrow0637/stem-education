# code · 算法与实验代码

本项目**没有独立的上位机算法代码**。小车的"算法"就是 `firmware/line_follower/line_follower.ino` 里的 4 条判断规则（看不到线→直走、左看到→左拐、右看到→右拐、都看到→直走）。

若后续做进阶实验，建议按主题建子目录：

```
code/
├── follow-5ch/      # 5 路循迹的加权算法
├── pid-speed/       # 用 PID 让速度更稳
└── notebooks/       # 串口数据分析（Python）
```

## 约定

1. 每个子目录一个 `README.md`：目的、输入、输出、运行命令、依赖。
2. 实验要能复现：写清"改哪个文件、改哪一行、期望看到什么"。
3. 记录实验结论（哪个参数有效、现象对比），否则代码无法转成教学素材。
