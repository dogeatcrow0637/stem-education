## 下单检查

- [ ] 开发板标题含 **AMOLED / 触摸 / 1.75**；确认 1.75 还是 1.75C
- [ ] 电池 3.7V、带保护板、MX1.25 2P，红黑顺序与板子一致；官方铝壳按 **702530（7×25×30）** 买，最大试 702540/802535，1500mAh 放不进
- [ ] 喇叭 8Ω 2W，插头与板子喇叭座匹配
- [ ] USB-C 线支持数据传输（不是纯充电线）
- [ ] 外壳先不打样：纸板 1:1 模型确认开孔与厚度后再打印
