## 6. 能不能插 4G 流量卡？

**不能直接插。** ESP32-S3 没有蜂窝基带，这块板也没有 SIM 卡座。要用 4G，必须外接 4G 模块，SIM 卡插在模块上。

| 方式 | 需要什么 | 优点 | 代价 |
|---|---|---|---|
| 手机热点 / 4G MiFi | 无 | 零改动，最稳 | 手机/MiFi 要随身、要充电 |
| Cat.1 模块（Air780E、ML307R、EC800M） | UART + 天线 + IoT 卡 | 体积小、便宜（模块约 ¥30–80） | 要改固件（AT/PPP 拨号）、单独供电 |
| Cat.4 模块（EC20、SIM7600、A7670） | UART/USB + 天线 + 卡 | 通用、资料多 | 更贵、更耗电、体积更大 |

关键坑：

- **电源**：4G 发射瞬间要 1–2A，不能从板子 3.3V 取电；要电池经 buck + 大电容，否则会重启。
- **天线**：金属怀表壳会屏蔽信号，必须留天线窗或外置天线。
- **续航**：500mAh（702530 原装）电池 + 4G 常连，会明显短于 Wi-Fi 场景（`待实测`）。
- **服务端**：设备走 4G 后不在家里局域网，服务端必须有公网地址（云服务器 + HTTPS/WSS，或内网穿透）。
- **固件**：自研固件 V0.1 不含 4G 驱动；要上 4G 需自己接 Cat.1/Cat.4 模块并写 PPP/AT 驱动，工作量大（`待验证`）。

**结论**：MVP 先用 Wi-Fi；出门临时用手机热点或 4G MiFi；确实要做独立 4G，放到 V2，加 Cat.1 模块并把服务端改成公网部署。

> **本项目决定（2026-11-13）**：不增加 4G 模块。家里连路由器，外出连手机 2.4GHz 热点；服务端要么在云上，要么让服务端电脑也连同一个热点。4G 模块只作为 V2 备选。

### 能用小天才手表共享网络吗？

**不能，至少没有可用的官方路径。**

- 小天才手表是封闭系统，没有「蓝牙网络共享 / 热点」给第三方设备用的功能，也不能装自定义 App；
- 它自己的 4G 只服务手表自己的云，不对外提供上网通道；
- 就算手表开放 BLE，ESP32-S3 **只支持 BLE，不支持经典蓝牙**，而手机/手表常见的「蓝牙共享网络」（PAN/BNEP）走的是经典蓝牙，S3 接不了；
- 部分小天才型号能连 Wi-Fi，但那是「手表上网」，不是「手表当热点」。

可行替代：**手机 2.4GHz 热点**、**4G MiFi/随身 Wi-Fi**、或 V2 的 **Cat.1 模块**。别在这条路上花时间。
