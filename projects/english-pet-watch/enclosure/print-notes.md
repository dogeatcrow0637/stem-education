**通用建议**

- 承力件用 PETG；纯外观件可用 PLA。
- 螺丝孔预留 0.2mm 间隙；需要反复拆装时加热熔铜螺母（M2）。
- 大平面件加 brim 防翘边；PETG 关风扇或低风速。
- 打印前用卡尺量板子实际尺寸，按实测改模型，不要只信标称。

## 3. 金属加工件清单

无。本项目只用打印件 + 标准螺丝 + 挂绳。

## 4. 装配顺序

1. 清理支撑与毛刺，试装屏幕和板子，确认不干涉。
2. 前壳贴泡棉，放屏幕/板子，四角固定。
3. 喇叭装后盖，线走边缘；电池装电池托，远离天线。
4. 干装合盖，检查 USB-C、麦克风孔、喇叭孔、触摸。
5. 锁 M2 螺丝（手拧到贴合），装表圈与挂绳。
6. ⚠️ 装壳前断电；电池不压螺丝；天线区留空。

**完成判断标准**：合壳后屏幕无压痕、触摸正常、USB-C 能插、麦克风能拾音、Wi-Fi 能连、整机不晃。

## 5. 易错点

| 现象 | 原因 | 规避 |
|---|---|---|
| 屏幕压出亮斑 | 表圈/前壳压到 AMOLED | 开孔放大 0.3–0.5mm，加 0.5mm 泡棉 |
| 合壳后 Wi-Fi 掉线 | 电池/金属挡天线 | 天线窗留塑料，电池移到另一侧 |
| 喇叭破音 | 后腔漏气/太小 | 加密封泡棉，开孔率 ≥15% |
| 螺丝柱开裂 | 孔径太小/过拧 | 预留 0.2mm，手拧 |
| 电池装不进 | 没留膨胀余量 | 电池仓每边留 1mm |
