# enclosure · 英语宠物怀表

> 适用版本：v0.1（未建模、未打印）　|　最后更新：2026-11-13
> 目标：把开发板、喇叭、电池装进一个可以挂书包的圆怀表壳；**不追求防水**。

## 1. 设计约束

| 项 | 目标值 | 说明 |
|---|---|---|
| 外径 | 60–68mm | 覆盖 1.75 寸屏与板子 |
| 厚度 | 18–24mm | 含屏幕、板子、电池、后盖 |
| 屏幕开孔 | 与可视圆屏同心 | 留 0.3–0.5mm 间隙，不压屏幕 |
| USB-C 开孔 | 侧边，插头能进 | 留 1mm 余量 |
| 麦克风孔 | 2 个，正对板载麦克风 | 不要被电池/走线挡住 |
| 喇叭孔 | 背面或侧边阵列 | 8Ω 2W，开孔率 ≥15% |
| 天线窗 | 塑料，不贴金属/电池 | Wi-Fi 天线附近留空 |
| 挂绳孔 | 顶部，≥3mm | 穿短挂绳 |

## 3. 三步走（不要跳步）

1. **纸板模型（30 分钟）**：按屏幕外径画圆，剪出 USB-C、喇叭、麦克风孔，确认板子能放进去、手指能点到屏幕。
2. **简化壳（PETG 打印）**：先打一个厚壁圆盒 + 后盖，不追求曲面；验证装配与信号。
3. **成品壳（可选）**：加表圈、挂绳耳、按键帽，打磨倒角。

## 4. 装配顺序

1. 断电，取下电池。
2. 屏幕/板子放入前壳，四角用双面胶或尼龙柱固定。
3. 喇叭装入后盖，线走边缘，不压电池。
4. 电池用双面胶固定在电池托上，远离天线区。
5. 合盖，先干装确认无干涉，再锁 M2 螺丝。
6. 挂绳穿过顶部挂绳孔，打结固定。

**完成判断**：屏幕无压痕、触摸正常、USB-C 能插、麦克风孔不被挡、合壳后 Wi-Fi 仍能连。

## 5. 易错点

| 现象 | 原因 | 规避 |
|---|---|---|
| 屏幕边缘发红/压痕 | 表圈压到 AMOLED | 开孔放大 0.3–0.5mm，加泡棉 |
| 合壳后 Wi-Fi 变差 | 电池/金属挡住天线 | 天线区留塑料窗，电池移开 |
| 喇叭破音 | 后腔太小/漏气 | 留后腔，开孔率 ≥15%，加密封泡棉 |
| 螺丝滑丝 | 自攻螺丝过拧 | 手拧到贴合即可，不追求死紧 |
| USB-C 插不进 | 开孔偏/毛刺 | 开孔留 1mm 余量，锉刀修边 |

> ⚠️ 装壳前必须断电；电池不要压在螺丝下；不要用金属壳包住天线。
