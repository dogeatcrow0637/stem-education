**关键结论**：

- **3g 内存上限会 OOM**（ASR 模型加载峰值超过 3g，容器 exit 137）；5g 可稳定启动；
- ASR 常驻约 3.1 GiB，不是之前估的 1–2 GiB；后续要上全模块/本地 TTS 需重新算内存；
- 主机还剩 2.9 GiB 可用，游戏 API 很轻（约 18 MiB），当前够用但余量不大；
- Swap 已用 931 MiB，持续观察；不要在同一台机器再起大内存服务。
