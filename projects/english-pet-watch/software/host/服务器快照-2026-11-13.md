## 五、对 EPW 部署的结论

| 项 | 判断 |
|---|---|
| 能否同机跑 xiaozhi-server | **可以**：5.7 GiB 可用、4 核、151 GB 磁盘 |
| 端口 | xiaozhi 用 `127.0.0.1:8000/8003`，nginx 对外 `5801`；安全组只开 5801 |
| 与游戏 API 隔离 | 独立目录 `/home/ubuntu/english-pet-watch`、独立容器；不动 8787/5800 |
| 内存预算 | xiaozhi + FunASR 预计 1–2 GiB，上线后 `docker stats` 观察 |
| 需要确认 | 安全组放行 5801；`8818` 用途；`check-new-relea` 100% CPU |
| 不建议 | 同时起 MySQL 全模块；跑 `docker image prune -a`；直接 kill 未知进程 |
