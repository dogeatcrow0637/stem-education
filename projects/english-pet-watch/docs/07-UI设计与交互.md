## 1. 设计目标

| 目标 | 做法 |
|---|---|
| 像一块正常的智能手表表盘 | 单个表盘页：大号数字时间（主视觉）+ 中文日期 + 天气 + 电量 + Wi-Fi；**不出现电子宠物** |
| 给小朋友看的纯数字表盘 | **完全去掉刻度环、分钟数字和装饰刻度**；只保留圆润大数字，一眼读懂 |
| 字体像产品，而不是默认字体 | 时间用 Fredoka SemiBold 150px（圆润略胖、数字辨识度高），中文用 Noto Sans SC 20px；不用小于 16px 的中文 |
| 交互像 Apple Watch / 华为手表 | 表盘下滑 → 控制中心；控制中心上滑 → 表盘；状态 / 亮度 / 音量页从左往右滑 → 关闭回上一层 |
| 控制中心像产品，不像调试面板 | 4+3 圆形磁贴，每块磁贴一个独立手绘图标（芯片 / 太阳云 / 电池 / 手电 / 太阳 / 喇叭 / 猫脸），**不再用单一色环和进度弧** |
| 一眼区分充电 / 普通 | 外圈常驻三色儿童科技环；电量主色始终绿色，充电时额外叠一圈天蓝柔光 |
| 去掉点击换屏 | 表盘不响应点按；点击只作用于明确的磁贴 / 按钮 |
| 不误触 | 调节页只有按在轨道上才能拖动；滑动结束补发的 CLICKED 用 `lv_indev_get_press_moved()` 拦截 |
| AMOLED 省电 | 背景纯黑 `#000000`；亮度默认 80%，可降到 10% |

字体：

- 时间：`epw_time_150`（Fredoka SemiBold 150，仅数字与冒号）——表盘主视觉，圆润、儿童友好
- 中文：`epw_cjk_16` / `epw_cjk_20`（Noto Sans SC，**GB2312 全集 6763 字 + 界面文案，共 6870 字形**，运行时不再缺字）
- 数字：Montserrat 20 / 24 / 28（磁贴数值、调节页当前值）
- **不使用小于 12 的字号**；中文日期固定 20px

形状：三色外环直径 446、线宽 8；底部电量弧直径 414、线宽 7，扫过 120°（4 点 → 8 点）；控制中心磁贴直径 84；应用图标直径 96；亮度 / 音量轨道 44×280。

圆屏安全区：关键内容放在中心 360px 圆内；文字不放到 x<50 / y<40 的区域。

**没有**每日单词页、没有页码点、没有左右点击翻页、没有刻度环。

### 3.1 表盘

- 三色装饰外环：直径 446、线宽 8，三段各 116°，留 4° 呼吸口；颜色亮黄（右上）→ 橙（底部）→ 天蓝（左上），常驻显示，**不是刻度**
- 天气：太阳 + `24°` + `晴`（`epw_cjk_20` / `epw_cjk_16`，固定演示值），贴在顶部上沿；天气上方一条绿色细弧做分割，让信息跟着圆边走
- 时间：`HH:MM`，`epw_time_150`（Fredoka SemiBold 150px），单行居中，下移到屏幕视觉中心；每 1s 刷新，跨分钟才重绘
- 日期：`M月D日 周X`（`epw_cjk_20`，`#D6E2F0`）；联网后由 SNTP 取真实日期，失败时用内置时钟兜底
- **无刻度**：不画刻度环、不画分钟数字，表盘留黑
- 底部电量弧（常驻，贴近外圈）：
  - 直径 414、线宽 7，扫过 120°（屏幕 4 点 → 8 点），从左侧顺时针按电量增长
  - 弧内侧固定一个 `⚡` 小闪电 + `94%`，合起来就是“电量”语义
  - 主色固定绿色 `#2EE66B`，普通与充电模式都保持绿色
  - 充电模式额外在弧外侧叠一条 14px、20% 透明度的天蓝柔光，拔线后柔光立即消失
- Wi-Fi：右上只画三层信号弧 + 圆点，**不写「已连接/连接中」**；青绿=已连接、琥珀=连接中、珊瑚=断开、灰=关闭
- 交互：只有**下滑**打开控制中心；表盘点按不切页

### 3.2 控制中心（4+3 磁贴）

- 入口：表盘下滑
- 动画：从屏幕上方滑入（-466 → 0，240ms ease-out）；上滑或点「上滑收起」滑出（240ms ease-in）
- 布局：标题 y=48；上排 4 块圆心 x=74/180/286/392、y=158；下排 3 块圆心 x=128/233/338、y=290；直径 84（整体比 V0.11 初版下移 18px，仍在圆屏安全区内）
- 跟手：下拉 / 收起时移动的是**一张开机预渲染的 RGB565 整页快照**，真实磁贴面板只在落定后才接管交互，拖动期间不重绘磁贴
- 每块磁贴 = 圆形深色底 + 1px 描边 + 强调色柔光 + 顶部标签 + 一个**独立手绘图标**；不再有进度弧和端点圆点
- 磁贴与行为：

| 磁贴 | 强调色 | 图标 / 数值 | 点按后 |
|---|---|---|---|
| 状态 | TEAL | 芯片（四边引脚 + 深色内芯 + 在线点） | 打开状态页 |
| 天气 | BLUE | 双色太阳 + 白云 + `24°` | toast `天气 24°` |
| 电量 | GREEN | 白描边电池 + 绿色填充 + 黄色闪电 + `94%` | 打开状态页 |
| 手电 | YELLOW | 手电筒 + 三道灯光 + 玻璃反光 | 纯白满亮度；双击退出 |
| 亮度 | AMBER | 双色太阳 + `80%` | 打开亮度调节页 |
| 音量 | PINK | 喇叭 + 静音斜线 + `0` | 打开音量调节页 |
| Mimi Cat | PINK | Fluent Emoji 3D 猫脸 | 打开宠物页 |

### 3.3 状态页

- 打开：控制中心点「状态」或「电量」磁贴；从屏幕右侧滑入（+466 → 0，240ms ease-in）
- 关闭：**从左往右滑**，或点左上返回圆钮；滑出后回到控制中心
- 副标题：`ESP32-S3 · 1.75" AMOLED · 实时读取`
- 9 行只读信息（运行时读取）：

| 行 | 值 |
|---|---|
| 显示 | `466 x 466` |
| 触摸 | `CST9217` |
| 电池 | `充电中 xx%` / `已充满` / `xx%`（<20% 珊瑚色） |
| 音频 | `静音`（珊瑚色） |
| 网络 | `连接中` / `已连接` / `未连接`（按状态变色） |
| IP | 联网后显示 `192.168.x.x`（青绿），未联网 `--` |
| 芯片 | `ESP32-S3` |
| 闪存 | `esp_flash_get_size()` → `32 MB` |
| 内存 | `esp_psram_get_size()` → `8 MB PSRAM` |

- 本页不再提供亮度调节；亮度统一在控制中心的独立调节页完成

### 3.4 亮度 / 音量调节页

- 入口：控制中心「亮度」/「音量」磁贴；从屏幕右侧滑入（+466 → 0，280ms ease-out）
- 关闭：**从左往右滑**，或点左上返回圆钮
- 视觉：
  - 屏幕水平居中一条 44×280 的竖向圆角粗轨道，整体垂直居中
  - 轨道底色为 30% 透明度的科技浅绿，已选部分用实色 `#5CF39A`
  - 顶部只显示当前值（如 `40%` / `0%`），右侧显示 `100` 与 `0`，**没有标题、没有说明文字、没有圆形拖点**
- 交互：
  - 手指必须按在轨道或填充上才能拖动，避免与「左→右滑关闭」误触
  - 底部为 0%，顶部为 100%；亮度实时应用并下限 10%
  - 音量页只改 UI 数值（音频未初始化，默认 0）

### 3.5 手电页

- 入口：控制中心「手电」磁贴
- 表现：整屏纯白，同时把屏幕亮度拉到 100%
- 退出：**在白屏上双击**（两次 CLICKED 间隔 ≤450ms）；退出后恢复进入前的亮度
- 首次进入会短暂显示「双击退出」提示，2.6s 后自动隐藏

### 3.6 应用桌面（备用入口）

- 入口：`PWR` 短按
- 布局：9 个圆形图标，3×3；中心 104px、外圈 94px、四角 88px，启动时按槽位栅格化一次
- 拖动：整体跟手平移（最大一格 + 16px 过冲），松手回弹到原始九宫格；拖动期间图标尺寸与位图不变，只改位置，避免逐帧重采样造成变形和卡顿
- 点按：宠物 / 儿歌 / 状态 / Wi-Fi / 设置 / 计时器 / 亮度 / 音量 / 手电
- 关闭：`PWR` / `BOOT` 切换页面（桌面不放返回按钮）

### 3.7 宠物页（Mimi Cat · 3D 正脸猫）

- 入口：控制中心「Mimi Cat」磁贴、应用桌面「宠物」图标、`BOOT` 短按
- 视觉：Microsoft Fluent Emoji 3D（MIT）8 张正脸猫图（idle/happy/excited/thinking/speaking/sleepy/sad/love），素材直接生成 **208px** 并在页内 1:1 显示；背后是两层同心圆柔光（随情绪变色，纯色填充，不用 shadow）
- 圆屏安全区布局（466×466 圆形 AMOLED，安全半径约 215）：
  - 顶部只有名字与情绪字：名字「Mimi Cat」在 `y=52` 水平居中，情绪字在 `y=82` 水平居中
  - 猫身 208px 位于 `x=129, y=108`（圆心 212），气泡 300×92 位于 `x=83, y=304`
  - 气泡底边收在 y=396、圆角 26，最宽处仍在圆屏内
- 情绪共 9 种（含「倾听」复用 idle 形象）：

| 情绪 | 默认台词 | 动效 |
|---|---|---|
| 发呆 idle | 喵～ 你好呀！我是 Mimi。 | 缓慢上下浮动 |
| 开心 happy | 见到你真开心！ | 轻快上下跳 |
| 兴奋 excited | 哇！太棒啦！ | 大幅弹跳 + 星点绕头 |
| 思考 thinking | 让我想一想… | 极轻微浮动 |
| 说话 speaking | Hello！跟我读：cat！ | 小幅点头 |
| 困了 sleepy | 我有点困了，晚安～ | 下沉 |
| 难过 sad | 别难过，我陪着你。 | 下沉、低头 |
| 喜欢 love | 我最喜欢你啦！ | 上浮 + 粉色星点 |
| 倾听 listening | 我在听，你说吧。 | 几乎静止的呼吸感 |

- 性能策略（V0.8.1 宠物页卡顿修复）：
  - 动画只做 **y 位移**；不做运行时缩放/旋转（避免每帧软件变换与 layer 合成）
  - 光晕不用 LVGL shadow（SW 模糊每帧重算，是原先卡顿主因），改两层纯色同心圆
  - 动画 tick 80ms（12.5fps）；位置没变就不写，星点每 2 个 tick 更新一次
  - 打开/关闭宠物页**不做全屏淡入淡出**，直接显示/收起
  - 气泡提示改为 8px 的 y 轻跳，不再对整块气泡做缩放合成

- 快捷互动（全部触屏手势，页面不放任何文字按钮）：
  - **互动只在宠物区（208×208 猫身矩形）生效**；页面空白处只响应右滑退出
  - 点按猫：切到「喜欢」+ `摸摸我的头，好开心！`（连点切「开心」+ `嘿嘿，好痒呀！`）
  - 左滑：先「倾听」→ 1.1s 后「思考」→「说话」→「开心」，共 3 段本地剧本（音频未接）
  - 上滑：切到「兴奋」+ `哇！我飞起来啦！`
  - 下滑：切到「困了」+ 晚安台词
  - 长按：切到「思考」+ `让我想一想…`；已用标志位拦截长按后补发的 CLICKED
  - **左→右滑：退出宠物页**（宠物区和空白区都生效）
- 字体：`epw_cjk_16/20` 固定包含 GB2312 全集（6763 字）+ 界面文案，共 6870 字形；`CONFIG_LV_FONT_FMT_TXT_LARGE=y` 支持大字体 bitmap 偏移；豆包动态台词经 `pet_safe_text()` 逐字校验，字体没有的码点（生僻字 / emoji）直接丢弃，杜绝方框
- 本地情景引擎（每 9s 检查，豆包桥接静默 30s 后生效）：
  1. 充电中 → 开心「充电中，能量满满！」
  2. 电量 <20% → 难过「电量有点低，快给我充电吧。」
  3. Wi-Fi 连接中 → 思考「我在找网络，等一下哦…」
  4. 21:00–07:00 → 困了「很晚啦，我们睡觉吧，晚安～」
  5. 其它 → 在 7 句英语教学台词间轮换，情绪按 idle/happy/thinking/listening 循环
- 豆包接入：设备端只轮询 `CONFIG_EPW_PET_BRIDGE_URL`（默认 8s），服务端返回
  `{"emotion":"happy","text":"..."}`；设备不保存任何云 Key
- 关闭：在任意位置从左往右滑（下滑是「困了」，不关闭页面）

## 4. 交互规范

| 手势 / 操作 | 位置 | 结果 | 反馈 |
|---|---|---|---|
| 下滑 | 表盘 | 打开控制中心 | 从上方滑入 300ms |
| 点按表盘其他区域 | 表盘 | 无动作（不切页） | —— |
| 上滑 / 点「上滑收起」 | 控制中心 | 收起控制中心 | 上滑 240ms |
| 点「状态」/「电量」 | 控制中心 | 打开状态页 | 右侧滑入 240ms |
| 点「天气」 | 控制中心 | toast `天气 24°` | 居中胶囊 |
| 点「手电」 | 控制中心 | 纯白满亮度 | 双击白屏退出 |
| 点「亮度」 | 控制中心 | 打开亮度调节页 | 右侧滑入 280ms |
| 点「音量」 | 控制中心 | 打开音量调节页 | 右侧滑入 280ms |
| 点「Mimi Cat」 | 控制中心 | 打开宠物页 | 直接显示 |
| 左 → 右滑 | 状态页 | 关闭，回到控制中心 | 右侧滑出 240ms |
| 点返回圆钮 | 状态页左上 | 关闭，回到控制中心 | 右侧滑出 240ms |
| 在轨道上上下拖 | 亮度 / 音量页 | 调值 | 填充高度 + 当前值实时更新 |
| 左 → 右滑 | 亮度 / 音量页 | 关闭，回到控制中心 | 右侧滑出 |
| 双击白屏 | 手电页 | 退出，恢复原亮度 | —— |
| 短按 BOOT | 物理键 GPIO0 | 切换宠物页 | 直接显示 / 收起 |
| 短按 PWR | 物理键 AXP2101 | 切换应用桌面（备用入口） | 下方滑入 220ms |
| 点按宠物区 | 宠物页 | 切到「喜欢」（连点切「开心」） | 表情 + 光晕 + 气泡弹跳 |
| 左滑宠物区 | 宠物页 | 倾听 → 思考 → 说话 → 开心 | 三段 1.1s 剧本 |
| 上滑 / 下滑 / 长按宠物区 | 宠物页 | 兴奋 / 困了 / 思考 | 表情 + 台词 |
| 左→右滑（任意位置） | 宠物页 | 关闭宠物页 | 直接收起，不触发宠物互动 |
| 上下滑 | 无覆盖页 | 无翻页 | —— |

规则：

- 一屏只做一件事；表盘不响应点击换屏。
- 所有状态变化必须在 200ms 内有可见反馈。
- 亮度限制 10–100，不允许黑屏。
- 调节页只有按在轨道上才响应，避免与右滑关闭互相误触。
- 音频未接：音量 UI 可调，但实际始终无声，不出现「正在听/正在说」的假状态。
- 页面互斥：宠物页 / 应用桌面 / 控制中心 / 状态页 / 调节页 / 手电同一时刻只显示一层。
- 控制中心/状态页/调节页/宠物页/应用桌面打开时，下层不响应点击（全屏覆盖并消费事件）。
- 每个打开函数入口都会先 `close_now` 同层兄弟页；页面滑入/滑出动画期间（`page_anim_lock`）屏蔽点击与抽屉手势，防止连点两下同时拉起两个页面。
- 下拉/收起控制中心时若已有任一覆盖页打开，手势直接丢弃，不把位移叠加到下层页面。

实现注意（LVGL 9）：

- 页面与覆盖层必须显式 `lv_obj_remove_flag(..., LV_OBJ_FLAG_GESTURE_BUBBLE)`，否则手势冒泡到 screen，收不到 `LV_EVENT_GESTURE`，滑动退化成点击。
- 滑动结束 LVGL 仍会补发 `LV_EVENT_CLICKED`，点击处理先判 `lv_indev_get_press_moved()`。
- `lv_arc` 整圆底轨必须写 `0 → 360`；LVGL 9 只做一次 >360 归一。
- 覆盖层关闭动画完成回调里再 `LV_OBJ_FLAG_HIDDEN`，避免动画期间可见。
- 三色环与电量弧使用 `rotation=270`，0° 在 12 点、角度顺时针增长；改环段顺序时先换算起止角。

## 5. 状态与边界

| 状态 | 表现 |
|---|---|
| 网络 未连接 / 连接中 / 已连接 | 表盘 Wi-Fi 图标变珊瑚 / 琥珀 / 青绿；状态页每 2s 刷新文字 |
| 热点不存在（reason 201） | 串口提示检查 2.4GHz/最大兼容性；固件持续重试并扫描打印可见 AP |
| 拔掉 USB | 电量弧保持绿色，天蓝柔光隐藏；三色外环常驻 |
| 插上 USB | 电量弧仍为绿色，叠一圈天蓝柔光；状态页显示「充电中 xx%」 |
| 电量未知 | 显示 `--`；充电时显示 `充电中` |
| 电量 <20% | 状态页电量文字变珊瑚色；表盘电量弧仍为绿色 |
| SNTP 未同步 | 使用内置时钟（10:09 起走），日期按内置时间推进 |
| 控制中心已打开 | 再次下滑被忽略（`s_center_open` 防重入） |
| 状态页 / 调节页关闭中 | 右滑期间重复触发被状态保护 |
| 应用图标拖动中 | 不触发打开；松手后吸附最近槽位，占用则交换 |
| 豆包桥接无响应 | 30s 后回落到本地情景引擎，不会卡在「思考」 |
| 亮度最低 | 10%，仍可看清时间和返回操作 |
