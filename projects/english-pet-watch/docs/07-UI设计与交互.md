# 07 · UI 设计与交互（V0.9 真机版）

> 适用版本：UI Demo V0.9（`firmware/ui_demo/`）　|　最后更新：2026-11-16
> 目标板：Waveshare ESP32-S3-Touch-AMOLED-1.75C，466×466 圆屏，CST9217 单点触摸
> 约束：办公室演示环境，**不接音频，音量固定 0**；本次只验证 UI、交互与真机观感。

## 1. 设计目标

| 目标 | 做法 |
|---|---|
| 像一块正常的智能手表表盘 | 单个表盘页：大号数字时间（主视觉）+ 中文日期 + 天气 + 电量 + Wi-Fi；**不出现电子宠物** |
| 给小朋友看的纯数字表盘 | **完全去掉刻度环、分钟数字和装饰刻度**；只保留圆润大数字，一眼读懂 |
| 字体像产品，而不是默认字体 | 时间用 Fredoka SemiBold 150px（圆润略胖、数字辨识度高），中文用 Noto Sans SC 20px；不用小于 16px 的中文 |
| 交互像 Apple Watch / 华为手表 | 表盘下滑 → 控制中心；控制中心上滑 → 表盘；状态页从左往右滑 → 关闭回控制中心 |
| 参考华为表盘磁贴 | 控制中心 2×3 圆形磁贴：圆底 + 彩色弧 + 端点圆点 + 图标/数值；六块磁贴六种颜色 |
| 一眼区分充电 / 普通 | 外圈常驻三色儿童科技环；底部电量弧普通模式按电量变色，插 USB 后变青柠色并带柔光 |
| 去掉点击换屏 | 表盘不响应点按；点击只作用于明确的磁贴 / 按钮 |
| 不误触 | 滑动结束补发的 CLICKED 一律用 `lv_indev_get_press_moved()` 拦截 |
| AMOLED 省电 | 背景纯黑 `#000000`；亮度默认 80%，可降到 10% |

| PURPLE | `#B39BFF` | 亮度磁贴 / 触摸 / 芯片 |
| PINK | `#FF8FB1` | 音量磁贴 / 内存 |
| CORAL | `#FF6B7A` | 低电量 / 静音 |

字体：

- 时间：`epw_time_150`（Fredoka SemiBold 150，仅数字与冒号）——表盘主视觉，圆润、儿童友好
- 中文：`epw_cjk_16` / `epw_cjk_20`（Noto Sans SC，**GB2312 全集 6763 字 + 界面文案，共 6870 字形**，运行时不再缺字）
- 数字：Montserrat 20 / 24 / 28（磁贴数值、亮度按钮）
- **不使用小于 12 的字号**；中文日期固定 20px

形状：表盘三色外环直径 446、线宽 5；底部电量弧直径 414、线宽 7，扫过 120°（4 点到 8 点）；控制中心磁贴直径 118、弧宽 4；应用图标直径 96。

圆屏安全区：关键内容放在中心 360px 圆内；文字不放到 x<50 / y<40 的区域。

├── 状态页 s_status（从右侧滑入的全屏覆盖层）
│   ├── 返回圆钮 + 标题「状态」+「ESP32-S3 · 1.75" AMOLED · 实时读取」
│   ├── 9 行硬件/网络信息（含 IP）
│   └── 亮度条 + 「-」「+」圆钮
├── 应用桌面 s_apps（备用入口，仅 PWR 短按打开）
│   ├── 标题「Pip 的桌面」+ 副标题「点按打开 · 拖动换位」
│   ├── 6 个圆形图标（2×3）：宠物 / 控制中心 / 状态 / 天气 / 亮度 / 音量
│   └── 底部「返回表盘」胶囊
└── 宠物页 s_pet（Pip · 3D 正脸猫）

    ├── 3D 猫表情 + 呼吸光晕
    ├── 对话气泡
    └── 触屏手势：点按 / 左右滑 / 上下滑 / 长按（无文字按钮）

**没有**每日单词页、没有页码点、没有左右点击翻页、没有刻度环。

### 3.1 表盘

- 三色装饰外环：直径 446、线宽 5，三段各 116°，留 4° 呼吸口；颜色青柠 → 蓝 → 紫，常驻显示，给小朋友的“科技感”，**不是刻度**
- 天气：太阳 + `24°` + `晴`（`epw_cjk_20` / `epw_cjk_16`，固定演示值），贴在顶部上沿；背后一条 44° 琥珀色细弧，让天气信息跟着圆边走，而不是浮在一条横线上
- 时间：`HH:MM`，`epw_time_150`（Fredoka SemiBold 150px），单行居中，字号比 V0.8 放大约 50%，整体下移到屏幕视觉中心；每 1s 刷新，跨分钟才重绘
- 日期：`M月D日 周X`（`epw_cjk_20`，`#D6E2F0`）；联网后由 SNTP 取真实日期，失败时用内置时钟兜底
- **无刻度**：不画刻度环、不画分钟数字，表盘留黑
- 底部电量弧（常驻，贴近外圈）：
  - 直径 414、线宽 7，扫过 120°（屏幕 4 点 → 8 点），从左侧顺时针按电量增长
  - 弧内侧固定一个 `⚡` 小闪电 + `94%`，合起来就是“电量”语义，不再用胶囊和文字解释
  - 普通模式：>50% 青绿、20–50% 琥珀、<20% 珊瑚
  - 充电模式：整段变青柠色，并在弧外侧叠一条 14px、20% 透明度的柔光，拔线后柔光立即消失
- Wi-Fi：右上只画三层信号弧 + 圆点，**不写「已连接/连接中」**；青绿=已连接、琥珀=连接中、珊瑚=断开、灰=关闭
- 交互：只有**下滑**打开控制中心；表盘点按不切页

### 3.2 控制中心（参考华为表盘磁贴）

- 入口：表盘下滑
- 动画：从屏幕上方滑入（-466 → 0，300ms ease-out）；上滑或点「上滑收起」滑出（240ms ease-in）
- 布局：标题 y=48；磁贴圆心 x=101/233/365，y=168/310；直径 118
- 每个磁贴 = 圆形深色底 + 1px 描边 + 4px 底轨弧 + 彩色弧 + 端点圆点 + 顶部标签
- 磁贴与行为：

| 磁贴 | 颜色 | 图形 / 数值 | 点按后 |
|---|---|---|---|
| 状态 | TEAL | `i` 图标 + 270° 弧 | 打开状态页 |
| 天气 | BLUE | 太阳 + `24°` | toast `天气 24°` |
| 电量 | LIME | 进度弧 + `94%`（充电时加闪电） | 打开状态页 |
| 亮度 | PURPLE | 太阳 + `80%` + 进度弧 | 亮度 +10%（循环） |
| 音量 | PINK | 静音喇叭 + `0` | toast `音量固定为 0` |
| AI | AMBER | Fluent Emoji 3D 猫脸 | 打开宠物页 |

- 六块磁贴使用六种不同强调色，不再全绿；弧只做视觉引导与进度表达。

### 3.3 状态页

- 打开：控制中心点「状态」或「电量」磁贴；从屏幕右侧滑入（+466 → 0，240ms ease-in）
- 关闭：**从左往右滑**，或点左上返回圆钮；滑出后回到控制中心
- 副标题：`ESP32-S3 · 1.75" AMOLED · 实时读取`
- 9 行信息（运行时读取）：

| 行 | 值 |
|---|---|
| 显示 | `466 x 466` |
| 触摸 | `CST9217` |
| 电池 | `充电中 xx%` / `已充满` / `xx%`（<20% 珊瑚色） |
| 音频 | `静音`（珊瑚色） |
| 网络 | `连接中` / `已连接` / `未连接`（按状态变色） |
| IP | 联网后显示 `192.168.x.x`（青绿），未联网 `--` |
| 芯片 | `ESP32-S3` |
| 闪存 | `esp_flash_get_size()` → `32 MB` |
| 内存 | `esp_psram_get_size()` → `8 MB PSRAM` |

- 亮度：10–100%，步进 10；`-` / `+` 圆钮；状态页与磁贴同步

### 3.4 应用桌面（备用入口）

- 入口：`PWR` 短按（表盘已不再用底部按钮或点按进入桌面）
- 布局：6 个圆形图标，2 行 × 3 列，圆心 x=101/233/365，y=190/320；图标直径 96
- 拖动：按下移动超过 8px 进入拖动，松手吸附最近槽位，占用则交换；槽位写 NVS，重启保持
- 点按：宠物 / 控制中心 / 状态 / 天气 toast / 亮度 +10% / 音量 toast
- 关闭：点「返回表盘」或上滑

### 3.5 宠物页（Pip · 3D 正脸猫）

- 入口：控制中心 AI 磁贴、应用桌面「宠物」图标、`BOOT` 短按
- 视觉：Microsoft Fluent Emoji 3D（MIT）8 张正脸猫图（idle/happy/excited/thinking/speaking/sleepy/sad/love），素材直接生成 **208px** 并在页内 1:1 显示；背后是两层同心圆柔光（随情绪变色，纯色填充，不用 shadow）
- 情绪共 9 种（含「倾听」复用 idle 形象）：

| 情绪 | 默认台词 | 动效 |
|---|---|---|
| 发呆 idle | 喵～ 你好呀！我是 Pip。 | 缓慢上下浮动 |
| 开心 happy | 见到你真开心！ | 轻快上下跳 |
| 兴奋 excited | 哇！太棒啦！ | 大幅弹跳 + 星点绕头 |
| 思考 thinking | 让我想一想… | 极轻微浮动 |
| 说话 speaking | Hello！跟我读：cat！ | 小幅点头 |
| 困了 sleepy | 我有点困了，晚安～ | 下沉 |
| 难过 sad | 别难过，我陪着你。 | 下沉、低头 |
| 喜欢 love | 我最喜欢你啦！ | 上浮 + 粉色星点 |
| 倾听 listening | 我在听，你说吧。 | 几乎静止的呼吸感 |

- 性能策略（V0.8.1 宠物页卡顿修复）：
  - 动画只做 **y 位移**；不做运行时缩放/旋转（避免每帧软件变换与 layer 合成）
  - 光晕不用 LVGL shadow（SW 模糊每帧重算，是原先卡顿主因），改两层纯色同心圆
  - 动画 tick 80ms（12.5fps）；位置没变就不写，星点每 2 个 tick 更新一次
  - 打开/关闭宠物页**不做全屏淡入淡出**，直接显示/收起（全屏 466×466 淡入会连续重绘整屏）
  - 气泡提示改为 8px 的 y 轻跳，不再对整块气泡做缩放合成

- 快捷互动（全部触屏手势，页面不放任何文字按钮）：
  - 点按猫 / 页面：切到「喜欢」+ `摸摸我的头，好开心！`（连点切「开心」+ `嘿嘿，好痒呀！`）
  - 左右滑：先「倾听」→ 1.1s 后「思考」→「说话」→「开心」，共 3 段本地剧本（音频未接）
  - 上滑：切到「兴奋」+ `哇！我飞起来啦！`
  - 下滑：切到「困了」+ 晚安台词
  - 长按：切到「思考」+ `让我想一想…`；已用标志位拦截长按后补发的 CLICKED
- 字体：`epw_cjk_16/20` 固定包含 GB2312 全集（6763 字）+ 界面文案，共 6870 字形；`CONFIG_LV_FONT_FMT_TXT_LARGE=y` 支持大字体 bitmap 偏移；豆包动态台词经 `pet_safe_text()` 逐字校验，字体没有的码点（生僻字 / emoji）直接丢弃，杜绝方框
- 本地情景引擎（每 9s 检查，豆包桥接静默 30s 后生效）：
  1. 充电中 → 开心「充电中，能量满满！」
  2. 电量 <20% → 难过「电量有点低，快给我充电吧。」
  3. Wi-Fi 连接中 → 思考「我在找网络，等一下哦…」
  4. 21:00–07:00 → 困了「很晚啦，我们睡觉吧，晚安～」
  5. 其它 → 在 7 句英语教学台词间轮换，情绪按 idle/happy/thinking/listening 循环
- 豆包接入：设备端只轮询 `CONFIG_EPW_PET_BRIDGE_URL`（默认 8s），服务端返回
  `{"emotion":"happy","text":"..."}`；设备不保存任何云 Key
- 关闭：点左上返回圆钮（下滑是「困了」，不关闭页面）

## 4. 交互规范

| 手势 / 操作 | 位置 | 结果 | 反馈 |
|---|---|---|---|
| 下滑 | 表盘 | 打开控制中心 | 从上方滑入 300ms |
| 点按表盘其他区域 | 表盘 | 无动作（不切页） | —— |
| 上滑 / 点「上滑收起」 | 控制中心 | 收起控制中心 | 上滑 240ms |
| 点「状态」/「电量」 | 控制中心 | 打开状态页 | 右侧滑入 240ms |
| 点「天气」 | 控制中心 | toast `天气 24°` | 居中胶囊 |
| 点「亮度」 | 控制中心 | 亮度 +10% | 弧 + 数值 + toast |
| 点「音量」 | 控制中心 | toast `音量固定为 0` | 居中胶囊 |
| 点「AI」 | 控制中心 | 打开宠物页 | 淡入 180ms |
| 左 → 右滑 | 状态页 | 关闭，回到控制中心 | 右侧滑出 240ms |
| 点返回圆钮 | 状态页左上 | 关闭，回到控制中心 | 右侧滑出 240ms |
| 短按 BOOT | 物理键 GPIO0 | 切换宠物页 | 淡入 / 淡出 160–180ms |
| 短按 PWR | 物理键 AXP2101 | 切换应用桌面（备用入口） | 下方滑入 220ms |
| 点按猫 / 页面 | 宠物页 | 切到「喜欢」（连点切「开心」） | 表情 + 光晕 + 气泡弹跳 |
| 左右滑 | 宠物页 | 倾听 → 思考 → 说话 → 开心 | 三段 1.1s 剧本 |
| 上滑 / 下滑 / 长按 | 宠物页 | 兴奋 / 困了 / 思考 | 表情 + 台词 |
| 点返回圆钮 | 宠物页左上 | 关闭宠物页 | 淡出 160ms |
| 上下滑 | 无覆盖页 | 无翻页 | —— |

规则：

- 一屏只做一件事；表盘不响应点击换屏。
- 所有状态变化必须在 200ms 内有可见反馈。
- 亮度限制 10–100，不允许黑屏。
- 音频相关入口一律显示 `静音 / 固定 0`，不出现「正在听/正在说」的假状态。
- 页面互斥：宠物页 / 应用桌面 / 控制中心 / 状态页同一时刻只显示一层，新页面打开前先立即收起其它层。
- 控制中心/状态页/宠物页/应用桌面打开时，下层不响应点击（全屏覆盖并消费事件）。

实现注意（LVGL 9）：

- 页面与覆盖层必须显式 `lv_obj_remove_flag(..., LV_OBJ_FLAG_GESTURE_BUBBLE)`，否则手势冒泡到 screen，收不到 `LV_EVENT_GESTURE`，滑动退化成点击。
- 滑动结束 LVGL 仍会补发 `LV_EVENT_CLICKED`，点击处理先判 `lv_indev_get_press_moved()`。
- `lv_arc` 整圆底轨必须写 `0 → 360`；LVGL 9 只做一次 >360 归一。
- 覆盖层关闭动画完成回调里再 `LV_OBJ_FLAG_HIDDEN`，避免动画期间可见。
- 磁贴圆点位置用 `dot_place()` 按角度计算，不要手写坐标。

## 5. 状态与边界

| 状态 | 表现 |
|---|---|
| 网络 未连接 / 连接中 / 已连接 | 表盘 Wi-Fi 图标变珊瑚 / 琥珀 / 青绿；状态页每 2s 刷新文字 |
| 热点不存在（reason 201） | 串口提示检查 2.4GHz/最大兼容性；固件持续重试并扫描打印可见 AP |
| 拔掉 USB | 电量弧恢复按电量配色（青绿/琥珀/珊瑚），柔光隐藏；三色外环保持常驻 |
| 插上 USB | 电量弧整段变青柠色并出现柔光；闪电与百分比同步变青柠 |
| 电量未知 | 显示 `--`；充电时显示 `充电中` |
| 电量 <20% | 电量数字/电量条变珊瑚色 |
| SNTP 未同步 | 使用内置时钟（10:09 起走），日期按内置时间推进 |
| 控制中心已打开 | 再次下滑被忽略（`s_center_open` 防重入） |
| 状态页关闭中 | 右滑期间重复触发被状态保护 |
| 应用图标拖动中 | 不触发打开；松手后吸附最近槽位，占用则交换 |
| 豆包桥接无响应 | 30s 后回落到本地情景引擎，不会卡在「思考」 |
| 亮度最低 | 10%，仍可看清时间和返回操作 |

## 7. 已知取舍与后续

| 项 | 现在 | 后续 |
|---|---|---|
| 音频 | 完全关闭，音量 0 | 接 ES8311/ES7210 后再加「聆听/说话」动效 |
| 时间 | SNTP（联网时）+ 内置时钟兜底 | 接 PCF85063 RTC，离线也保持准确 |
| 天气 | 固定 24° 演示值 | 联网天气 API |
| 对话形象 | 独立宠物页：8 张 Fluent Emoji 3D 正脸猫 + 9 种情绪 | 接 TTS 后让「说话」状态与真实语音同步 |
| 豆包接入 | 设备轮询轻量 JSON（服务端持 Key），内置 9 种情绪映射 | 正式链路改用 xiaozhi-server WebSocket（ASR → 豆包 LLM → TTS） |
| 应用桌面 | 6 个图标固定，可拖动换位；V0.8 起仅 PWR 进入 | 后续可加更多应用、分页与文件夹 |
| 表盘 | 纯数字、无刻度；三色环常驻 + 底部电量弧 | 可做 2–3 个表盘主题切换 |
| 字体 | Fredoka SemiBold 150 + Noto Sans SC GB2312 全集（6870 字形） | 换文案无需再生成字体子集 |
| 触摸 | 单点，无多指 | 保持单点，符合儿童使用与硬件能力 |
| 圆屏适配 | 手写坐标 | 抽取 `safe_area` 常量，方便换其它圆屏 |
