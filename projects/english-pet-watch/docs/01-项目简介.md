# 01 · 项目简介

> 适用版本：方案 v1.0（未实物验证）　|　最后更新：2026-11-13　|　前置条件：无

## 这是什么

英语宠物怀表是一块 **ESP32-S3 + 1.75 英寸 AMOLED 触摸圆屏**的随身语音设备：触摸或唤醒后，它用英语和孩子聊天、教单词、陪读句型，并记住每天学过的内容。硬件只保留「屏幕 + 麦克风 + 扬声器 + 电池」，软件只保留「语音接大模型」这条主链路，外形做成可以挂在书包或口袋里的怀表。

设计目标是**一块开发板就能跑通**：不做双屏、不做自训练唤醒词、不依赖境外网络，家长不需要训练模型，也不需要画 PCB。

## 系统怎么跑（一张图）

```text
孩子说话
   │ 麦克风
   ▼
┌──────────── 怀表：ESP32-S3 ────────────┐
│ 唤醒词 / 触摸 → 录音 → Opus → Wi-Fi    │
│ 放音、屏幕表情、音量、打断             │
└───────────────┬───────────────────────┘
                │ WebSocket（家里局域网）
                ▼
┌──────────── 服务端：电脑 / NAS ─────────┐
│ VAD → ASR（FunASR）→ 记忆 / 意图 → TTS │
│ 还负责设备接入、OTA、配置下发           │
└───────────────┬───────────────────────┘
                │ HTTPS
                ▼
        豆包 LLM（火山方舟 API）
```

| 角色 | 必须吗 | 负责什么 | 可以换成 |
|---|---|---|---|
| 怀表 ESP32-S3 | 必须 | 唤醒、录音、放音、屏幕、Wi-Fi | — |
| 服务端 | **本方案必须** | VAD、ASR、TTS、记忆、意图、Prompt 组装、设备接入与 OTA | 旧笔记本、NAS、迷你主机、云服务器 |
| 豆包 LLM | 必须 | 理解与生成对话 | 其他国内模型；或本地 Ollama |

> 服务端不是「只做 VAD/ASR/TTS」，它还是整条链路的**编排中心**；只是 LLM 放在云端豆包。若完全不想维护服务端，只能改用「云端实时语音 + 改固件」的另一条路线，不属于本项目的 MVP。

### 服务端要什么配置

- **最低**：2 核 CPU / 4GB 内存 / 10GB 空闲磁盘，x86 小主机或 Mac 都行；
- **推荐**：4 核 / 8GB，FunASR 识别更快，首响更稳；
- ARM NAS 能跑但 SenseVoice 推理偏慢（`待实测`）；树莓派不建议作为首选；
- 同一局域网最省事：设备直接连 `ws://<电脑局域网IP>:8000`，不需要公网和 HTTPS；
- 电脑要**常开**；不想常开就放到云服务器（需要公网 IP + HTTPS/WSS）。

## 能做什么

| 能力 | 说明 | 阶段 |
|---|---|---|
| 看时间 | 息屏/亮屏怀表表盘，显示时间、日期、电量、天气（可选） | MVP |
| 语音对话 | 触摸/按键开始，流式 ASR → LLM → TTS，可打断、可静音 | MVP |
| 英语陪练 | 自由聊天、单词卡、句型跟读、情景角色扮演（点餐/上学/动物） | MVP |
| 发音反馈 | 跟读后给「很棒 / 不错 / 再试一次」三档反馈（可选接入评测 API） | V2 |
| 单词本 | 记录今天新词、错词，第二天主动复习 | V1 |
| 宠物表情 | 用 LVGL 画一只会眨眼、会困、会开心的小宠物 | V1 |
| 家长控制 | 单次时长上限、每日总时长、音量上限、内容过滤、API Key 管理 | V1 |
| OTA 升级 | Wi-Fi 下检查新固件并升级 | V2 |

**明确不做**：

- 不做离线大模型（ESP32-S3 跑不动可用的 LLM；本地只跑唤醒词）。
- 不做儿童安全监护/定位设备（没有 4G、没有 GPS；如需定位另加模块）。
- 不做开放域上网搜索（默认关闭，避免不可控内容）。
- 不做摄像头（本板无摄像头；需要拍照识物请另选带摄像头的板卡）。

## 教学价值与目标人群

**适合谁**

- 6–10 岁、已经能说少量英语单词/句型的小学生；
- 想让孩子理解「AI 语音助手到底怎么工作」的家长；
- 有一点命令行基础、愿意陪孩子做 4–6 个周末的家长（不会焊接也可以）。

**教学目标**

1. 能画出并讲清「声音 → 文字 → 大模型 → 声音」的完整链路。
2. 能独立完成烧录、配网、对话测试和一次故障排查。
3. 能设计一段 3 分钟的英语对话脚本，并解释为什么要这样问。
4. 能说出在线语音助手的三个边界：没网不能用、会花钱、隐私要注意。

**前置知识**

- 孩子：认识英文字母、能跟读 3–5 个单词的短句；会使用触摸屏。
- 家长：会解压文件、复制命令、看日志；不需要会写 C++ 或 Python。

## 投入与风险提示

| 项 | 量级 | 备注 |
|---|---|---|
| 硬件成本 | ￥300–450 | 开发板占大头；外壳可先用纸板/现成盒 |
| 家长工时 | 8–12 小时 | 不含采购等待；含烧录、服务端、装壳、调 Prompt |
| 云端成本 | ￥20–80/月 | 与模型、每天时长强相关；先设上限 |
| 主要风险 | 网络与供应商依赖 | 断网/欠费/接口变更都会让「老师」罢工 |
| 隐私风险 | 语音会上传到云端 | 只在唤醒后上传；不存孩子姓名/学校；关闭供应商数据留存 |
| 内容风险 | 大模型可能跑题 | 系统 Prompt + 内容过滤 + 家长抽查，不能完全交给模型 |
| 硬件风险 | 锂电池、音量、屏幕 | 家长负责充电与音量；单次使用 ≤15 分钟 |
| 许可 | 自研固件（本项目）与服务端 xiaozhi-esp32-server（MIT） | 保留服务端版权声明即可 |
