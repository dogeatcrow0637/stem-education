# 05 · 教学与课程

> 适用版本：方案 v1.0　|　最后更新：2026-11-13　|　适用学段：小学 1–4 年级（6–10 岁，按 L1/L2/L3 分档）
> 课时安排：6 课时 × 45 分钟；建议每周 1 课，另加 2 个周末做装壳与续航
> 配套产出：[`儿童课程/`](儿童课程/README.md)（一课一个目录：课件 + 配图 + 知识卡）、[`家长实现/`](家长实现/00-总纲与路线图.md)

## 一、课程目标

学完能：

1. 指着设备说出屏幕、麦克风、喇叭、电池、主控分别在哪里、干什么。
2. 独立完成一次「烧录 → 配网 → 对话」的完整流程，并能处理至少 2 种常见故障。
3. 画出「声音 → 文字 → 大模型 → 声音」链路图，并解释每一段由谁完成。
4. 设计并演示一段 3 分钟的英语陪练对话，说明为什么这样问、怎样纠错。
5. 说出在线语音助手的边界：没网不能用、会花钱、语音会上云、不能替代真人老师。

## 三、实验任务

| # | 任务 | 难度 | 验收标准 |
|---|---|---|---|
| 1 | 部件寻宝：找到 5 个部件并贴标签 | 入门 | 5 个全对，能说出 1 句作用 |
| 2 | 烧录一个表盘 demo | 入门 | 屏幕显示时间，重启后仍正常 |
| 3 | 录 3 秒语音并看到波形 | 入门 | 波形随声音变化，能回放 |
| 4 | 测 5 次「说完到出声」的时间 | 进阶 | 记录表完整，能算出平均值 |
| 5 | 断网实验：拔掉网线/关 Wi-Fi | 进阶 | 能说出哪一步失败、为什么 |
| 6 | 写 5 句英语对话并让设备说出来 | 进阶 | 3 轮不跑题，纠错用语友好 |
| 7 | 合壳后连续对话 30 分钟 | 挑战 | 不重启、不发烫、电量记录完整 |
| 8 | 3 分钟作品展示 | 挑战 | 按「是什么/怎么做/最难/还想改」讲完 |

## 四、考核点

| 维度 | 权重 | 说明 |
|---|---|---|
| 动手装配 | 30% | 能安全完成插线、装壳、充电；工具归位 |
| 调试与排障 | 25% | 能按「先查电源→再查连接→再看日志」顺序排查 |
| 对话设计/编程 | 25% | 能写短句脚本、改 Prompt、解释改动效果 |
| 报告与表达 | 20% | 能画链路图，讲清一个技术点 |

> 不建议用分数排名。用「通关 + 称号」：接线员 → 调试员 → 对话设计师 → 怀表工程师。

## 五、常见提问（FAQ）

| 学生问题 | 回答要点 |
|---|---|
| 它自己会思考吗？ | 不会。它把你的话变成文字发给云端大模型，再把回答变成声音。断网就「变笨」。 |
| 为什么它有时候听不懂？ | 麦克风离得远、环境吵、或者 ASR 把词听错了；靠近、慢一点、说短句。 |
| 它会记住我吗？ | 只会记住你允许它记的单词和偏好；不会记住你的声音去认人。 |
| 为什么不能一直聊？ | 云端按时间收费，眼睛和耳朵也要休息；每次 10–15 分钟。 |
| 它说的英语一定对吗？ | 大模型可能犯错；它是陪练，不是老师。拿不准就问家长或查词典。 |
| 为什么装壳后信号变差？ | 电池和金属挡住了天线；天线附近要留塑料窗口。 |
| 电池为什么会鼓？ | 过充、劣质电池、挤压；鼓包立即停用。 |
| 我能改它的性格吗？ | 能。改 Prompt 里的「规则」，但每次只改一条，再对比效果。 |

## 六、安全须知（必讲）

1. ⚠️ **锂电池**：只由家长充电；不用快充头；不穿刺、不挤压、不放在高温处；鼓包/异味立即停用并移到室外。
2. ⚠️ **音量**：耳机/贴耳测试由家长做；设备音量上限 70%；孩子连续使用 ≤15 分钟。
3. ⚠️ **USB/充电**：插拔前先停止对话；不要边充电边放在床上/枕边。
4. ⚠️ **小零件**：螺丝、喇叭、电池插头远离 3 岁以下幼儿。
5. ⚠️ **隐私**：只在设备亮屏/唤醒后说话；不把全名、学校、家庭住址告诉它；家长定期抽查对话记录。
6. ⚠️ **内容边界**：不聊暴力、恐怖、成人话题；发现跑题立即说「Stop」并告诉家长。
