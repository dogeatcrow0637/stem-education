## 2. 失败排查表（按顺序查，不要跳）

| 现象 | 最可能原因（按概率排序） | 先查什么 |
|---|---|---|
| 上电无任何反应 | 电池没电 / 开关 OFF / 插头反接 / USB 线只供电 | 换 USB 供电 → 量电池电压 → 查极性 |
| 屏幕亮但白屏/花屏 | 板级配置选错（1.75 vs 1.75C）/ 排线松 | 选对 Board Type → 重插排线 |
| 触摸没反应/偏移 | 触摸复位/中断引脚配错 / 排线 | 对照 `config.h` 的触摸引脚 → 重烧 |
| 喇叭无声 | PA 使能未拉高 / 音量 0 / 喇叭坏 | 跑 `06_I2SCodec` → 查 GPIO46 → 换喇叭 |
| 喇叭破音 | 音量过大 / 喇叭阻抗不匹配 / 腔体共振 | 音量降到 70% → 查 8Ω → 加泡棉 |
| 麦克风没输入 | 麦克风孔堵 / ES7210 未初始化 / 增益 0 | 清孔 → 跑音频 demo → 调增益 |
| 设备连不上 Wi-Fi | 只支持 2.4G / 密码错 / 信号弱 | 开 2.4G → 近路由器 → 查天线净空 |
| 连上 Wi-Fi 但连不上服务端 | IP/端口错 / 防火墙 / 不同网段 | `ping` 设备 → `curl` OTA 地址 → 关防火墙 |
| ASR 识别错/没文本 | 环境吵 / 麦克风远 / 语种配置错 | 靠近说 → 看服务端日志 → 改 ASR 语言 |
| TTS 没声音/断流 | 供应商余额 / 网络 / 文本过长 | 查余额 → 缩短回复 → 换 TTS |
| 对话两分钟就断 | Wi-Fi 不稳 / 服务端超时 / 过热 | 看日志 → 降亮度 → 加散热孔 |
| 装壳后 Wi-Fi 变差 | 电池/金属挡天线 | 开天线窗 → 移电池 → 换外壳材料 |
| 充电发烫/鼓包 | 劣质电池 / 快充头 / 挤压 | **立即停用** → 移室外 → 换正规电池 |

## 3. 作品展示脚本（让孩子讲 3 分钟）

1. **它是什么**（30 秒）：「这是我做的英语宠物怀表，它能听我说英语、回我英语，还会记住今天学的单词。」
2. **怎么做的**（60 秒）：按「先装屏幕和声音 → 再烧固件联网 → 最后接上英语老师」说三个最关键步骤。
3. **最难的地方**（45 秒）：「最难的是让它连上服务端，我试了 __ 次，最后发现是 __。」
4. **我还想改**（45 秒）：「下一步我想让它 __（换音色 / 加单词游戏 / 做更薄的壳）。」

家长只做两件事：计时、听完后问一个问题（「如果明天断网，它会怎样？」）。

## 5. 验收后的三件事

1. 把实测续航、延迟、成本回填到 `docs/01-项目简介.md`，把 `待验证` 改成实测值。
2. 把踩过的坑补进项目 `README.md` 的「已知问题」。
3. 和孩子一起决定下一个改动（只选一个），写进 `CHANGELOG.md` 的「未发布」。
