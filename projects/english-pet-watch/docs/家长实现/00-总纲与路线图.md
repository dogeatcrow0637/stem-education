# 家长实现总纲（英语宠物怀表）

| 字段 | 值 |
|---|---|
| 项目编号 | 06 |
| 项目目录 | `projects/english-pet-watch` |
| 适用版本 | 硬件：Waveshare ESP32-S3-Touch-AMOLED-1.75（方案 v1.0）／软件：自研固件 V0.1 + xiaozhi-esp32-server（以仓库当日 main 为准） |
| 最后更新 | 2026-11-13 |
| 前置条件 | 一台能装 ESP-IDF 的电脑（macOS/Windows/Linux）、一个 2.4GHz Wi-Fi、能陪孩子每次 45 分钟的家长；不需要会焊接、不需要会写代码 |

> 本手册面向**完全零基础的家长**，用于带一名小学生从零把本项目做出来并讲明白。工程细节以 `projects/english-pet-watch/docs/` 为准，本手册只讲「怎么带着孩子做」。

## 一句话目标

做完之后，孩子能独立完成的最小成果是：**合上怀表壳，按一下屏幕，用英语说 "Hello"，设备 3 秒内用英语回应**；能看到的现象是：屏幕上的小宠物从「睡觉」变成「抬头听」，说完后张嘴说话，屏幕上出现今天学的单词。

## 这套手册怎么用

1. **先读安全红线**（本文件最后一节），再读 `05-安全与工具采购清单.md`。
2. 按 `02-里程碑与任务卡.md` 从头做；**一张卡一次坐下做，做完打勾再进下一张**。
3. 每张卡按孩子的实际水平选一档执行（同一项目不同环节可选不同档）：

| 档 | 孩子做什么 | 家长做什么 | 什么时候升档 |
|---|---|---|---|
| L1 观察 | 递零件、对编号、按按钮、说出看到的现象 | 全部动手 + 讲解 + 防护 | 孩子能说清「这步在做什么、成功会看到什么」 |
| L2 协作 | 拧螺丝、插线、插拔 USB、填验收表 | 把关极性与紧固、执行危险步骤 | 同类动作无提示也能做对 |
| L3 独立 | 看图纸独立做、改参数、记录数据、讲原理 | 只做安全监护，允许失败 | 能讲清「上次为什么失败、这次改了什么」 |

4. 需要**外包**的环节（家长不必自学）：3D 打印怀表壳（也可先用纸板/现成盒）、喇叭线焊接（买带插头的喇叭就不用）。
5. 卡住了：先查 `04-验收与展示.md` 的失败排查表，再对照卡片里的「失败兜底」。

## 场地、作息与收纳

- 工作台：干燥桌面 + 防火垫（放电池和充电时用）；光线充足；远离水杯。
- 单次时长：≤45 分钟（2 张卡）；孩子连续使用设备 ≤15 分钟。
- 收纳：螺丝/插头分格；每次结束拍照记录当前状态；**断电、拔电池再离开**。

## 安全红线（先读这一页）

1. 危险动作一律家长单独执行：**电池接入/充电、首次上电、装壳后长时间通电**。孩子只观察和记录。
2. 上电前必须做的三件事：① 电池极性核对（红正黑负）② 喇叭/电池插头插到底 ③ 手离开设备。
3. 出现异常（异味 / 异响 / 冒烟 / 发烫 / 屏幕花屏）→ **立即断电**，再排查；电池鼓包立即移到室外通风处。
4. 设备音量上限 70%；不贴耳试听；不边充电边放枕边。
5. 只在设备亮屏/唤醒后说话；不告诉它全名、学校、家庭住址；家长每周抽查一次对话记录。
6. 详细清单见 `05-安全与工具采购清单.md`。

## 假设与已知限制

- 本文假设：家长不会焊接、不写代码、家里有 Wi-Fi 和电脑；如会，可跳过对应外包项。
- 未验证项：连续对话续航、首响延迟、外壳尺寸、发音评测效果（均标 `待验证`，实测后更新）。
- 关键风险：**它是「在线」设备**——断网、欠费、云服务变更都会让它变笨；不要把它当离线玩具或安全监护设备。
- 内容风险：大模型可能跑题或说错；系统 Prompt + 家长抽查 + 内容过滤三道一起用，不能完全交给模型。
- 许可风险：固件与服务端均为 MIT，保留版权声明即可；不引入来源不明的模型权重。
