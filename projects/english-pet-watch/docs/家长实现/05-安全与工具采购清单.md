## 1. 本项目危险源与防护（只列本项目真实存在的）

| 危险源 | 本项目是否存在 | 谁执行 | 防护 | 出错怎么收场 |
|---|---|---|---|---|
| 市电 220V / 电源拆解 | **否**（只用 USB 5V 充电头） | — | — | — |
| 电烙铁 / 热风枪 | **通常否**（买带插头喇叭就不需要） | 家长（如需要） | 支架 + 隔热垫 + 通风，孩子远离 | 烫伤先冲冷水 15 分钟再就医 |
| 热熔胶枪 | 可选（固定电池/走线） | 家长 | 不让孩子挤胶 | 烫伤同上 |
| 锂电池充放电 | **是** | 家长 | 带保护板电池、5V/1A 充电头、不过充、不穿刺挤压 | 鼓包/异味 → 断电移到室外，停用 |
| 上电与首次开机 | **是** | 家长 | 极性核对、绝缘桌面、手离开 | 发烫/异味 → 立即断电 |
| 高音量 | **是** | 家长 | 音量 ≤70%，不贴耳，单次 ≤15 分钟 | 耳鸣/不适 → 休息并调低 |
| 小零件（螺丝/插头） | **是** | 家长 | 3 岁以下远离，分格收纳 | 误吞 → 立即就医 |
| 屏幕玻璃/排线 | **是** | 家长 | 不压、不折排线 | 裂屏 → 停用换板 |
| 网络与隐私 | **是** | 家长 | 只用唤醒后上传；不存真名/学校；定期抽查 | 发现异常内容 → 停用并改 Prompt/换模型 |
| 云端费用 | **是** | 家长 | 设每日时长与预算上限 | 超支 → 停服务、换便宜模型 |

**上电前三件事**：① 电池极性核对 ② 喇叭/电池插头插到底 ③ 手离开设备。

**异常处理**：异味 / 异响 / 冒烟 / 发烫 / 屏幕花屏 / 电池鼓包 → **先断电，再排查**，不要边跑边查。

## 7. 场地与收纳习惯

- 固定工作台 + 防火垫；充电时人不远离；**断电、拔电池再离开**。
- 螺丝/插头分格收纳，拆下的件放专用小盒。
- 每张卡结束拍照留存当前状态，便于下次恢复。
- 电池单独存放，不与其他金属件混放；不放在阳光直射处。
- 设备和充电线远离水杯、鱼缸、加湿器。
