# 家长话术与提问卡（英语宠物怀表）

| 字段 | 值 |
|---|---|
| 适用版本 | 方案 v1.0 |
| 最后更新 | 2026-11-13 |
| 前置条件 | 与 `02-里程碑与任务卡.md` 配套使用 |

> 目标：家长不讲课，只提问。孩子说出来，才算学会。每张卡至少问一次「为什么」。

## 1. 各阶段引导提问（每个里程碑选 3 个问）

| 里程碑 | 提问 |
|---|---|
| M0 采购 | 1）「你觉得怀表和手机语音助手，最大的不同是什么？」 2）「这块板为什么比普通开发板贵？贵在哪？」 3）「第一批只买必须的，你猜哪些可以以后再买？」 |
| M1 屏幕与声音 | 1）「屏幕亮的时候，电从哪来、走到哪去？」 2）「喇叭为什么能发出声音？你摸到它在动吗？」 3）「麦克风在哪？如果用手捂住会怎样？」 |
| M2 烧录与联网 | 1）「固件是什么？没有固件，板子会怎样？」 2）「它是怎么找到我们家的 Wi-Fi 的？」 3）「如果串口认不到板子，你先查哪三样？」 |
| M3 英语老师 | 1）「你说的话，先变成什么，再变成什么？」 2）「为什么它有时候听不懂？是耳朵问题还是脑子问题？」 3）「它说话的时候你插嘴，它为什么停下？」 |
| M4 装壳与展示 | 1）「为什么装壳后 Wi-Fi 会变差？」 2）「电池能用多久，你怎么测出来的？」 3）「如果明天断网，它还能教你英语吗？」 |

## 2. 孩子常问的「为什么」与答法

| 孩子的问法 | 一句话答法 |
|---|---|
| 它自己会思考吗？ | 「不会。它把你的话寄给远方的大模型老师，再把答案寄回来。」 |
| 为什么没网就不行？ | 「因为它的大脑在云端，不在表里；没网就像电话打不通。」 |
| 它为什么能听懂我？ | 「先有听写员（ASR）把声音变文字，再有老师（LLM）想答案。」 |
| 它说话为什么像真人？ | 「朗读员（TTS）把文字一句一句读出来，还能换音色。」 |
| 它会不会偷听？ | 「只在你按它/叫醒它以后才听；平时麦克风是关的。」 |
| 为什么不能一直聊？ | 「云端按时间收费，而且眼睛和耳朵也要休息。」 |
| 为什么它有时候答错？ | 「大模型也会犯错，它是陪练，不是真老师；拿不准要问家长。」 |
| 为什么装壳后信号差？ | 「电池和金属挡住了天线，就像手捂住手机。」 |
| 电池为什么会鼓？ | 「过充、劣质电池、挤压都会；鼓了就要马上停用。」 |

## 3. 本项目术语生活类比表

| 术语 | 生活类比 | 一句话解释 |
|---|---|---|
| 麦克风 | 耳朵 | 把空气的振动变成电信号 |
| 扬声器 | 嘴巴 | 把电信号变回声音 |
| 主控 / 固件 | 小脑 | 管手脚和嘴巴，不管「想答案」 |
| Wi-Fi | 电话线 | 把设备接到云端老师 |
| ASR 语音识别 | 听写员 | 把声音变成文字 |
| LLM 大模型 | 远方老师 | 读文字、想答案、写回文字 |
| TTS 语音合成 | 朗读员 | 把文字读成声音 |
| AEC 回声消除 | 捂耳朵 | 不让自己刚说的话又被自己听到 |
| 唤醒词 | 叫名字 | 只有叫它，它才开始听 |
| Prompt 提示词 | 给老师的便条 | 告诉它「你是谁、怎么教」 |
| 延迟 | 对话的等待 | 从你说完到它出声的时间 |
| OTA | 换新课本 | 通过网络更新固件 |
| 锂电池 | 充电的水壶 | 存电，但不能过充/挤压 |

> 讲术语时先用外号，再给正式名；一页只讲一个。

## 4. 收尾 20 秒复盘（每张卡结束必做）

1. 「今天成功的标志是什么？」
2. 「哪里最麻烦？」
3. 「下次想改哪里？」

## 5. 关键话术（直接抄）

- 交付动作：「你负责 __，我负责 __。电池和充电这步我一个人做，你在旁边看着。」
- 卡住时：「先只找一件事：这一步和上一张卡比，哪里不一样？」
- 失败时：「失败很正常，工程师每天在试。记下现象，下一张卡第一件事就查它。」
- 拒绝代劳：「我可以说怎么做，但手是你的——所以你才是这块表的作者。」
- 升档：「这张卡我不动手，你来做，我叫你才帮。」
- 隐私：「我们可以跟它练英语，但不告诉它真名、学校和家住哪里。」
- 内容边界：「如果它说了奇怪的话，立刻说 Stop，然后告诉我。」
- 结束语：「它不是真老师，它是陪你练胆子的宠物；拿不准的，我们一起查。」
