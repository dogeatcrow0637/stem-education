## 本项目额外约定

- **不要**把任何 API Key、Wi-Fi 密码、孩子姓名/学校写进本目录；配置只放本机 `data/.config.yaml`。
- 云端价格、续航、延迟等未实测数据必须标 `待验证`，实测后回填并更新日期。
- 引用上游架构图/文字时保留署名与许可说明。
- 课程图片优先用本项目实拍；没有实拍时用示意图，并在图注写「示意图」。

## 写作要求

- 文档头写明 **适用版本 / 最后更新 / 前置条件**。
- 危险操作（锂电池、充电、通电、音量）用 ⚠️ 单独标注，并写清防护与异常收场。
- 步骤要能**照着做**：每一大步给出「完成的判断标准」。
