# 04 · 软件环境

> 适用版本：自研固件 V0.1 + 真机 UI Demo（ESP-IDF 6.0.2 已验证）+ xiaozhi-esp32-server（MIT）　|　最后更新：2026-11-16
> 已验证操作系统：macOS 26.6（ESP-IDF 6.0.2 + 1.75C 真机）；Windows / Ubuntu `待验证`
> 前置条件：完成 `03-组装与调试.md` 的桌面最小系统

> ⚠️ 烧录必须用**物理机 USB 口**，不要用虚拟机/USB 转发（容易掉线、识别不到串口）。服务端可以跑在 Docker 里。

## 一、环境要求

| 项 | 版本 | 说明 |
|---|---|---|
| 操作系统 | macOS 13+ / Ubuntu 22.04+ / Windows 10+ | 烧录用物理机 |
| ESP-IDF | **6.0.1 或更高**（推荐 `release/v6.1`） | xiaozhi-esp32 当前要求；5.x 不再支持 |
| Python | 3.10+ | ESP-IDF 工具链与服务端 |
| 编译器 | ESP32-S3 工具链（IDF 自带） | `idf.py` |
| 服务端 | Docker 24+ 或 Python 3.10 + conda | 本机/NAS/云主机均可 |
| 硬件接口 | USB-C 数据口 | 需能传数据 |
| 网络 | 2.4GHz Wi-Fi | 设备与服务端同局域网最省事 |

## 二、安装

### 2.1 安装 ESP-IDF

```bash
# macOS / Linux
git clone -b release/v6.1 --recursive https://github.com/espressif/esp-idf.git
cd esp-idf
./install.sh esp32s3
. ./export.sh          # 每次新开终端都要 source
idf.py --version       # 期望：ESP-IDF v6.1.x
```

> macOS 先装 Xcode Command Line Tools：`xcode-select --install`。Windows 用 Espressif IDE 或官方安装器。

### 2.2 编译自研固件

> 本项目的固件源码就在 `../firmware/`，**不是**到 xiaozhi-esp32 仓库编译上游固件。V0.1 只有 Wi-Fi + OTA。

```bash
. <你的ESP-IDF>/export.sh
cd projects/english-pet-watch/firmware
idf.py set-target esp32s3

idf.py menuconfig
#   English Pet Watch ->
#     Wi-Fi SSID / Password           2.4GHz
#     Device model                    epw-watch-175
#     OTA check URL                   服务端 /xiaozhi/ota/ 地址
#     OTA check interval (seconds)    默认 300

idf.py build
idf.py -p /dev/tty.usbmodem* flash monitor   # macOS
# Linux: /dev/ttyACM0；Windows: COMx
```

版本号在 `firmware/CMakeLists.txt` 的 `PROJECT_VER`；发布 OTA 时改它，并把 `build/english_pet_watch.bin` 传到服务端 `data/bin/{model}_{version}.bin`。完整流程见 [`06-自研固件与OTA.md`](06-自研固件与OTA.md)。

**板级配置核对**（只参考上游引脚，不复制其固件代码）：

- 上游参考：`main/boards/waveshare/esp32-s3-touch-amoled-1.75/config.h`
- `AUDIO_INPUT_SAMPLE_RATE` / `AUDIO_OUTPUT_SAMPLE_RATE` = 24000
- `AUDIO_CODEC_ES8311_ADDR` + `AUDIO_CODEC_ES7210_ADDR`
- `AUDIO_CODEC_PA_PIN` = GPIO46
- `DISPLAY_WIDTH` / `DISPLAY_HEIGHT` = 466 / 466
- 1.75 与 1.75C 的 `AUDIO_I2S_GPIO_MCLK`、`EXAMPLE_PIN_NUM_LCD_RST`、`PIN_NUM_TOUCH_RST` 不同

> V0.1 还没有用音频和屏幕；这些引脚在 V0.2/V0.3 接音频与屏幕时才会写进自研固件。

### 2.3 部署服务端（最简化 Docker）

> 分工：**怀表只负责唤醒、录音、放音和屏幕**；VAD/ASR/TTS 都跑在这台服务端电脑上（LLM 在云端）。所以「本机算力」指服务端电脑，不是 ESP32-S3。
>
> **外出用手机热点**：热点要开 2.4GHz（iPhone 开「最大兼容性」），且设备和服务端必须能互相访问——服务端在家里的电脑上时，设备连手机热点是找不到它的；要么把服务端放云上，要么让服务端电脑也连同一个热点。

```bash
# 目录准备
mkdir -p xiaozhi-server/data xiaozhi-server/models/SenseVoiceSmall
cd xiaozhi-server

# 下载 docker-compose.yml 与 config.yaml（见下方链接）
# https://github.com/xinnan-tech/xiaozhi-esp32-server/blob/main/main/xiaozhi-server/docker-compose.yml
# https://github.com/xinnan-tech/xiaozhi-esp32-server/blob/main/main/xiaozhi-server/config.yaml
# config.yaml 放到 data/.config.yaml

# 下载本地 ASR 模型（默认 SenseVoiceSmall）
# https://modelscope.cn/models/iic/SenseVoiceSmall/resolve/master/model.pt
# 放到 models/SenseVoiceSmall/model.pt

docker compose up -d
docker logs -f xiaozhi-esp32-server
```

启动成功后日志应出现：

- OTA：`http://<IP>:8003/xiaozhi/ota/`
- WebSocket：`ws://<IP>:8000/xiaozhi/v1/`

> 只跑 server 的最简化模式没有智控台界面（默认端口 8000/8003）。需要网页管理多用户/多智能体时，用仓库的「全模块安装」，会额外起数据库与智控台（端口以文档为准）。

### 2.4 配置英语老师

编辑 `data/.config.yaml`，至少设：

```yaml
server:
  websocket: ws://<你的局域网IP>:8000/xiaozhi/v1/

selected_module:
  ASR: <你选的ASR>
  LLM: <你选的LLM>
  TTS: <你选的TTS>

prompt: |
  你是 Pico，一只住在怀表里的英语小宠物，陪 6–10 岁的中国孩子练英语。
  规则：
  1. 先用 1 句简单英语问候，再用 1 句中文提示；每次最多 2 个新单词。
  2. 孩子说错时不要批评，用正确的说法重复一遍，再让他跟读。
  3. 每次回答不超过 2 句话，语速慢，句子短。
  4. 不聊暴力、恐怖、成人话题；被问到就转回英语小游戏。
  5. 每 3 轮做一次小复习；结束时说一句鼓励的话。
```

> 完整版 Prompt、单词表和对话脚本见 [`../software/prompts/english-teacher.md`](../software/prompts/english-teacher.md)。

### 2.5 完整选型配置示例（可直接复制）

> 无密钥的可复制模板：[`../software/configs/`](../software/configs/)：
> `local-ollama.config.yaml`（零申请）/ `mvp-free.config.yaml`（智谱免费）/ `doubao-llm-only.config.yaml`（只接豆包 LLM）/ `mvp-stream.config.yaml`（全量流式）。
> **本项目首选 `doubao-llm-only.config.yaml`**：只申请一个火山方舟 Key，ASR 用本地 FunASR，TTS 用 EdgeTTS。

**本项目最终选型（板子到货就按这个配）**

| 模块 | 选择 | 要申请 Key 吗 |
|---|---|---|
| 唤醒 | V0.1 无；V0.2 先触摸，稳定后自研唤醒（AFE WakeNet 或云端） | 否 |
| VAD | `SileroVAD` | 否 |
| ASR | `FunASR`（本地 SenseVoiceSmall） | 否 |
| LLM | `DoubaoLLM`（Doubao-Seed-2.0-Lite） | **是，唯一必填** |
| TTS | `EdgeTTS`（`en-US-JennyNeural`，童声可换 `en-US-AnaNeural`） | 否 |
| Memory | `mem_local_short`；做单词本再升 `powermem` | 否 |
| Intent | `function_call`，只留 `change_role` | 否 |
| Prompt | [`software/prompts/english-teacher.md`](../software/prompts/english-teacher.md) | 否 |

> 模板里没有 Gemini / OpenAI 选项：它们需要代理，且免费层数据会用于产品改进，本项目不采用。

先备份再改：`cp data/.config.yaml data/.config.yaml.bak`；改完 `docker compose restart`。

**方案 A：零成本跑通（第一次部署用这个）**

```yaml
selected_module:
  VAD: SileroVAD
  ASR: FunASR
  LLM: ChatGLMLLM
  TTS: EdgeTTS
  Memory: mem_local_short
  Intent: function_call

VAD:
  SileroVAD:
    type: silero
    threshold: 0.5
    threshold_low: 0.3
    min_silence_duration_ms: 900    # 孩子说话慢；太小会抢话

ASR:
  FunASR:
    type: fun_local
    model_dir: models/SenseVoiceSmall
    language: auto                  # 中英混识；误判成韩文时改 zh 或 zh,en

LLM:
  ChatGLMLLM:
    type: openai
    model_name: glm-4-flash         # 免费档
    url: https://open.bigmodel.cn/api/paas/v4/
    api_key: <你的智谱 Key>
    temperature: 0.4                # 教学要稳
    max_tokens: 300                 # 强制短回答

TTS:
  EdgeTTS:
    type: edge
    voice: en-US-AnaNeural          # 英语儿童音色；音色名以 Edge TTS 当期列表为准
    language: "英语"

Memory:
  mem_local_short:
    type: mem_local_short
    llm: ChatGLMLLM                 # 记忆总结用免费模型，不占对话模型

Intent:
  function_call:
    type: function_call
    functions:
      - change_role                 # 只留必要插件，减少跑题
```

**方案 B：推荐日常使用（流式 + 更稳）**

```yaml
selected_module:
  VAD: SileroVAD
  ASR: DoubaoStreamASR
  LLM: DoubaoLLM
  TTS: HuoshanDoubleStreamTTS
  Memory: powermem
  Intent: function_call

VAD:
  SileroVAD:
    type: silero
    threshold: 0.5
    threshold_low: 0.3
    min_silence_duration_ms: 900

ASR:
  DoubaoStreamASR:
    type: doubao_stream
    appid: <火山语音 appid>
    access_token: <火山语音 access_token>
    resource_id: volc.bigasr.sauc.duration
    enable_multilingual: true       # 中英混识
    end_window_size: 500            # 断句静音时长(ms)

LLM:
  DoubaoLLM:
    type: openai
    base_url: https://ark.cn-beijing.volces.com/api/v3
    model_name: doubao-seed-2-0-lite-260215
    api_key: <火山方舟 Key>
    temperature: 0.4
    max_tokens: 300

TTS:
  HuoshanDoubleStreamTTS:
    type: huoshan_double_stream
    ws_url: wss://openspeech.bytedance.com/api/v3/tts/bidirection
    appid: <火山语音 appid>
    access_token: <火山语音 access_token>
    resource_id: volc.service_type.10029
    speaker: <在控制台选英语儿童音色>
    audio_params:
      speech_rate: -10              # 放慢，方便跟读

Memory:
  powermem:
    type: powermem
    enable_user_profile: true
    llm:
      provider: openai
      config:
        api_key: <LLM Key>
        model: glm-4-flash
        openai_base_url: https://open.bigmodel.cn/api/paas/v4/
    embedder:
      provider: openai
      config:
        api_key: <Embedding Key>
        model: embedding-2
        openai_base_url: https://open.bigmodel.cn/api/paas/v4/
    vector_store:
      provider: sqlite
      config: {}                    # 零成本本地库

Intent:
  function_call:
    type: function_call
    functions:
      - change_role
```

**逐模块验证表**（改完一项就查这一行，别一次全改）：

| 模块 | 怎么确认真的生效 | 不生效先看 |
|---|---|---|
| VAD | 说完停 1 秒，日志里是一整句而不是两段 | `min_silence_duration_ms` |
| ASR | 日志出现你说的话，英文单词不大面积错 | `language`、模型文件、Key |
| LLM | 回复符合 Prompt：英语为主、≤2 句、不跑题 | `model_name`、`api_key`、`max_tokens` |
| TTS | 声音是英语音色、语速慢、连续 10 轮不报错 | `voice`/`speaker`、并发额度 |
| Memory | 同一会话追问「刚才的单词」能答对 | `Memory` 键名、总结用 LLM |
| Intent | 说「退出」能结束；不加载搜索就不会联网 | `functions` 列表、LLM 是否支持 |
| Prompt | 第一句不是台湾腔，按英语老师规则说话 | 是否启用了智控台覆盖 |

**回滚**：任何一项改坏，`cp data/.config.yaml.bak data/.config.yaml && docker compose restart`。

**选型原则（给家长的一句话版）**：

1. 先免费跑通：`FunASR` + `glm-4-flash` + `EdgeTTS` + `mem_local_short`。
2. **不想申请任何 Key**：把 LLM 换成本地 `OllamaLLM`（`qwen2.5:3b`），配置模板见 [`../software/configs/local-ollama.config.yaml`](../software/configs/local-ollama.config.yaml)；代价是慢、英文质量一般。
3. 再换流式：豆包流式 ASR + 豆包/Qwen + 火山双流式 TTS，首响通常能快 1–2 秒（`待实测`）。
4. 记忆先小后大：MVP 只开本地短期；要做单词本再上 `powermem`，不要一上来用云端记忆。
5. 人设只改 Prompt，不改代码；一次只改一条规则，录前后对比。
6. 英语识别优先选支持中英混识的 ASR；本地 `FunASR/SenseVoice` 偏中文，英语口音要实测。

> 配置优先级：`data/.config.yaml` 覆盖 `config.yaml`；**启用智控台后，这两个文件里的角色/模型配置都不生效**，要在智控台按智能体设置。默认示例 Prompt 是「台湾腔女友」，给孩子用前必须替换成 2.4 的英语老师 Prompt。

## 三、运行与验证

### 3.1 V0.1（当前）：联网 + OTA

```bash
# 终端 1：服务端
docker logs -f xiaozhi-esp32-server

# 终端 2：看设备日志
cd projects/english-pet-watch/firmware
. <你的esp-idf>/export.sh
idf.py -p /dev/tty.usbmodem* monitor
```

**验证标准**：

1. 串口出现 `获得 IP: ...`；
2. 串口出现 `服务端 WebSocket 地址: ws://...`（说明 OTA 契约已通）；
3. 发布更高版本 bin 后，出现 `发现新固件` → `OTA 进度` → 重启；
4. 重启后 `版本` 与 `分区` 都变化。

发布与电脑侧探测：

```bash
./tools/ota_probe.sh http://124.222.233.196:5801/xiaozhi/ota/ 00:11:22:33:44:55 0.1.0 epw-watch-175
./tools/publish_firmware.sh build/english_pet_watch.bin 0.2.0
```

## 五、故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `idf.py: command not found` | 没 source export.sh | 每次新终端 `. <IDF>/export.sh` |
| 编译报依赖缺失 | 子模块没拉全 | `git submodule update --init --recursive` |
| 烧录找不到串口 | 线只供电/驱动缺失/被占用 | 换线；装 CP210x/CH34x 驱动；关串口监视器 |
| `Failed to connect` | 没进下载模式 | 按住 BOOT 再点 RST，或降低波特率 |
| 板子反复重启 | 供电不足/看门狗/内存 | 换 USB 口；看 panic 日志；关掉调试选项 |
| 服务端启动即退出 | 缺 `model.pt`/配置键错/端口占用 | 看日志第一行错误；补模型；改端口 |
| 设备连不上 WebSocket | IP 写错/防火墙/不同网段 | 电脑 `curl` OTA 地址；关防火墙；同一路由器 |
| TTS 没声音但日志正常 | 设备音量 0/PA 未使能/喇叭坏 | 调音量；跑音频 demo |
| ASR 识别成日文/韩文 | 语言模型/语种配置不对 | 在服务端把 ASR 语言设为中文/英语混识 |
