# 03 · 组装与调试

> 适用版本：方案 v1.0（Waveshare ESP32-S3-Touch-AMOLED-1.75）　|　最后更新：2026-11-13　|　预计耗时：2–4 小时（不含打印）
> 前置条件：已读完 `02-选型与BOM.md`，物料到货，电脑已装 ESP-IDF（见 `04-软件环境.md`）

> ⚠️ 本项目涉及**锂电池充放电**与**扬声器高音量**。电池接入、首次充电、装壳后长时间通电，全部由家长执行；孩子只在安全距离外观察。异常（异味/鼓包/发烫/异响）→ **立即断电**，电池移到室外通风处。

## 一、前置准备

| 项 | 内容 |
|---|---|
| 工具 | 十字螺丝刀、万用表（必备）、尖嘴钳、镊子、双面胶/热熔胶（可选）、USB-C 数据线 |
| 环境 | 干燥桌面、防火垫、通风；旁边不要放金属碎屑与水杯 |
| 需要先完成 | 电脑装好 ESP-IDF 6.0.1+；服务端能在局域网跑起来（可后补） |
| 软件入口 | 固件：[`../firmware/README.md`](../firmware/README.md)；服务端：[`../software/README.md`](../software/README.md) |

## 二、装配步骤

### 步骤 1：到货验收（先不接电）

- 装什么：开箱、点件、看丝印。
- 用什么：BOM 清单 + 手机拍照。
- 注意事项：
  - 确认开发板是 **ESP32-S3-Touch-AMOLED-1.75**（或 1.75C），不是无触摸版；
  - 看屏幕有无裂痕、排线是否压伤；
  - 电池是否带保护板、插头是否为 MX1.25、红黑线顺序；
  - 喇叭阻抗是否为 8Ω。
- **完成判断标准**：BOM 每一项都有实物或已登记缺件；照片存档。

### 步骤 2：桌面最小系统（只插 USB）

- 装什么：开发板 + USB-C 数据线，接电脑。
- 用什么：能传数据的 USB-C 线。
- 注意事项：
  - 先**不接电池、不接喇叭**；
  - 板子可能短暂重枚举串口，属正常；
  - 若电脑完全没反应，先换线、换口。
- **完成判断标准**：屏幕亮起（出厂 demo 或黑屏但串口能识别），电脑出现串口设备。

### 步骤 3：烧官方 demo，逐个验硬件

按 Waveshare Wiki 的 ESP-IDF demo 顺序烧，**每烧一个只验证一件事**：

| demo | 验证什么 | 通过标准 |
|---|---|---|
| `01_AXP2101` | 电源管理 | 串口能读到电池电压/充电状态 |
| `02_PCF85063` | RTC | 串口时间正常走 |
| `03_QMI8658` | IMU | 倾斜板子，数值变化 |
| `05_LVGL_WITH_RAM` | 屏幕 + PSRAM | 屏幕显示 LVGL 示例，不花屏 |
| `06_I2SCodec` | 音频 | 喇叭有测试音；麦克风能录到波形 |

- 注意事项：音频 demo 需要先接喇叭；确认功放使能脚（GPIO46）已拉高。
- **完成判断标准**：上表 5 项全部通过，并各拍一张照片/录 5 秒视频。

### 步骤 4：接喇叭与电池

- 装什么：8Ω 喇叭接到板载喇叭座；LiPo 接到 MX1.25 电池口。
- 用什么：喇叭、电池、万用表。
- 注意事项：
  - ⚠️ **先量电池极性**：红正黑负，插头方向与板子丝印一致；反接可能烧板；
  - 先接喇叭，再接电池；接电池前确认电源开关在 OFF；
  - 第一次充电用 5V/1A 普通充电头，**不要用手机快充头**；
  - 电池不要折叠、穿刺、压在螺丝下。
- **完成判断标准**：拔掉 USB 后板子仍能开机；屏幕显示电量；充电指示灯正常。

### 步骤 5：烧自研固件 V0.1（Wi-Fi + OTA）

- 装什么：能联网、能检查升级的固件（还没有语音）。
- 用什么：ESP-IDF + 本仓库 `firmware/`。
- 注意事项：
  - 先**不接喇叭和电池**，只用 USB 供电；
  - `cd projects/english-pet-watch/firmware`，`idf.py set-target esp32s3`；
  - `idf.py menuconfig` → `English Pet Watch`：填 2.4GHz Wi-Fi 的 SSID/密码、`Device model`（默认 `epw-watch-175`）、`OTA check URL`；
  - OTA 地址先填服务端局域网地址：`http://<电脑局域网IP>:8003/xiaozhi/ota/`；云上服务端用 `http://124.222.233.196:5801/xiaozhi/ota/`；
  - 完整命令与故障表见 `../firmware/README.md`。
- **完成判断标准**：串口出现 `获得 IP: ...`，随后出现 `服务端 WebSocket 地址: ...` 和 `当前已是最新固件`。

### 步骤 6：验证一次 OTA 升级

- 装什么：不装硬件，验证“服务端下发固件 → 设备自动升级”。
- 用什么：`firmware/tools/` 下的两个脚本 + 服务端。
- 注意事项：
  - 先把 `CMakeLists.txt` 的 `PROJECT_VER` 改成更大的版本（如 `0.2.0`）并 `idf.py build`；
  - 运行 `./tools/publish_firmware.sh build/english_pet_watch.bin 0.2.0` 把 bin 传到服务端 `data/bin/`；
  - 板子重新上电，串口应出现 `发现新固件` → `OTA 进度` → 重启，重启后版本号变化；
  - 板子没到货时，先在电脑上跑 `./tools/ota_probe.sh` 验证服务端返回；
  - **语音对话不在 V0.1**：V0.2 完成音频 + WebSocket 后再做「说 Hello → 英语回应」，验证标准见 `docs/06-自研固件与OTA.md` 第六节。
- **完成判断标准**：设备从旧版本升到新版本，且串口分区标签在 `ota_0` / `ota_1` 之间切换。

### 步骤 7：装壳

- 装什么：屏幕/主板/喇叭/电池进怀表壳。
- 注意事项：
  - 先干装，不锁螺丝；确认屏幕开孔、触摸、按键、USB-C 口、喇叭孔、麦克风孔都对齐；
  - 天线区域（板载天线）**不要贴电池、不要用金属壳**；外壳对应位置留非金属窗；
  - 喇叭与麦克风之间加泡棉/隔断，减少回灌；
  - 电池用双面胶固定，避免晃动拉断线；
  - 最后再接电池，锁壳前先通电测一次。
- **完成判断标准**：合壳后屏幕/触摸/麦克风/喇叭/充电都正常；Wi-Fi 信号强度与合壳前相差不超过约 10dB（`待验证`）。

## 三、通电与自检

| 检查项 | 期望结果 | 异常处理 |
|---|---|---|
| 电池极性 | 红正黑负，插头方向正确 | 反接立即拔掉，检查板子是否发烫 |
| 开机 | 屏幕亮、宠物动画/表盘出现 | 查电源开关、电池电量、USB 供电 |
| 触摸 | 点按位置准确，无漂移 | 重烧对应 1.75/1.75C 配置；查触摸排线 |
| 麦克风 | 说话时波形/识别文本变化 | 查 ES7210、麦克风孔是否被壳堵住 |
| 喇叭 | 测试音清晰、无破音 | 查 PA 使能、喇叭阻抗、音量是否过高 |
| Wi-Fi | 2.4GHz 能连，信号 > -70dBm | 靠近路由器；检查天线净空；改信道 |
| 充电 | 插 USB 后电量上升，无发烫 | 换 5V/1A 充电头；查 AXP2101 配置 |
| 连续对话 10 分钟 | 不重启、不明显卡顿 | 查内存、降亮度、看服务端日志 |

## 四、校准

| 项 | 怎么做 | 输出/记录 |
|---|---|---|
| 触摸 | 依次点四角与中心，看坐标是否落在触点 | 记录偏移方向；必要时在 LVGL 里做校准 |
| 麦克风增益 | 正常音量说话，看 ASR 是否稳定；太小声/爆音都调 | 记录 `mic_gain`（以固件配置为准） |
| AEC | 放 TTS 时说话，看设备是否把自己声音识别进去 | 确认 `CONFIG_USE_DEVICE_AEC=y`；喇叭/麦克风开孔隔开 |
| 音量 | 距耳朵 30cm 听，不超过舒适音量 | 记录音量百分比；建议上限 70% |
| 电量计 | 满电到自动关机，记录时长 | 回填 `待验证` 续航数据 |
| RTC | 断网重启后时间是否保持 | 换 CR1220/超级电容（如板载）或联网校时 |

## 五、常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 上电无反应 | 电池没电/开关 OFF/插头反接/保险 | 先 USB 供电试；量电池电压；查极性 |
| 屏幕亮但白屏/花屏 | 板级配置不对（1.75 vs 1.75C）、排线松 | 选对 Board Type；重插排线 |
| 触摸无反应 | 触摸复位/中断引脚配置错 | 对照 `config.h` 的 `PIN_NUM_TOUCH_RST`/`PIN_NUM_TOUCH_INT` |
| 喇叭无声 | PA 使能未拉高、喇叭坏、音量 0 | 先跑 `06_I2SCodec`；查 GPIO46；换喇叭 |
| 麦克风无输入 | ES7210 未初始化、麦克风孔堵、增益 0 | 跑音频 demo；清孔；调增益 |
| 设备连不上服务端 | IP/端口错、防火墙、设备与电脑不同网段 | 电脑 `ping` 设备；关防火墙；确认 `ws://IP:8000/xiaozhi/v1/` |
| ASR 一直识别错 | 环境噪音、麦克风太远、语言模型不对 | 靠近说话；换 ASR 语言/模型；加泡棉隔音 |
| 对话中途断 | Wi-Fi 不稳、服务端超时、TTS 失败 | 看服务端日志；换 5GHz 路由器的 2.4G 频段；缩短回复 |
| 装壳后 Wi-Fi 变差 | 电池/金属遮挡天线 | 天线区域开窗；电池移位；改外壳材料 |
| 充电发烫/鼓包 | 电池质量、过充、挤压 | **立即停用**，移到室外；换正规电池 |
