# code · 算法与实验代码

> 适用版本：v0.1　|　最后更新：2026-11-13
> 本项目**没有传统算法代码**：语音能力来自 xiaozhi 固件 + 服务端，教学效果主要靠 Prompt、记忆配置和对话脚本。

## 1. 现在的“代码”在哪

| 要改什么 | 改哪里 | 说明 |
|---|---|---|
| 英语老师人格 | `../software/prompts/english-teacher.md` | 系统 Prompt |
| 模型/记忆选择 | 服务端 `data/.config.yaml` 或智控台 | ASR/LLM/TTS/Memory |
| 设备交互 | 自研固件（板级引脚参考上游） | 触摸/唤醒/屏幕 |
| 单词本/复习 | V1 再做 | 先手工记录，不急着写程序 |

## 2. 未来可做的实验（按优先级）

| 实验 | 目的 | 最小做法 | 风险 |
|---|---|---|---|
| 延迟测量 | 找出最慢的一段 | 服务端日志时间戳 + 5 次取平均 | 无 |
| Prompt A/B | 验证“一次只改一条” | 两版 Prompt 各聊 3 轮，录 10 秒对比 | 跑题 |
| 单词本 | 复习闭环 | 服务端记忆 + 家长只读清单 | 隐私 |
| 发音反馈 | 跟读评分 | 讯飞 ISE / Azure 评测 API（V2） | 计费、口音 |

## 3. 约定

1. 数据集与权重不入库；本项目不训练模型。
2. 实验要有最小可复现命令与结论，否则不写进文档。
3. 引用外部代码注明来源与 commit；不要整包复制。
4. 不记录孩子真实姓名、学校、住址；测试音频用完即删。

> 目前没有可运行脚本；先按 `../software/tools/README.md` 的命令清单手工测。
