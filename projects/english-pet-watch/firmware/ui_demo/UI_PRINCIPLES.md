# UI 精简原则

本项目的所有页面（表盘 / 控制中心 / 应用桌面 / 宠物页 / 设置页）都遵循同一套精简原则。
新增或修改 UI 前先对照本文，能删就删，不能删才加。

## 1. 只显示当前需要的值

- 数值直接显示当前值：亮度`80`、音量`60`，不写 `80%`、`60%`。
- 不显示刻度端点（如 `0` / `100`），不显示百分比符号、单位说明。
- 一个页面只回答一个问题（当前亮度是多少 / 当前音量是多少），不附带科普、标题副文案。

## 2. 不展示设备不支持或没有数据来源的内容

- 不显示心率、血氧、步数等本机没有传感器的数据。
- 不用假数据占位；没有数据时留空或隐藏，而不是显示 `--`、`0`、`24°` 之类的占位符。
- 网络、电量、天气等状态必须有真实来源才展示。

## 3. 入口分层，避免功能堆叠

- 音量 / 亮度 / 手电只放在表盘下拉的控制中心，不进入应用桌面。
- 应用桌面只放真正的 App（Mimi、状态、网络）。
- 同一功能只保留一个入口，不重复放置。

## 4. 一屏一功能，操作路径最短

- 点一次进页面，滑一次回上一级；不做多层嵌套设置。
- 返回优先用「从左往右滑」，页面内不再堆返回按钮 + 文字说明。
- 大按钮（PWR）逐层退出：密码页 → Wi-Fi 列表 → 应用桌面 → 表盘，不一步跳回。

## 5. 手势只作用于当前页面

- 滑动手势不能被下层页面共享：退出音量页时，外层控制中心不能跟着位移。
- 页面根部关闭 `LV_OBJ_FLAG_SCROLLABLE`，手势事件不向上冒泡。
- 拖动跟手，松手按最近档位吸附；动画只改位移/透明度，不做全屏缩放模糊。

## 6. 熄屏优先

- 30s 无操作自动熄屏；熄屏后点屏幕或按键的第一下只负责点亮。
- 熄屏状态不唤醒、不进入 Mimi Cat、不更新台词、不发声。
- 熄屏即退出 Mimi Cat 状态，避免黑屏下保留对话。

## 7. 文案与视觉极简

- 文案短、纯中文、无营销词；一个标签最多 4 个字。
- 控制中心纯图标：不写标题、不写磁贴名、不写数值文字，靠图标形状与颜色表达。
- 圆屏边缘不放可点击控件，图标与文字留足触摸区域。
- 优先纯色块与描边，少用阴影、渐变、模糊等每帧重绘开销大的效果。

## 8. 睡眠模式

- 控制中心提供「睡眠」磁贴，点一下进入睡眠表盘：整屏黑底，只保留暗灰色时间，
  外环 / 电量 / 天气 / 日期 / Wi-Fi 全部隐藏。
- 睡眠模式下交互规则不变：下拉仍可打开控制中心，向上滑收起。
- 只有再点一次「睡眠」磁贴才恢复彩色表盘；开关状态用磁贴边框亮度区分。
- 睡眠模式只改变表盘显示，不改变熄屏策略与已有音量 / 亮度设置。

## 9. Wi-Fi 密码页（圆屏适配）

- 键盘自绘 4 行 buttonmatrix，不直接用 lv_keyboard：其构造函数会把 align 设为 BOTTOM_MID，之后 lv_obj_set_pos 只改偏移量，键盘仍贴在屏幕底部并被圆屏裁掉。
- 键盘 360×200 放在 (53,166)：上沿距圆边 70px、下沿 10px，四个角都在 466 圆内，4 行按键完整可见。
- 按键只用 0x20-0x7E ASCII（Aa / abc / 1# / Del / space / OK），epw_cjk_16 不会缺字。
- 密码框高 60px，文字用 pad_top 垂直居中；点按输入框或键盘输入都不跳动。
