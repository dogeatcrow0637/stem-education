# 可实现路径与外包（Step 3 用）

目标：把"这个项目要做什么"落成**能买到、能下单、能外协、能验收**的具体动作。
原则：**能买到的都不自制；自制只保留"买不到且安全"的那部分。**

> 价格只写量级，且必须标 `以页面为准（访问日期 YYYY-MM-DD）`。活动价与首单优惠经常变，不要把旧价写进教学文档。

## 一、先做决策：这块要自己做吗

| 情况 | 做法 | 理由 |
|---|---|---|
| 官方有现成主板/驱动板卖 | **直接买** | 便宜、有文档、坏了能换 |
| 功能都在成品模块里（电机驱动、传感器、电源） | 模块 + 洞洞板/杜邦线/PCB 转接板 | 免焊、可反复改 |
| 只有面包板级需求 | 面包板先跑通，最后再固化 | 孩子能自己插拔，试错成本低 |
| 官方只给原理图，没有成品 | 画板打样（见 §2）或洞洞板手焊 | 先估算：元件数 > 20 或需要走线才值得画板 |
| 机械件官方只给 STEP | 3D 打印代做（见 §3）；急用先 FDM-PLA | 别买 3D 打印机就能开工 |
| 需要焊接/烧录/标定但家长不会 | 外协（见 §5） | 唯一不能外包的是"调试与排错" |

给孩子的说法：**"我们先搭积木，等它跑通了再把它变成一块真正的板子。"**

## 二、PCB 打样与贴片（嘉立创 / 立创EDA 流程）

**流程（家长能照做的顺序）**

1. 画图：立创EDA（网页版，免安装）→ 新建工程 → 原理图 → 转 PCB → 自动布线可先凑合 → **DRC 检查必须 0 错误**。
2. 导出：Gerber（打样用）、BOM（元件型号 + 位号 + 数量）、坐标文件（贴片用）。
3. 下单：嘉立创下单页面上传 Gerber → 逐项选参数 → 加入购物车 → 付款。需要贴片时再传 BOM + 坐标文件，选"SMT 贴片"服务。
4. 收货验收：见 §6。

**下单参数怎么选（新手默认值）**

| 参数 | 默认 | 说明 |
|---|---|---|
| 层数 | 2 层 | 4 层只在有高速信号/电源层需求时用；6 层以上教学项目不需要 |
| 尺寸 | ≤100×100mm | 这个尺寸档最便宜；超了价格跳档 |
| 数量 | 5 片 | 打样就是给 5 片，留 1–2 片备用（焊接练习） |
| 板厚 | 1.6mm | 插拔端子需要强度就 1.6mm，不要 0.8mm |
| 铜厚 | 1oz | 电机/大电流回路再上 2oz |
| 阻焊/丝印 | 任意颜色 | 让孩子选颜色（唯一不影响电性能的选择权） |
| 表面处理 | 喷锡（有铅/无铅） | 沉金是给细间距 BGA 用的，贵 |
| 拼板 | 需要拼接才选 V-CUT/邮票孔 | 单板别拼，减少断板与返工 |
| 最小线宽/间距 | 6/6mil 及以上 | 越小越贵且易废板 |

**SMT 贴片要点**

- BOM 里元件必须写：**型号 + 封装 + 位号 + 数量**；同型号不同封装不能合并。
- 优先选商城有库存的元件；无库存要么换型号，要么走"自行寄件"（更慢更贵）。
- 只贴关键元件（主控、驱动、细间距芯片），剩下的排针、端子、大电容留给自己/孩子焊（L2 参与）。
- 单面贴片比双面便宜；元件都在同一面。
- 需要多板重复焊接时才做钢网。

**常见被拒/翻车**

- DRC 有未连接网络、丝印压焊盘、焊盘间距小于工艺能力 → 直接退单。
- BOM 位号与坐标文件位号不一致 → 贴错位置。
- 元件封装选错（原理图对、PCB 图不对）→ 板子回来焊不上，只能飞线。
- 花了大钱做板，结果电路没在面包板上验证过 → **规则：任何自制板，必须先在模块/面包板上跑通同一套电路。**

## 三、结构件：3D 打印与激光切割

| 方式 | 适合 | 关键参数 |
|---|---|---|
| 嘉立创 3D 打印（树脂/尼龙等，以页面为准） | 精度要求高、表面要好看的小件 | 传 STL/STEP；按克或按体积计价；标注关键公差 ±0.2mm |
| 淘宝/FDM 代打店 | 大件、承力件、急件 | 材料 PLA / PETG / 尼龙；层高 0.2mm；填充 15%（外观件）～40%（承力件）；按克计价 |
| 激光切割（亚克力/木板） | 平板结构、底板、外壳板 | 给 DXF/SVG；孔位按 0.1–0.2mm 补偿；亚克力厚 3–5mm |
| CNC / 钣金 | 金属支架、底板 | 给 STEP + 材质 + 表面处理；最贵，能买成品就别做 |

打印件下单前必查：**孔位是否预留公差**（直接按标称尺寸打，装不进螺丝）；**是否需要支撑**（悬空面朝向改一下能省支撑）；**承力方向**（层间方向是弱点，别让受力垂直于层纹）。

替代手作（零成本、孩子参与度最高）：亚克力板 + 尼龙柱、雪糕棒/瓦楞纸做外壳草模、乐高做关节限位。**先用草模验证结构，再下单打印正式件。**

## 四、线束、端子与工具

- 优先买**成品线束**；自制才需要压线钳与端子。
- 必须写清：线径（AWG）、长度（mm）、端子型号、针序（1 号在哪边）、对端接口。
- 免焊方案：快接端子（WAGO 类）、杜邦端子、XT30/XT60 成品线、鳄鱼夹。
- 一次买对的工具：十字/内六角螺丝刀套装（含 M2–M4）、镊子、万用表、尼龙柱与铜柱混装包、热缩管、扎带、分格收纳盒。
- 焊接类工具（烙铁、热风枪、助焊剂）**不是必需品**——不能外包再加购。

## 五、外协渠道与话术

| 需求 | 找谁 | 交付物 | 话术要点 |
|---|---|---|---|
| 代焊 | 创客空间/电子市场/闲鱼 | 焊好的板 + 通断检查结果 | "按位号表焊接，不要动 XX 元件，焊完拍照" |
| 代烧录 | 淘宝/闲鱼/社区群 | 已烧录模块 + 一句话验证方法 | "烧这个 hex/bin，烧完告诉我串口应看到什么" |
| 代打打印件 | 淘宝/嘉立创 | 件 + 按件号分装 | "按 100% 缩放，别自动修复模型，件号写在袋子上" |
| 代建模 | 学生/闲鱼/自己学 | STEP + STL + 打印参数 | 给草图尺寸与装配关系 |
| 远程装环境 | 社区/Linux 用户 | 能跑通的命令序列 | 要求写成脚本，别只口头讲 |

外协件进文档时必须写：下单要点 / 价格量级 / 交期 / 收货验收动作。**外协不等于免责——排错还是家长的事。**

## 六、收货验收（每次到货都做，孩子可参与 L1/L2）

- [ ] 数量与型号逐项核对，缺件立刻报商家（截图订单 + 包装照片）
- [ ] PCB：目检虚焊、桥连、元件方向、位号是否对得上；万用表量电源与地是否短路
- [ ] 贴片板：对照 BOM 抽查 3 个关键元件
- [ ] 打印件：关键孔距用尺量（与图纸差值 >0.3mm 就找店家）
- [ ] 线束：逐根量通断、确认针序
- [ ] 结果记进采购清单备注列（谁验收、日期、结论）

## 八、写进文档的三条硬约束

1. 每个硬件环节必须给出"买成品 / 代做 / 自制"三选一结论，不能只列元件。
2. 自制件必须给参数（层数、板厚、材料、填充、公差），让别人能照着下单。
3. 别把"打样过"写成"验证过"；板子回来后未通电测试的，一律标 `待验证`。
