# 儿童适配与安全（Step 4 用）

用途：把拆解出来的工程步骤，改写成"零基础家长 + 小学生"能安全执行的卡片与话术。

分工：本文管**分档、节奏、术语类比、安全红线**；游戏化包装、语言规则、情绪处理、知识卡五步法、课件写法见 `儿童友好设计.md`。

## 一、三档参与度的判定

不要用年龄当唯一标准，用**三个可观察能力**判档（同一项目不同环节可以不同档）：

| 能力 | 低档信号 | 可升档信号 |
|---|---|---|
| 观察与表达 | 说不清"刚才发生了什么" | 能主动说出"上次失败是因为 XX" |
| 精细动作 | 拧不动 M3 螺丝、插不准排线 | 能对准孔位、能自己插拔 USB-C 与排线 |
| 阅读理解 | 需要家长逐句念 | 能照着图示独立完成 3 步以上 |

> 学段只是起点参考：1–2 年级通常全项目在 L1–L2 之间；3–5 年级在 L2 为主，少量 L3；有乐高/编程基础的可提前进 L3。

## 二、节奏与注意力

- 单个动作单元 **≤ 25 分钟**；超时的动作一定拆成两张卡。
- 每 **3 张卡**安排一次"展示时刻"（拍照/录 10 秒视频/让家长看结果），这是唯一能撑住长期兴趣的机制。
- 一次坐下不超过 **2 张卡（约 45 分钟）**，中间必须休息；宁可一天一张卡也不要连做三小时。
- 顺序原则：**先反馈、后原理**。先让灯亮、轮子转，再解释"为什么"——反过来孩子会走神。
- 项目周期建议压在 4–8 周内，隔太久要重新找回上下文。

## 三、把抽象概念翻译成孩子听得懂的话

三步法：

1. **找生活对应物**（他能摸到、见过的东西）
2. **说它做什么**（一句话描述行为，不讲参数）
3. **给一句话定义**（正式术语 + 类比绑定）

示例（直接可用，也按此格式自造其它词）：

| 术语 | 类比 | 一句话定义 |
|---|---|---|
| 电压 / 电流 | 水压 / 水流 | 电压是"推水的劲儿"，电流是"每秒流过多少水" |
| 固件 | 机器人的"小脑" | 装在板子上、负责让电机听话的那段程序 |
| 上位机 | 遥控器的大脑 | 电脑上那个发命令、看画面的软件 |
| CAN 总线 | 对讲机频道 | 大家共用一条线，轮流说话，抢话就乱 |
| 标定 | 校秤 | 告诉机器"这个位置叫 0 度"，校准后才准 |
| PID | 骑车扶龙头 | 偏了就拉回来，劲儿太大就晃，太小就倒 |
| 终端电阻 | 水管末端堵头 | 不堵住信号会反弹，通信就出错 |
| 堵转 | 用力顶住电风扇 | 转不动时电流最大，容易发热烧掉 |
| 3D 打印填充率 | 面包的夹心密度 | 里面越实越结实，也越费料越久 |
| 抱闸 | 自行车的刹车 | 有刹车断电不会掉，没刹车一断电就往下掉 |

规则：**每个术语在文档中第一次出现处**必须补齐这三列；正文里不再重复解释。

## 四、话术模板

| 场合 | 话术 |
|---|---|
| 卡片开场 | "这张卡我们只做一件事：让 XX 动一下。做完你指给我看，动没动。" |
| 交付动作前 | "你负责拧这四个螺丝，我负责插电。插电的时候你站这边看着，先别碰。" |
| 孩子卡住 | "先别急，我们只找一件事：这一步和上一张卡比起来，哪里不一样？" |
| 失败时 | "失败很正常，工程师每天都在试。我们记一下现象，下一张卡第一件事就是查它。" |
| 收尾（20 秒复盘） | "今天成功的标志是什么？""哪里最麻烦？""下次想改哪里？" |
| 升级到 L3 | "这张卡我不动手，你来做，我只在你叫我时才帮。" |
| 拒绝代劳 | "我可以说怎么做，但手是你的——所以你才是这台机器的作者。" |

## 五、安全红线（写进每张相关任务卡）

**一律家长单独执行、孩子在安全距离外或以 L1 参与**：

| 危险源 | 防护 | 出错怎么收场 |
|---|---|---|
| 市电 220V / 电源适配器拆解 | 不拆电源本体；只在断电后接线 | 立即断电，湿手不碰，检查后重来 |
| 电烙铁 / 热风枪 | 固定支架、隔热垫、通风、儿童远离 | 烫伤先冲冷水 15 分钟再就医 |
| 热熔胶枪 | 胶温 >150℃；不让孩子挤胶 | 同上 |
| 锂电池充放电 | 用原装充电器、不过充、鼓包即停用；不可穿刺挤压 | 鼓包/异味 → 断电移到室外空地 |
| 上电与电机使能 | 先固定机身、限位、清空运动范围 | 异常抖动/异响 → 立刻断电 |
| 无抱闸关节（断电下落） | 加支撑、垫软垫、不用来托易碎物 | 落下前不要把手伸进运动范围 |
| 旋转件 / 高速风扇 / 激光 | 装护罩、孩子不戴宽松衣物与挂饰、不直视激光 | 停机后再处理卡料 |
| 金属加工（钻孔 / 切割 / 锉） | 夹持固定、护目镜、家长操作 | 小伤口冲洗消毒；铁屑勿用手扫 |
| 结构调整（弹簧 / 夹爪） | 卸力后再拆，避免夹手 | 夹伤冷敷，严重就医 |

**场地与习惯**：固定工作台 + 防火垫 + 分区收纳（螺丝按规格分格）+ 每次结束拍照记录状态 + 断电断料再离开。

## 六、家长常见误区（写进 `00-总纲` 提醒）

1. **代劳**：孩子慢就抢过来做 → 兴趣立刻消失。允许慢，只控制系统安全边界。
2. **赶进度**：跳卡导致后面全崩（尤其漏装零件、漏紧固）。
3. **跳过验收**：没验收就进下一张卡，出错时无法定位是哪一步。
4. **一次到底**：连续 3 小时 → 注意力崩、情绪崩。
5. **把"没跑通"当失败**：应把它当成"发现了新卡点"，并写进踩坑表。
6. **只动手不解释**：孩子变成搬运工，学不到东西；每张卡必须有一次"为什么"。
7. **不记录**：没有照片与现象记录，下次无法复现与排查。

## 七、让孩子持续参与的四个角色

每张卡选一个角色给孩子（轮换），比单纯"帮忙"更能维持动机：

| 角色 | 职责 | 适合档 |
|---|---|---|
| 材料管理员 | 按 BOM 找件、点数、分格收纳、报告缺件 | L1 |
| 记录员 | 拍照、在验收表打勾、记下异常现象 | L1–L2 |
| 装配工 | 拧螺丝、插线、按顺序装 | L2 |
| 质检员 | 按验收判据检查（松了没、接对没、转得动没）、签字 | L2–L3 |
| 工程师 | 改一个参数、提出一个改进、讲清原理 | L3 |
