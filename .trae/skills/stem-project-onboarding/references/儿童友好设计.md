# 儿童友好设计（Step 5 / 课件 / 知识卡 用）

一句话标准：**孩子愿意自己坐下来做第二张卡，就算设计成功。**
术语类比表见 `儿童适配与安全.md` §三；本文补游戏化、语言、视觉、情绪与知识卡写法。

## 一、游戏化骨架（把工程步骤包装成关卡）

| 工程物 | 孩子的说法 | 作用 |
|---|---|---|
| 里程碑 M0–M4 | 第 1–5 关 | 有终点感 |
| 任务卡 | 任务卡（带编号，如 `M2-2`） | 一张卡一件事，做完盖章 |
| 验收判据 | 通关条件（"灯亮了"/"轮子转一圈"） | 孩子能自己判断过没过 |
| 一次示波/一次演示 | 展示时刻（每 3 张卡一次） | 唯一能长期撑住兴趣的机制 |
| 项目完成 | Boss 关：做给家人看 | 归属感 |
| 能力成长 | 称号升级：材料员 → 接线员 → 调试员 → 工程师 | 比分数更持久 |

道具（低成本就够）：印章/贴纸本、进度条（白板画 5 格）、计时器（沙漏或手机倒计时）、名牌（写当天角色）、"线索本"（记录失败现象）。

规则：**只有通关才算盖章**；不许用"做完就奖励零食"替代——奖励要绑在结果上，不绑在时间上。

## 二、语言规则（写卡片、课件、话术都遵守）

1. 一句话 ≤12 字；一张卡最多 3 句连续的命令。
2. 术语**先给外号，再给正式名**："这个爱数格子的小尺子，正式名字叫编码器。"
3. 抽象概念用"看得见的东西"打比方（见下表）。
4. 拟声词与拟人化描述现象："电机在使劲，嗯嗯叫，说明它被卡住了。"
5. 不用否定式命令（"别碰" → "手放在这里"）。
6. 不出现"显然、简单、当然、这都不懂"这类词。

**新增常用类比（与 `儿童适配与安全.md` 的术语表互补，首现处用）**

| 术语 | 类比 | 一句话解释 |
|---|---|---|
| 齿轮/减速比 | 变速自行车 | 小牙盘带大牙盘，转得慢但更有劲 |
| 电机 | 会转的肌肉 | 通电就转，转多快看给多少电 |
| 编码器 | 数格子的尺子 | 记下"转了多少格"，机器才知道自己在哪 |
| 电池/电源 | 水壶/水塔 | 水壶带出门用，水塔一直供水 |
| 传感器 | 眼睛和耳朵 | 帮机器"看见""听见"，它自己不会感觉 |
| 程序 | 菜谱 | 一步一步照着做，顺序错了味道就变 |
| 循环 | 重复做同一件事 | "再来一遍"写一次就能做很多遍 |
| 变量 | 贴了标签的盒子 | 盒子上写名字，里面装会变的数 |
| 电路 | 环形跑道 | 电要跑一整圈回到起点，断一节就跑不动 |
| 地线 | 下水道 | 所有水最后都回到这里，大家要共用 |
| 电阻 | 细吸管 | 吸管细了水就流得少 |
| 主控板 | 交通警察 | 它决定谁先走谁等着 |
| 继电器 | 别人帮你按开关的手 | 小电控制大电，手不去碰高压 |
| 堵转 | 顶住电风扇不让转 | 转不动时电流最大，最容易发热 |

## 三、节奏：10 分钟微循环

每个环节按 **看 → 猜 → 做 → 说** 循环，一轮 10 分钟内：

1. 看（1 分钟）：家长演示一次，孩子只看不说话。
2. 猜（1 分钟）："你猜它会往哪转？"先说不许试。
3. 做（5 分钟）：孩子动手，家长只在安全边界上介入。
4. 说（1 分钟）："刚才发生了什么？"孩子复述一遍。

硬约束：单卡 ≤25 分钟；一次坐下 ≤2 张卡；一张卡结束必须留一个"下次的钩子"（"下次我们让它自己走一圈"）。**先反馈后原理**——先让灯亮，再解释为什么亮。

## 四、视觉与动手友好

- **编号贴纸**：零件/端子/线都贴编号，图纸上写同一编号；孩子只要对号，不用读字。
- **颜色编码**：正极红、负极黑、信号黄（与实物线色一致，别只在图上标色）。
- **大图优先**：课件与卡片以照片/截图为主，一张图配 ≤3 个词；箭头标出"看这里"。
- **实物对照**：图旁边放实物照片（同一角度），孩子才能对上。
- **收尾固定动作**：拍照 → 打勾 → 把螺丝收进对应格。

## 五、情绪与挫败处理

| 情形 | 家长说什么（照抄） |
|---|---|
| 孩子装反了 | "先别拆，我们看看它现在是什么样子，再决定怎么改。" |
| 反复失败 | "试到第三次了，说明这个坑有点深，我们来换个办法。" |
| 孩子想放弃 | "今天先到这儿，这台机器已经完成 __ 了，明天只做一件事。" |
| 想抢家长的活 | "这一步是危险动作，交给我；危险的归我，好玩儿的归你。" |
| 孩子非要改方案 | "可以，你先说改了以后会怎样，我们再动手。" |

家长红线：不代劳、不赶进度、不跳验收、不一口气讲完原理、不把"没跑通"当失败。**允许一张卡连续两周做不完，但不允许跳过。**

## 六、儿童知识卡：五步法（本项目每个原理点一张，随课时分发到 `儿童课程/第NN课-课题/知识卡/`）

| 步 | 写什么 | 长度上限 | 关键要求 |
|---|---|---|---|
| 1 看到什么 | 一个能亲眼看到的现象 | 1 句 | 必须现场能复现，不用仪器 |
| 2 先猜 | 一个开放问题 + 两个常见猜法 | 2 句 | 不写答案，留白 |
| 3 动手验证 | 家里就能做的小实验 | 3 步 | **不需要额外采购**，5 分钟内出结果 |
| 4 它叫什么 | 外号 → 正式术语 → 生活类比 | 3 行 | 术语只出现一次，加粗 |
| 5 还在哪见过 | 生活中 2 个例子 | 2 条 | 越贴近孩子日常越好 |

**分层问法（同一张卡按档问）**

| 档 | 问法 |
|---|---|
| L1 | "你看到了什么？跟你猜的一样吗？" |
| L2 | "如果我们把它换成 __，会变成什么样？" |
| L3 | "你能用一个生活里的例子，讲给奶奶听吗？" |

**样例（机械臂项目，可直接改）**

> 标题：**会数格子的尺子**
> 1 看到：用手把机械臂的关节拧一下，屏幕上有个数字跟着变。
> 2 先猜：它是怎么知道你转了多少的？（A 它看着你 B 它自己数格子）
> 3 动手验证：用纸盘画 12 个格子做成转盘，让家人背对着转，你只看格子数，能报出转了多少吗？
> 4 它叫什么：外号"数格子的尺子" → 正式名**编码器** → 类比：像尺子上的刻度，转一格记一次。
> 5 还在哪见过：健身车的显示屏、打印机的进纸轮。

> 标题：**转得慢更有劲**
> 1 看到：同一台电机，装上大齿轮后能抬起更重的东西，但转得慢。
> 2 先猜：为什么慢下来反而有力气？
> 3 动手验证：用乐高/积木搭两级齿轮，试着用手按停小齿轮和大齿轮，哪个更难按停？
> 4 它叫什么：外号"变速车的大牙盘" → 正式名**减速比** → 类比：变速自行车上坡用小牙盘带大牙盘。
> 5 还在哪见过：电梯的曳引机、玩具车的齿轮箱。

## 七、课件页设计规则（配合 `assets/课件模板/示例-第一课.md`）

- 一页只讲一件事；**页面上文字 ≤15 字**，其余靠家长说。
- 一页讲 1 分钟；一课时 10–14 页（45 分钟课程）。
- 每页必须有图位：实物照片 / 截图 / 手绘草图都行，**空图位不算完成**。
- 固定节奏页：封面（今天做什么）→ 现象页 → 猜一猜页 → 动手页（步骤 ≤3）→ 通关条件页 → 庆祝页。
- 提问页只放问题与两个选项，不放答案；讲者备注写"孩子答错怎么接"。
- 播放：`build_slides.py` 生成 HTML，浏览器全屏 + ←→ 翻页，`N` 显示备注，`Ctrl+P` 导出 PDF 当讲义。

## 八、亲子对话的说话规则

本仓库不产出备课文案；下面这些规则用于家长手册的"话术与提问卡"和课件讲者备注。

- 用口语短句，允许停顿标记（`（停 3 秒）`）。
- 先问后讲：任何知识点先抛问题，等 10 秒再给线索，最后才给答案。
- 每讲 5 分钟必有一次孩子动手；孩子只说不做的段落不超过 3 分钟。
- 孩子答错不给否定，给"那我们试试看"。
- 收尾 3 问固定：今天成功的标志是什么 / 哪里最麻烦 / 下次想改哪里。
