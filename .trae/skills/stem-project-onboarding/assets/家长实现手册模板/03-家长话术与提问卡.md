> 目标：家长不讲课，只提问。孩子说出来，才算学会。每张卡至少问一次"为什么"。

## 1. 各阶段引导提问（每个里程碑选 3 个问）

| 里程碑 | 提问 |
|---|---|
| M0 定稿与采购 | 1）"我们要做的这个东西，你见过真的吗？在哪见过？" 2）"你看这两套，哪个贵、差在哪？" 3）"第一批只买必须的，你猜哪些可以先不买？" |
| M1 通电自检 | 1）"通电以后你看到了什么？" 2）"如果灯不亮，可能是哪三个原因？" 3）"为什么上电的时候要离远一点？" |
| M2 单模块能动 | 1）"刚才是谁让这个关节动的？" 2）"改大一点会发生什么？先猜再试。" 3）"它动的时候有什么声音？说明什么？" |
| M3 完整链路 | 1）"命令从哪出发、经过谁、最后到哪里？" 2）"如果电脑认识不到它，先查什么？" 3）"哪一步最容易出错？" |
| M4 自主创作 | 1）"你想让它多一个什么本事？" 2）"改哪里最小、最容易成功？" 3）"怎么证明你的改动有效？" |

## 2. 孩子常问的"为什么"与答法

| 孩子的问法 | 一句话答法 |
|---|---|
| 为什么不能直接用手拨？ | "手拨它不听指挥，我们要让它自己会数角度。" |
| 为什么插反了会坏？ | "电和水一样，倒着流会把里面的零件冲坏。" |
| 为什么要先装这个再装那个？ | "因为后面装上去就挡住螺丝了，就像先穿袜子再穿鞋。" |
| 为什么它有时候抖？ | "它使劲太大了，像骑车扶龙头抓太紧。" |
| 为什么非要对着电脑？ | "电脑是它的教练，教练喊口令它才做动作。" |
| 为什么不能一步到位？ | "大楼也是一层一层盖的，我们先盖第一层。" |

## 5. 关键话术（直接抄）

- 交付动作："你负责 __，我负责 __。危险的那步我一个人做，你在旁边看着。"
- 卡住时："先只找一件事：这一步和上一张卡比，哪里不一样？"
- 失败时："失败很正常，工程师每天在试。记下现象，下一张卡第一件事就查它。"
- 拒绝代劳："我可以说怎么做，但手是你的——所以你才是这台机器的作者。"
- 升档："这张卡我不动手，你来做，我叫你才帮。"
