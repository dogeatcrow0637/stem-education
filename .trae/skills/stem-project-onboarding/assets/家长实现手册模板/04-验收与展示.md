## 2. 失败排查表（按顺序查，不要跳）

| 现象 | 最可能原因（按概率排序） | 先查什么 |
|---|---|---|
| 上电无任何反应 | 未供电 / 保险 / 开关 / 极性反接 | 万用表量电源输出 → 量板端电压 |
| 灯亮但不通信 | 线序错 / 设备未使能 / 串口被占用 | 换线 → 查设备列表 → 关掉占用程序 |
| 电脑识别不到设备 | 驱动 / 权限 / 线材（很多线只供电不传数据） | 换一根确认能传数据的线 → 查权限与 udev |
| 电机不动 | 未使能 / ID 冲突 / 供电不足 / 抱闸未松 | 逐项查：使能状态 → ID → 电源电流 |
| 电机抖动或异响 | 参数过大 / 机械干涉 / 限位未设 | 降速度幅度 → 手动盘车看是否卡 |
| 通信偶发失败 | 终端电阻 / 共地 / 干扰 / 线太长 | 查终端电阻与接地 → 缩短线 → 远离大电流线 |
| 打印件装不上 | 公差 / 支撑残留 / 方向装反 | 清支撑 → 攻丝或铜螺母 → 核对镜像件 |
| 跑一会就断 | 过热保护 / 电源余量不足 / 接触不良 | 断电摸温度 → 查电源额定 vs 峰值 |

## 3. 作品展示脚本（让孩子讲 3 分钟）

1. **它是什么**（30 秒）："这是我做的 __，它能 __。"
2. **怎么做的**（60 秒）：按"先…然后…最后…"说三个最关键的步骤。
3. **最难的地方**（45 秒）："最难的是 __，我试了 __ 次，最后用 __ 解决。"
4. **我还想改**（45 秒）："下一步我想让它 __。"

家长只做两件事：计时、听完后问一个问题（"如果再来一次，你会先做什么？"）。
