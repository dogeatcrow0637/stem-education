## M0 定稿与采购

目标：型号定稿、MVP 物料到货、核对无缺件。

### 卡 M0-1：选版本与下单
- 目标（孩子视角）："我们决定买哪一套，把它请回家。"
- 物料：采购清单（见 `05-安全与工具采购清单.md`）
- 三档分工：L1 一起看图片/视频并说出选哪个｜L2 一起对照清单点数量｜L3 孩子做比较表（价格/难度）并给结论
- 步骤：
  1. 看官方演示视频 → 结果：孩子能说出"我们要做的是这个"
  2. 对照版本对比表选型 → 结果：写下一行结论（版本 + 理由）
  3. 下单 → 结果：订单截图存档
- 验收判据：清单每一项都有"已下单/替代型号"状态
- 失败兜底：缺货 → 换替代型号或分两家买
- ⚠️ 安全：—

### 卡 M0-2：到货核对
- 目标："所有零件都到齐，一个都不少。"
- 物料：采购清单 + 收纳盒
- 三档分工：L1 报出零件名｜L2 点数并分格收纳｜L3 记录缺件与错件
- 步骤：逐项核对 → 结果：清单全部打勾；分格收纳 → 结果：照片一张
- 验收判据：无未处理缺件（缺件已联系商家）
- 失败兜底：缺件先做不依赖它的里程碑

## M1 通电自检

目标：供电正常、无短路，孩子看到"活的"第一眼反馈。

### 卡 M1-1：结构粗装与固定
- 目标：把机器立起来、固定住，不会自己倒/掉。
- 物料：__（打印件 / 螺丝 / 工具）
- 三档分工：L1 递件对号｜L2 拧螺丝（家长把关力矩）｜L3 独立照图装
- 步骤：
  1. 按图装 __ → 结果：底座能立住不晃
  2. 固定线束 → 结果：极限姿态不夹线
- 验收判据：__（螺丝紧固、无干涉）
- 失败兜底：孔位偏紧 → 攻丝或换铜螺母；干涉 → 先调限位
- ⚠️ 安全：无抱闸/弹簧类结构拆装前先卸力

### 卡 M1-2：首次上电
- 目标：灯亮/屏亮/蜂鸣，说明电走到了。
- 物料：__（电源、线束、万用表）
- 三档分工：L1 在安全距离外看并说出看到什么｜L2 家长口令下按住电源开关｜L3 自己按顺序上电并口述检查项
- 步骤：
  1. 断电状态核对极性 → 结果：正负极对得上
  2. 上电 → 结果：__（灯亮/屏亮/蜂鸣）
- 验收判据：出现预期反馈且无发烫、异味、异响
- 失败兜底：无反应 → 查电源/保险/开关；发烫或异味 → 立即断电
- ⚠️ 安全：上电前清空运动范围、机身固定、手离开运动区域

## M2 单模块能动

目标：一个电机（或一个传感器）受控动作，孩子第一次看到"我让它动它就动"。

### 卡 M2-1：烧录/配置固件
- 目标：板子装上"小脑"。
- 物料：__（开发板、数据线、固件）
- 三档分工：L1 看着并复述"烧进去的是什么"｜L2 在口令下插拔线｜L3 独立照文档烧录
- 步骤：
  1. 装工具链（如无法完成 → 外包/用预烧录模块）→ 结果：__命令能跑
  2. 烧录 → 结果：串口出现 `__`
- 验收判据：串口出现预期信息 / 板载灯按预期闪烁
- 失败兜底：串口被占用 → 关掉上位机；识别不到板 → 换线、装驱动
- ⚠️ 安全：烧录前断开电机/舵机电源

### 卡 M2-2：让一个关节/轮子动起来
- 目标："我发命令，它动一下。"
- 物料：__
- 三档分工：L1 按按钮｜L2 按口令发指令并记录现象｜L3 自己改一个参数（角度/速度）看变化
- 步骤：发一条指令 → 结果：__ 动一次（录 ≤10 秒视频）

## M4 自主创作

目标：孩子提出并实现一个小改动，形成"这是我改的"归属感。

### 卡 M4-1：改一个参数
- 目标：改动前后有可比较的差异。
- 三档分工：L1 选"改哪个、变大还是变小"｜L2 一起改并观察｜L3 独立改并解释原理
- 步骤：记录原始值 → 改 → 对比 → 结果：对比记录（数字/照片）
- 验收判据：孩子能说出"改了什么、为什么变了"

### 卡 M4-2：加一个功能 / 讲给别人听
- 目标：把作品讲清楚，成为"作者"。
- 三档分工：L1 说 3 句话介绍｜L2 演示 + 说 1 分钟｜L3 独立做 3 分钟讲解（按展示脚本）
- 验收判据：能回答"哪里最难、怎么解决的"
