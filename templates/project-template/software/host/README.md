# host · 上位机

图形化控制台 / 监控面板 / 参数配置工具。

## 必备内容

| 项 | 说明 |
|---|---|
| 运行环境 | 操作系统与版本、Python/运行时版本、USB/串口/网口权限 |
| 安装 | 依赖安装命令，或 `../tools/setup.sh` |
| 启动 | 具体命令；首次运行的初始化（标定、连接设备） |
| 界面说明 | 每个功能区的截图 + 一句话用途 |
| 验证 | **怎么算跑通**：能连上设备并在界面看到实时状态 |
| 故障排查 | 设备未识别、权限不足、端口占用等常见问题 |

## 约定

- 与设备通信的协议（串口 / CAN / TCP / MQTT）要单独成文，与 `firmware/README.md` 的协议表保持一致。
- 日志分级输出并落盘，便于课堂排障；不要打印敏感配置。
- 截图放 `../../resources/`，命名 `host_<功能>.png`。
