# sdk · 二次开发接口

对外提供的能力封装，供学生/开发者写自己的程序调用。

## 必备内容

| 项 | 说明 |
|---|---|
| 安装 | `pip install -e .` / 导入方式 |
| 快速示例 | 最小可运行代码（连接 → 读状态 → 发一条指令） |
| API 列表 | 类/函数、参数、返回值、异常 |
| 版本 | 与固件/硬件版本的兼容矩阵 |

## 约定

- 提供**最小示例**与**典型用例**各一个，示例代码必须可直接运行。
- 兼容矩阵写清楚：`sdk v1.2` 配 `firmware v1.1+`、`硬件 v1.1`；不兼容时给出明确报错。
- 与 `host/` 共用同一套通信层时，把通信层抽成独立模块，避免两处协议实现打架。
