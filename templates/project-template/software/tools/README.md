# tools · 开发机工具

烧录、标定、仿真、环境初始化等脚本。

建议清单：

| 脚本 | 作用 |
|---|---|
| `setup.sh` | 一键安装依赖、配置 udev 规则 / 串口权限、拉取上游仓库 |
| `flash.sh` | 编译并烧录固件 |
| `calibrate.py` | 传感器/关节标定，输出参数文件 |
| `check-env.sh` | 环境自检：找到设备、版本是否匹配 |

## 约定

- 每个脚本顶部写「用途 / 用法 / 依赖 / 影响范围」，破坏性操作（覆盖设备参数、清空 flash）必须先确认再执行。
- 脚本要**幂等**：重复执行不出错、不重复安装。
- 涉及固件版本的地方读同一份版本源（如 `VERSION` 文件），避免多处硬编码。
