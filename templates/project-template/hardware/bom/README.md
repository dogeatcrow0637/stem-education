# BOM

一份 BOM 一份文件，命名 `bom_<型号>_<版本>.csv`（例：`bom_base_v1.1.csv`）。

## 固定字段

```csv
序号,分类,名称,规格型号,数量,单位,参考单价(CNY),小计,采购渠道,链接,替代型号,备注
1,电机,达妙 DM4310,V4 版本,4,个,899,3596,官方店铺,,DM4340P,末端关节建议 4340P
2,结构,6061 铝件,CNC 加工,8,件,,,,,以 STEP 为准
3,标准件,内六角螺丝,M3x8 不锈钢,60,颗,0.1,6,五金店,,,
```

- `分类`：电机 / 主控 / 传感器 / 结构 / 标准件 / 线束 / 电源 / 工具 / 耗材
- `参考单价` 与 `链接` 必须可复核，注明采集日期（可写在文件头注释行）
- `替代型号` 用于缺货或降本方案
