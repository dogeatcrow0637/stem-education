# schematic

放原理图、PCB 工程与接线图。

- 命名：`schematic_<版本>.pdf`、`wiring_<功能>_<版本>.pdf`
- 同时给**图**和**表**：图看走向，表看端子（端子号 / 信号名 / 线色 / 对端 / 备注）
- PCB 源文件（Altium/KiCad/EasyEDA）保留可编辑版本，并导出 PDF 便于阅读
- 每份图纸标注：版本、日期、对应硬件版本

## 接线表模板

| 端子 | 信号 | 线色 | 对端 | 备注 |
|---|---|---|---|---|
| J1-1 | VCC 24V | 红 | 电源+X1-1 | 上电前测通断 |
