# 机械臂项目选型对比：reBot-DevArm vs Dummy-Robot

> 用途：决定哪个机械臂项目更适合作为本仓库面向"零基础家长 + 小学生"的 STEM 项目。
> 撰写日期：2026-10-20　|　对比对象版本：reBot-DevArm 上游 `Seeed-Projects/reBot-DevArm`（B601-DM v1.1）；Dummy-Robot 上游 `peng-zhihui/Dummy-Robot` @ `84453f1`（main，2024-03-14）

## 一、结论

**reBot-DevArm 明显更适合作为面向"零基础家长 + 小学生"的 STEM 项目；Dummy-Robot 的价值在"读"而不在"做"。**

| | reBot-DevArm | Dummy-Robot |
|---|---|---|
| 一句话定位 | 可以**照着装**的商业级开源机械臂 | 可以**照着读**的整机设计教科书 |
| 分水岭 | 不需要焊接、不需要画板、不需要写代码 | 必须跨过"画板 → 打样 → 贴片 → 编译固件"四条河 |
| 建议用法 | `projects/01` 家长带娃主线 | 高年级 / 家长自学的**参考资料**，不进 01 号位置 |

## 二、决定性差异：仓库里有没有"可直接生产的中间产物"

这一项比价格更致命。Dummy-Robot 的仓库很完整（955 个文件、87 MB），但**缺的恰好是从"代码/图纸"到"实物"的每一段过渡件**：

| 需要的东西 | reBot-DevArm | Dummy-Robot |
|---|---|---|
| 可直接打印的零件 | 93 个 STEP + 10 个 STP，按零件分组织 | 只有 4 个 STEP：总装模型 `Dummy v164.step`（32 MB）、外壳、电机上下盖。**无 STL、无单件拆图、无爆炸图** |
| 电路板文件 | 零自制板（电机自带驱动） | Altium 源文件（`.SchDoc/.PcbDoc`）。**REF 核心板、REF 底板、20 驱动板都没有 Gerber**，只有 42/57 驱动板给了 Gerber |
| BOM | 官方 BOM 细到每颗螺丝的规格 + 采购链接 | **仓库里没有任何 BOM / CSV / 贴片坐标文件** |
| 固件烧录件 | 不需要（电机固件出厂已带，只需配参数） | 只给了驱动板 `Ctrl-Step-Driver-STM32F1-fw.hex`；**核心控制器没有预编译 hex/bin，必须自己编译** |
| 文字教程 | 官方中文 Wiki 覆盖组装、校准、LeRobot 集成、GR00T 微调、Jetson 部署 | **全仓库文字文档只有 170 行 README + 7 张配图** |
| 上位机 | Python SDK + LeRobot 全开源 | DummyStudio 是 Unity 编译出的 Windows exe，作者明确写"**暂时没有计划开源**" |

> 结论：照着 reBot 复刻 = 采购 + 装配；照着 Dummy 复刻 = **把整个工程重新做一遍**。这对零基础家长是硬墙。

## 三、成本对比

| 项 | reBot-DevArm（B601-DM） | Dummy-Robot（原版） |
|---|---|---|
| **最小可跑闭环（MVP）** | **约 ¥1200–2000**：底座 + 1 颗电机 + 24V 电源 + USB-CAN + 打印件。不需要打板、不需要 CNC | **无 MVP 路径**。结构是一体串联的，要动就得有：4 块自研 PCB 打样+贴片 + 5 颗谐波减速器 + 5–6 颗步进电机。单关节试水的隐性成本仍包括 PCB 与贴片 |
| 全量散件自采 | 约 ¥6000（社区口径） | 约 ¥5500（普赢谐波）/ ¥8250（鑫拓谐波），社区复刻实测口径 |
| 官方套件 | `$1499` 早鸟价，含 Full Kit 到成品 5 档 | 无套件、无官方供货 |
| 最大单项成本 | 电机（7 颗 CAN 总线伺服） | **谐波减速器**：作者自述二手约 ¥600/个，5 个就 3000 起 |
| 结构制造 | 打印件 ~¥350 + 金属件 ~¥1500（仅局部制造成本） | 铝合金 CNC 约 ¥3000（社区口径） |
| 电路板 | ¥0 | 4 块板打样 + 贴片，量级 ¥500 起（社区口径） |
| 隐藏成本 | 电源与 C 型夹不在套件内 | Altium Designer 授权、谐波二手货源不稳定、社区改版的兼容性风险 |

社区另有"木子晓雯国产化 3D 打印改版"，把成本压到 ¥3000 以内，但那是**第三方改版仓库**，不是上游官方内容。

## 四、难易对比（零基础家长视角）

| 技能 | reBot-DevArm | Dummy-Robot |
|---|---|---|
| 焊接 | **完全不需要**（线束买带端子成品） | 需要（4 块板，若不自制也要自己焊接插件与电源线） |
| 画板 / 打样 / 贴片 | **完全不需要** | **必须**：用 Altium 打开工程 → 自己导出 Gerber → 打样 → 出 BOM + 坐标文件 → SMT 贴片 |
| 烧录固件 | 不需要（只配 CAN ID 与零点，有 GUI 工具） | 需要：核心控制器固件要自己用 STM32CubeIDE / CMake 编译后烧录 |
| 命令行 | 基础级（Ubuntu 装环境、跑官方示例） | 要会 CMake / STM32 工具链 / 串口调试 |
| 3D 打印 / 加工 | 传 STEP 找代打即可 | 需要自己从总装 STEP 拆件、补加工图，或直接走 CNC（¥3000 起） |
| 专业软件 | 无 | Altium Designer（商业 EDA） |
| 最容易卡住的地方 | Ubuntu 物理机环境与 CAN 权限（有官方文档可查） | 结构件拆分 + PCB 自制 + 固件编译，**三处都没官方教程** |

## 五、成就感的"到达时间"

| | reBot-DevArm | Dummy-Robot |
|---|---|---|
| 第一次"它动了" | 装底座 + 一个关节 + 配参数 → **1–3 天**（MVP 定稿后） | 即使全部外包打板贴片，PCB 交期 + CNC 交期 + 装配标定，社区实测周期以**周–月**计 |
| 中途失败率 | 中（多来自软件环境，可查文档） | 高（结构、电子、固件三线都可能断，且无官方排错指引） |
| 终点作品 | 一台能跑 LeRobot / VLA 的完整六轴臂 | 一台≥还原度的工业风桌面臂 + 一份读懂的整机设计 |

## 六、孩子参与度（小学生真正能上手的动作）

| | reBot-DevArm | Dummy-Robot |
|---|---|---|
| 安全等级 | 24V 供电，全程无烙铁、无高压、无金属加工 | 含打板、贴片、烧录、CNC 金属件；孩子核心环节只能旁观 |
| 孩子能做的动作 | 对件号、分装螺丝、拧螺丝、插接插件、看屏幕读角度、改参数、录数据、当解说员 | 主要只剩"递东西"和"看" |
| 可否做出"这是我改的" | 可以（改角度/速度/顺序，立刻可见） | 很难 |
| 危险项 | 无刹车断电下落（用支撑垫管理） | 无刹车下落 + 打板贴片 + 焊接 + 金属件毛刺 |

## 九、建议

1. **`projects/01` 保持 reBot-DevArm**，家长带娃主线不变。
2. **Dummy-Robot 不建议作为带娃动手项目**。若要收进本仓库，建议登记为 `projects/03`（或 `docs/` 下的参考解构），定位写成"**进阶阅读 / 整机设计解构**"，服务对象是高中以上学生或家长本人，产出以"读懂一份完整机器人设计"为目标，而不是"做出来"。
3. 若确实想要一台**比 reBot 更便宜、门槛更低的第二台机械臂**给孩子练手，Dummy 不是答案：它的对照物是 SO-ARM101（Hugging Face LeRobot 官方开源臂，3D 打印 + 舵机，无需自制 PCB，套件量级 ¥500–1500），这才是"低成本 + 免画板 + 有官方教程"的组合。
4. 若仍想复刻 Dummy，**不建议走原版 CNC 路线**。可行路径只有两条：① 用社区国产化 3D 打印改版（第三方仓库，成本约 ¥3000，需自行核验质量）；② 只用它当设计参考，实际制造外包给有 Altium 与 SMT 能力的团队。

## 十、事实来源与未核验项

**已核验（本地仓库 / 官方 API）**

- Dummy-Robot：`84453f1`（main）文件树 955 项（含目录，807 个文件）、仓库 87 MB、星标 15.6k、最后推送 2024-03-14、默认分支 main；`1.Hardware/` 为 Altium 源文件且 REF 与 20 驱动板无 Gerber；`4.Model/` 仅 4 个 STEP；`2.Firmware/_Released HEX/` 仅 1 个驱动板 hex；`5.Docs/` 仅 7 张图片；仓库根无 LICENSE 文件；驱动板 MCU 为 STM32F1、控制器为 STM32F405RGTx（依据 `.ioc` 与链接脚本）；`0.SubModules/Peak` 为空目录（submodule 未随快照拉取）。
- reBot-DevArm：见本项目 `projects/rebot-devarm/docs/01-项目简介.md`、`02-选型与BOM.md`、`99-参考资源.md`。
